# 图鉴观察图

**当前定位：程序试制对照，尚非最终美术成品。** 2026-10-02 用户再次指出线条和配色混杂，当前方向改为 AI 从原画提炼单色线稿，再把经过核对的成品图入库。首张素材与提示词准备在设计目录的 `ai-lineart-sample` 中；当前这些 WebP 仍是程序生成版本，不是 AI 成品。

当前仅保留 14 项算法对照：潮礁 7 张、洋馆 7 张（含旧版玛丽埃塔）。用户要求移除的三个早期条目已从目录、派生图与清单移除；旧派生文件移到忽略的报告目录保留对照。复用原图的遭遇不重复生成。主图和缩略图用于图鉴开发目录，不替换战斗原图，也不写玩家收录进度。名称与来源见 [catalog.json](catalog.json)，SHA-256、裁切范围、视觉重心、落地锚点、处理版本和产物 hash 见 [sources.json](sources.json)。

安装 `scripts/requirements-codex-observation.txt` 中的 Pillow、numpy、scipy 后，运行：

```sh
python3 scripts/prepare-codex-observation.py
python3 scripts/test_codex_observation.py
```

可用 `--asset enemy.slime.mire` 只重导指定素材；默认完整生成，并检查清单是否遗漏、重复或包含失效来源。每项输出透明无损 WebP：`{id}.webp` 主图与 `{id}.thumb.webp` 缩略图。二者分别按 550×380、82×62 显示框的两倍分辨率计算，等比适配，不拉伸素材。主图含每侧 12 个显示像素留白，缩略图含 4 个。

v5 试制按 alpha 可见范围规范化，在重采样时使用线性颜色预乘；原素材是 straight alpha，不作错误反预乘。保边平滑与五阶区域图为源墨线提供结构对齐评分，Zhang–Suen 骨架在交叉点拆段，按真实段长评分和局部密度选线，再以 1.0／0.7 个显示像素重绘。轮廓沿 alpha 内侧独立生成，不参与内部线条预算。

淡染修补实际转成浅线的区域，并限制纹理残差；少量紧凑暗点独立保留，不再用高对比旁路把所有碎纹变亮。输出 alpha 与规范化来源一致。该试制减少了亮色碎块，但用户未认可配色与整体质感；不继续将其视为定稿路径。旧 v4 和 v5 的离线诊断、原始素材均保留，AI 成品生成后应独立命名入库，避免离线脚本覆盖。

离线墨线、淡染、方向图层和历史总览保留在 `dist/reports/codex-observation`，由脚本重建。实际 Menu 的逐项截图用于检查轮廓、比例与视觉重心。来源覆盖、hash、主图/缩略图 alpha 与透明 RGB 污染有回归验证；审美效果仍以用户反馈为准。
