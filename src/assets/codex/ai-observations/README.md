# AI 观察线稿

当前图鉴目录 14 项，全部使用本目录成品：潮礁 7 项、洋馆 7 项（含旧版玛丽埃塔）。裂隙爪兽、畸变魔物、术式陷阱已移除。算法试制仅保留为离线对照，运行时不回退加载。

- 来源：目录中显式关联的原始战斗素材，原文件未改动。
- 生成：用户指定的本机 `nai5-image-studio`，Image 2.5 / `high`；礁蟹沿用用户接受的 v2。批次来源及实际模型、提示词、选中版本见 [批次记录](../../../../docs/design/codex-concept-2026-10-02/ai-lineart-batch-2026-10-02/README.md)。
- 线条：AI 负责主轮廓、内部结构与疏密。程序只将白底转换为透明，统一可见像素为 RGB(190,190,175)，保留原线宽；亡命徒细线对比做轻量匹配；不再从战斗原画抽边。
- 尺寸：按完整可见线条裁去空白，保留相连道具及边缘抗锯齿。主图上限 1100×800、缩略图 164×124，外围分别增加 6px、2px 透明留白，无损 WebP。原始生成图不覆盖。
- 展示：UI 按形体等比放大，千金、玛丽埃塔单独调整。主图允许超过观察区，四角柔化与外围软遮罩令边缘逐渐淡出；微光与轮盘仍属于 UI。

运行 `scripts/prepare-codex-ai-lineart.py` 可从已检查的原始 AI 输出重新整理素材。[sources.json](sources.json) 记录来源、原始图、真实生成记录、裁切范围、重心及产物 SHA-256。`scripts/check-codex-ai-lineart.py` 检查来源、质量、透明边缘、颜色及 14 项覆盖，并导出总览。

礁蟹方向已获用户接受；批次视觉修订继续按用户反馈调整，不以工程检查通过代替审美认可。
