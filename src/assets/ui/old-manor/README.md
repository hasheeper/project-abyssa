# 旧庄园战斗界面装饰

为 `old-manor` 主题手工绘制的独立 SVG，源文件即正式素材；无外链、嵌入位图或字体依赖。

- `battle-frame-threads.svg`：完整画框红线层，替代原先分开的顶饰和镜像角饰。招牌两肩保留成束向上牵引的红线，维持悬吊与破窗感；两侧脱离线束、单独从上方落下的长竖线已移除。松线从两肩下垂接入四边内沿；双股长线与局部回线补足边缘，交点以少量缠线固定。
- 上方的松弛线接在既有受力线束上：一根浅垂跨顶线、左右跨度和垂度不同的余线，以及从肩部绕结垂下的短线尾。受力线较实，松线较细暗；曲线受重力向下弯垂，避免等距平行、镜像复制或凭空落下的竖线。
- 坐标契约：宽 1540，画框高 1025.78，向上延伸 62；`viewBox="0 -62 1540 1087.78"`。框顶为 y=80.78，招牌接点约为 (490,29) / (1050,29)。顶栏、四角、内沿共享同一坐标系与整框缩放，接点不能再拆成镜像图拼接。

按用户最终调整移除花窗、黑铁包角、钥匙、缝针、布褶等具象装饰，只保留低亮度细红线。装饰经 `battleUiSkins.ts` 的 `frameOverlayUrl` 登记，不叠加 `FrameEdgeWeave` 或其他顶角饰；没有动画、发光或模糊滤镜，不参与状态、命中区域或战斗结算。
