# 商店木质样板 v1

仅用于真实商店的 TAB、货架与详情外框，不扩展到立绘框或其他页面。

- `wood-grain-v1.webp` 来自项目已有的 `src/assets/backgrounds/shop.png`，不是外部下载或 AI 生成素材。原图不修改。
- 裁取单块木板内部，转为水平纹理；保留原像素细节，只扣除大范围受光，再映射为低对比暖深木色。已移除首版的缩小、平滑再放大流程。
- 输出为 655 × 58 无损 WebP；边缘连续，按原尺寸平铺，不拉伸。所有处理离线完成，页面不使用实时滤镜或 canvas。
- TAB 与货架的纹理尺度、坐标原点一致。底纹替换货架的重复菱形，不叠加第二套装饰。
- 货架外圈保留木面；内部商品床通过上/左侧遮蔽、下沿受光表现内凹。持有量、价格为更深的两条纵向槽，表头、槽底、商品行共用列宽定义。
- 原有六层物品图案保留，只在商店列表局部把图标外缘改成嵌入式受光。装饰槽底不接收点击，不生成额外商品或占位行。
- 列表改为单行商品名，说明保留在下方详情及无障碍描述中。图标由 48 调到 42，与行线之间留出空隙；字号、56px 行高和七行容量保持不变。持有量、价格居中对齐各自的槽位与表头。
- 每页最多七件商品。箭头和页码并入“在售物资”表头，不另占底栏；单页仍显示禁用箭头。翻页同步选中项、详情和键盘焦点，不触发交易。
- 详情采用横向排版：左侧物品凹槽贯穿两行信息；名称短木衬与持有量／购后预览同排，说明位于名称下方。底部数量、合计、购买共用一条紧凑操作行，不再用贯穿横线划出结算区；文字区保持开放木面。
- 交易逻辑保持不变。出售、鉴定仍是禁用占位。

## 当前商店进场

- 沿用角色／出征的木板节奏：黑幕揭开后再开始，整板 820ms 缓落 34 个设计像素，材质单独 240ms 淡显。真实商店不再叠加旧的全局 500ms `panel-drop`；战斗和原型展示不改。
- 店主从 220ms 开始显露；TAB、货架、详情外框在同一平面上，从 260ms 开始进入，避免接缝分离。下栏物品图、文字、操作分别从 380／430／520ms 接上，最晚 860ms 完成。
- 仅动画化 `translate` 与 `opacity`，保留布局缩放；不缩放文本、不做逐行弹跳、不常驻动画层。输入会直接收稳，减弱动态／隐藏页面也直接到终态。
- 刷新与路由返回使用同一进场。切换商品仅调用现有 `UiContentTransition` 的 120ms 内容淡显；首次、同商品数量／库存／余额刷新不重播，按钮与外框不卸载。

使用带 Pillow、numpy 的 Python 运行：

```sh
python3 scripts/prepare-shop-wood.py
python3 scripts/prepare-shop-wood.py --check
```

`--check` 不写入文件，会验证材质像素、尺寸、平铺接缝及对比范围。
页面接入集中于 `src/apps/shop/shop-counter.css`，不修改共享 RpgFrame 皮肤。
