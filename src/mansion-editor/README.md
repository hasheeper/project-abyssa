# 洋馆热区标注器：MVP 需求

这个入口是正式洋馆界面的参数生产工具，不承载洋馆玩法。

## 本轮交付

- 将 `map.psd` 的顶层图层导出为透明裁切 PNG，并按 PSD 原始坐标在 HTML 中拼回 5162 × 1910 画布。
- 保留图层显隐开关；默认状态与 PSD 一致。
- 画布支持滚轮缩放、空格或中键拖动画布、一键适配窗口和 100% 查看。
- 高频房间可以直接拖拽框选矩形；矩形四角可以继续拖动微调。
- 非规则区域可以逐点框选多边形；点击首点或按 Enter 闭合，Escape 取消，退格撤回最后一个点。
- 已完成区域可以选择、改名、改变类型，并拖拽顶点微调。
- 标注自动保存在浏览器 `localStorage`，刷新页面不会丢失。
- 可以导入、复制或下载 JSON，并下载可直接提交到代码库的 TypeScript 固定参数。

## 固定参数契约

- 原始坐标系永久固定为 PSD 的 5162 × 1910。
- 区域顶点保存为 0–1 的归一化坐标，而不是当前屏幕坐标。
- 正式洋馆页只消费导出参数，不依赖标注器的缩放、平移或 DOM 状态。
- 矩形导出到独立的 `rectangles` 数组，保存归一化 `x/y/width/height`。
- 多边形导出到独立的 `regions` 数组，保存归一化 `points`。
- 两种区域都只带 `id`、`label` 和 `kind`；设施等级、角色站位、事件牌与收益属于后续业务数据。

## 默认对应

`defaultRegions.ts` 依据《ABYSSA-守望者之崖-布局骨架-v8定稿》的
`data-key` 与 `ROOM_DATA` 预置第一批房间。ID 延续原稿的 `kitchen`、
`abyssa`、`library` 等英文 key；中文显示名延续原稿命名。

PSD 中明显存在、但 v8 骨架没有独立列出的空间，以“美术补充”标记，
目前包括二层起居室、工坊和阁楼观星室。默认边界只是初始建议，进入
标注器后可直接拖动矩形四角或多边形顶点继续校准。

## 明确不做

- 不在本工具里实现角色拖放、设施排班、生产结算或房间升级。
- 不做自由家具摆放，也不把角色站位写入房间产能。
- 不自动猜测房间边界；多边形由策划人工确认。
- 不修改现有 `src/map/` 副本地图应用。
