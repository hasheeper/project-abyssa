# 内容 21：普通掉落表与商店数量出售

从冻结内容 20 克隆发布。新普通档使用此包；旧档及 AIRP 显式起点保留原内容摘要。

三条普通路线共用 12 种常规战利品和 4 种鉴定品。每个房间有固定的来源槽位，槽位各自按权重抽取；途中鉴定品为 20%，末战必得，同一趟不重复。房间结束获得，清层入袋，沿用普通损失规则。教程仍使用原固定 grants。

本包同时开放已知单件物品的数量出售，按实例核验并原子入账。未鉴定品、附带废料、拒收物和教程整批物不混入数量出售。

概率、价格与来源见[普通副本正式掉落表](../../../../docs/design/ORDINARY_DUNGEON_DROPS.md)，执行状态和非视觉证据见[实施记录](../../../../docs/audits/2026-09-24-ordinary-drops-implementation.md)。战备拾获暂不启用，五种专用小图仍为开发占位。
