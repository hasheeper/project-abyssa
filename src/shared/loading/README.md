# 游戏启动与资源准备

流程：**单入口 index.html → 六面骰黑幕下并行准备当前路由与首屏字形 → 当前页数据、字体和图片就绪 → 揭幕，同时后台预读后续资源**。标题 Logo 弹入不再等待整份资源清单。同一文档共享关键字体准备与后台预读；切页时目标模块与收幕动画并行，但必须等收幕完成才卸载旧页、挂载新页。首次加载和切页共用一个 `SceneTransition`。

## 所有权

- `config/vite/game-startup.mjs`：构建结束后依据输出生成 `game-assets.json` 和 `game-cache.js`。包含页面、代码块、CSS、运行图片、差分／漫符、字体与 JSON。洋馆只预读材质版清单的可见图层及兜底合成图；旧原图、参考图和隐藏图层仍保留给制作工具，不加入游戏预读。清单优先排列代码和标题 CG，不包含 source map。开发清单缓存到源码／素材变动再失效，合并并发请求。字体许可证随产物提供。
- `startup.ts`：`prepareGame()` 只加载首屏文本命中的字体子集；失败可重试。`warmGameResources()` 在揭幕时启动，不阻塞交互，失败后在实际使用或后续切页时重试。开启浏览器省流模式时跳过整包后台预读。`src/game-shell` 保留当前页数据、可见字体和图片就绪检查；模块可缓存，组件和 WebGL 不跨路由保活。
- `resources.ts`／`cache-worker.js`：后台预读两路低优先级下载；显式前台整包准备接口仍最多六路。发行版 SHA-256 校验、内容寻址缓存和进行中请求去重不变。失败保留已有资源，缓存限定当前部署目录与清单文件，不接管存档/API。
- `images.ts`：AVG、标题轮播、CG与场景交接共用图片解码服务；规范化 URL、共享 Promise、失败可重试。最多48项、约3200万像素（RGBA约128MB）。标题只预解码左右起始两张图，其余由后台字节预读和轮播的下一帧检查接力，解码失败继续保留旧画面。序幕仍保留当前／下一张工作集。

## 网络与内存是两层

首屏不再等待全游戏文件。揭幕后后台渐进填充完整运行资源缓存，但不会解码全部字体、把所有图片展开成像素、挂载隐藏场景或创建额外 WebGL 上下文。场景切换仍按需准备当前画面；后台尚未完成时可能出现短暂场景等待，不能把后台缓存成功当作数据就绪。原全量百分比已撤下，黑幕沿用活动指示，避免将后台进度误标为首屏进度。离页继续释放 WebGL、RAF、监听器及存档会话；页面 CSS 自动按路由隔离。

## 静态部署

1. `npm run build:game`，将 **整个** `dist/game` 放到同一 HTTPS 目录（本机 localhost 也支持 Service Worker）。可部署在 `/abyssa/` 等子目录，全部启动与缓存路径由当前文档目录解析。路由采用 `#/map?save=…&epoch=…`，无需服务器 rewrite，子目录刷新与浏览器前进后退均可用。生成的旧 `map.html` 等小型跳转页只兼容已有书签。
2. `game-assets.json`、`game-cache.js`、HTML须允许更新检查；建议 `Cache-Control: no-cache`。带内容哈希的 `assets/*` 可用长期immutable缓存。当前资源缓存自身也校验文件内容，无法通过校验的200错误页面不会被当成加载成功。
3. 必须保留生成的清单与Worker；更新采用整包原子发布，避免新旧文件混用。首页HTML在线优先，断网时使用缓存；前一版哈希资源为仍打开的旧页面保留。**标题可交互不代表整包已缓存完毕**：只有后台完整准备成功后才具备完整离线资源。提前关闭、断网或省流模式下，尚未缓存的场景仍需要网络。
4. 浏览器禁止Service Worker／持久缓存时，回退到同样限并发的HTTP后台预读。后台失败不阻断标题，实际页面准备失败仍通过黑幕重试。跨文档与离线缓存能力由宿主浏览器决定，不声称拥有持久离线保障。
5. 开发模式读取生产导入与运行素材目录生成清单，使用HTTP缓存，不注册Worker缓存开发脚本，避免HMR后看到旧代码。新增动态素材应加入资源profile或可识别的静态import/glob。

Cinzel与Noto Serif SC沿用原字体，103个官方WOFF2子集全部本地化；根据实际文本按需加载，不再强制逐个解析。旧骰局仍使用本地商店缇比立绘。

## 本机存档维护

开发服务器的 `/scripts/clear-game-saves.html` 提供手动清理页，不进入发行构建，不自动删除任何数据。在原游戏浏览器、原站点和原标签页打开，关闭其他游戏标签页后勾选确认。仅清除 `abyssa-game-v1`（存档与回执）、最近／归档标记及本标签页的存档提示，保留偏好设置与素材缓存。删除不可在游戏内撤销，需保留的数据先通过游戏档案页导出。`localhost` 和 `127.0.0.1`、不同端口或浏览器配置分别存储。

## 验证

- `src/shared/loading/*.test.ts`：关键字体选择、后台不阻塞、省流模式、两路低优先级预读、并发去重、响应体完整消费、失败重试、缓存跨版本复用、HTML错误响应、离线导航及图片预算。
- `src/game-shell/GameShell.test.tsx`：数据等待、单层黑幕、离页清理、存档重定向、模块失败重试与快速返回竞态；`tests/build/route-styles.test.mjs` 验证页面样式隔离。
- `tests/build/startup.test.mjs`：清单覆盖CG glob／差分／字体与内容版本；`check:output`核对产物及清单哈希。
- `src/apps/title/route.test.ts` 验证首屏只解码两张CG；`scripts/clear-game-saves.test.mjs` 验证清理范围与删除失败状态。
- 静态服务器验证标题、字体、图片和后续导航；完整后台缓存成功后再测试暖启动与离线访问。
