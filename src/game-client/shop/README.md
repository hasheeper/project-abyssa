# 商店共用展示层

正式商店与独立 `new-shop` 测试页共用 `ShopSurface`。组件通过 props 接收商品、余额、分类、台词和操作，不持有游戏存档，不导入测试数据。正式入口在 `src/apps/shop/ShopPage.tsx`，真实交易控制在 `ShopCounter.tsx`；旧版 `OldShopCounter.tsx` 仅作参考。

1600 × 900 Stage 等比适配。左导航从 x161 开始，货架 x350、宽744，人物栏宽400、高600，两栏间隔28。人物按430px宽裁切，固定对白高168。顶部560px招牌与310 × 52资产区分开；分类128 × 44，名称不超过两个字。横梁与两侧铜边连续，保留哑光木纹、凹槽、铜色物品槽和原有详情层次。买卖共用详情结构，鉴定使用固定台词、打字机与AVG差分。图标来源见 [归属说明](assets/icons/ATTRIBUTION.md)。

货架每页七条：48px 物品槽、名称与单行用途、持有量和价格保持固定对齐，选中态使用铜色内边与哑光底色。名称与用途之间保留 7px 间隔，满页时仍容纳两行文字。用途取真实物品描述，长文在列表截断、详情完整保留。三种模式都有“物品”表头；翻页仅在多页时出现在列表底部右侧，不占用表头。

分类 TAB 使用切角铜边，与横梁、表头共用原商店木纹；选中 TAB 底部开口接入横梁，顶部结构整体随柜台运动。列表与详情保持暖棕木底、铜金边饰和米色文字，材质只调整亮度与对比度，不整体去饱和。详情名称保留局部浅阴影，下方细线独立分隔标题与说明。

左侧导航保留现有图标与尺寸，长底板采用纵向木纹，短吊牌采用横向木纹；错开的底沿与投影表现叠层。选中项为右侧中央微凸的木质铭牌，菱形嵌在尖角前，哑铜细边与其他面板一致。导航不使用渐变填充、反光光斑或渐变图标；购买、出售、鉴定共用同一铭牌。

顶部招牌由两条短铜链从场景上缘吊住，链尾与牌面铆接扣重叠连接。吊链和扣件在招牌内部，随同一入场轨道运动，顶部延伸出画面，落位过程中不会与牌面脱开。

鉴定续句共用详情区的主按钮，`ShopSurface` 统一管理打字状态：首次点击补全当前句，再次点击推进，末句完成后显示“收好”。对白本身仍可点击或用键盘快进，不另放小按钮；打字机和入场状态保持同一条时序。

常规入场1120ms，剧情结束后短衔接480ms。`entrance.ts` 同时提供CSS变量和完成时间，`useNewShopIntro` 等资源解码、外层切场和 `SceneSequence` 释放后起播。横梁、货架和人物窗整组落位，背景、人物、前景与内容错拍；提前输入收束后仍执行原操作。打字在入场就绪后开始；减弱动态、后台与离场按共享生命周期收束。

鼠标景深已移除。静止时只有灯笼局部暖光轻微变化；后台与减弱动态保持静态。前景使用用户提供的 `Scylla-1-v1 (2).png`，扣黑底后的素材是 `assets/counter-foreground-front.png`，旧斜视素材保留在同目录。`counter-quill-mask.svg` 仅将羽毛笔上段降至约52–61%不透明度，桌面与灯笼保持实心。

`styles.css` 仅包含商店专用规则，供两个入口导入；公共基础样式由各入口通过同一模块路径加载，不在商店 CSS 内重复打包。所有商店规则均有组件类名作用域。独立入口的 `html/body/#root` 规则留在测试页 `preview.css`，不会污染正式游戏其他页面。资源清单来自现有内容展示定义；生产依赖链不包含 `preview-data.ts`。

公共对白统一从 `components-core.css` 加载，菜单、洋馆与剧情组件不再另载重复的 `dialogue.css`。否则懒加载的默认 `min-height: 112px` 会覆盖主菜单的 `158px`。浏览器回归在同一文档中执行“主菜单 → 首次入店 → 跳过对白 → 主菜单”，核对返回前后的宽度、高度、最小高度与正文内边距，并保存截图；尺寸比较之前不刷新页面。

正式页额外提供紧凑的鉴定记录浮层、真实错误反馈与公共游戏导航。购买成功使用通用“获得道具”侧上提示，多个提示向下叠放；出售明确显示收入。首次入店仍由 `ShopVisit` 和原存档命令管理，动画结束不推进剧情、不发奖励。
