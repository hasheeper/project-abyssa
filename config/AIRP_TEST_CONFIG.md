# AIRP 本地测试配置

更新：2026-09-25。正式测试入口是内容28的「AIRP 游玩」；内容18的「旧版 AIRP 调试」收在开始位置的「调试入口」中，仅用于旧药箱流程。两者调用链和存档协议不同，不能交叉作为验收证据。

## 配置与导入

以同目录的[airp-test.example.json](airp-test.example.json)为模板，填写本机`airp-test.local.json`。本机文件已被Git忽略，开发服务器也禁止通过HTTP读取；不提交、不放入`public/`或发布产物。

| 字段 | 用途 |
| --- | --- |
| `connection.baseUrl` | Chat Completions兼容API地址，例如`https://你的域名/v1`；保留已有路径，自动补`/chat/completions`，也接受完整请求地址 |
| `connection.apiKey` | 对应端点的Key |
| `models.planning` | 正式日度／副本／场景GM槽；旧试读协议可能用于大纲 |
| `models.writing` | 正文创作 |
| `models.updater` | 中文封装及独立结算等辅助任务 |

每槽可填写`model`、`max_tokens`、`timeoutMs`等受支持参数。当前模板给出默认示例，不代表供应商端点必然支持；显式导入值不会被新默认值覆盖。三槽默认共用公共连接，独立端点需同时配置该槽自己的Key。不要把Key写入地址、模型名或提示词。

页面只通过文件选择导入，不自动读取项目目录。进入「设置 → Model → 导入配置」，核对三槽后点击「保存」。仅导入不发请求，也不等于已经保存；下次同一浏览器／Origin打开时自动恢复已保存连接。生成面板只保留「前往设置」，不再复制连接表单。

连接使用独立浏览器存储，与游戏档案分开；磁盘上的源配置仍是明文。具体加密、删除和旧配置兼容规则见[统一连接说明](../docs/architecture/AIRP_CONNECTION_SETTINGS.md)。

## 正式游戏验收

```sh
npm run build:game
node scripts/serve-built.mjs
```

打开`http://127.0.0.1:5199/`，选择「新的开始 → AIRP 游玩」，再进入设置导入连接。当前内容28继承普通掉落、日期货架和洋馆生产；生成链见[LLM与AIRP](../docs/architecture/LLM_AND_AIRP.md)。

- 场景正文、中文封装、场景GM按当前轮次分别执行；日度／副本GM和行动／事件结算另有任务，不把一场三次当作整个流程的成本。
- 实际操作接受委托、出征、取得与带回目标，再按合法步骤交付。模型文本不能代替实物或真实战果。
- 收起生成面板可由后台宿主继续保存；进入AVG后锁定阅读，刷新恢复当前阅读位置。连接修改不会追改已冻结的任务输入、模型或端点。
- 保存失败用「重试保存」，有原稿用「继续后处理」，正文请求失败且无可用原稿才显示「重新请求正文」。后者会再次调用模型；打开面板和查看日志不会调用。空回复、工具调用、非文本和异常结束分别提示，详情在「调用记录」查看，分享使用脱敏诊断。
- 正式AIRP支持原身份备份恢复；完整存档含作者全文和非密钥模型配置，不含Key。脱敏诊断不能当作存档导入。

真实调用脚本可能产生费用，须先核对其对应版本与当前累计账本；旧报告中的12／46／500次等上限是当时记录，不能当成新的调用额度。此配置说明不授权自动生成、重置账本或操作玩家存档。

## 独立试读与旧协议复现

`npm run build:airp`后运行`npm run preview:airp`，打开`http://127.0.0.1:5195/airp.html`。独立试读用于预设和情境验证，阅读结果不写入正式游戏变量或记忆；新任务与继续原冻结任务分开。

内容18的「调试入口 → 旧版 AIRP 调试」及`playwright.airp-p2*.config.ts`只复现早期药箱闭环，不覆盖当前28的GM、实物委托或设施。旧真实报告保存在`dist/reports/airp-p2/`；恢复既有档案使用`playwright.airp-p2-restore.config.ts`，无需重新生成。旧10仍为相邻rp服务协议。已有18存档继续从「继续游戏」读取，不改变身份或内容版本。

按当前工作约定，不做录屏或截图视觉验收。运行测试前查看脚本作用，区分纯本地检查、恢复回放与真实模型调用。

## 网络与发布

浏览器直连API，端点须允许页面Origin的跨域预检及`Authorization`、`Content-Type`请求头；HTTPS页面使用HTTPS API。命令行连通不等于浏览器连通。

只发布`dist/game`或对应独立入口产物，不发布项目根目录、本机配置和`dist/reports`。客户端包含送模所需的作者资料，发布范围另按[HTTPS说明](../docs/deployment/AIRP_STATIC_HTTPS.md)核对。
