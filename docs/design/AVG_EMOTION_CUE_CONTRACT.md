# AVG 情绪联动与校准契约

更新：2026-09-09。情绪映射为已接入的首版表现方案；气泡位置以用户从工作台提供的两张完整校准表为准。

## 单触发词入口

固定剧本与后续 LLM 只需在发言消息中提交一个 `emotion`。Abyssa 本地依据角色配置解析表情、气泡和一次性动作。

```ts
{ id: "line-17", kind: "say", actorId: "marietta", emotion: "displeased", text: "……" }
```

输入集合沿用现有表情：

| 原代号 | 触发词 | 语义 | 原代号 | 触发词 | 语义 |
| --- | --- | --- | --- | --- | --- |
| a | neutral | 平静 | h | closed | 闭目 |
| b | smile | 微笑 | i | wry | 戏谑 |
| c | joy | 喜悦 | j | flustered | 窘迫 |
| d | sad | 低落 | k | displeased | 不悦 |
| e | angry | 生气 | l | confident | 自信 |
| f | surprised | 惊讶 | m | confused | 困惑 |
| g | serious | 认真 | n | panicked | 慌乱 |

英文词、a–n 与表中中文标签等价；旧 `expression` 字段兼容，二者都有时 `emotion` 优先。没有触发词时保留上次表情；不扫描对白、标点或称呼来猜情绪。未知值回落平静。

专属触发词保持现有素材范围：艾比希斯 `star-eyes` / `cat-mouth`，艾洛拉 `>_<`，柯萝萝 `wink`，缇比 `smiling-eyes`。不能把其他角色的专属词套过来。

## 逐角色表现

唯一映射源：[character-emotions.ts](../../src/content/presentation/character-emotions.ts)。覆盖10人×14种基础情绪及5项专属差分。配置包含表情、可为空的气泡、可为空的动作及幅度／时长。静止是有效表现，不要求每个情绪都凑满三项。

| 角色 | 匹配方向 | 示例 |
| --- | --- | --- |
| 艾比希斯 | 慵懒、反应小，威胁时静止 | 喜悦是星光与轻颔首；生气保持静止 |
| 阿尔薇特 | 稳重、克制 | 认可轻颔首；闭目没有睡眠符号 |
| 艾洛拉 | 柔软、担心时轻微动摇 | 窘迫配害羞与轻晃 |
| 尤斯缇丝 | 端着架子、节拍明确 | 不悦配愤怒符号与短促点头 |
| 柯萝萝 | 缓慢、慵懒 | 闭目可困倦；得意用灵光 |
| 蕾诺尔 | 寡言、带刺 | 不悦配低气压；窘迫才轻晃 |
| 玛丽埃塔 | 体面、无机质 | 不悦是省略号与静止 |
| 诺玛 | 灵活、狡黠 | 得手轻跃；窘迫冒一滴汗 |
| 缇比 | 活泼、精明 | 喜悦轻跃；自信配闪耀 |
| 薇薇安 | 从容、优雅 | 自信配闪耀；不做跳跃 |

这里的点头、摇晃、跳跃均使用现有立绘整体动画，不宣称有独立头部、手臂或骨骼动作。主角 `{{user}}` / 内部 `kael` 及静态肖像不自动获得动作或气泡。

### 动作幅度复核（2026-09-09）

此前24–42px的跳跃与3–8px的轻抖，在1600画布缩小后仍不清楚。现将原库基准改为跳跃72px／680ms、轻抖12px／440ms、剧震28px／640ms；角色映射同步提高，避免显式参数覆盖新基准：跳跃52–84px、轻抖9–20px。艾洛拉喜悦64px／760ms，诺玛喜悦76px／680ms；跳跃略延长腾空，轻抖原时长加100ms，保留人物之间的节奏差异。

跳跃／抖动的关键帧形状、衰减方式、一次性播放与原划入保持复用，不加额外轴向、镜头抖动或新动作。摇晃6–10px和静止映射保持原值；立绘位置、取景和气泡校准表不变。

1280×720隔离预览实测：艾洛拉喜悦在AVG／RP均上移约51px；诺玛慌乱的水平峰峰行程约25px，显式原库轻抖约18px。定格腾空检查了完整立绘与固定席位裁切；22项相关测试、前端类型检查、游戏构建及产物检查通过，未写入真实存档。

点头追加修订：基准改为30px／820ms，前半段稳稳下沉，底部停留约82ms，再用246ms抬起，最后82ms收稳。去掉急停撞底和身高压缩，回程只保留8%的轻微越位。角色配置同步调整为20–41px／710–1040ms，继续保留克制、利落与慵懒的区别，避免旧的8–22px配置覆盖新基准。正式舞台实测尤斯缇丝认真动作下沉26px，随后回程、轻微越位并归零。

## 演出时序

- **同一拍的文字、表情、气泡和动作同时开始。** AVG／RP不再统一等待700ms的席位进场，也不等待打字完成；入场与动作使用各自的变换层。文字自然结束或点击显示全文不重启、不打断当前动作。
- 表情保留；气泡最多出现2.3秒，随后卸载APNG；动作只播一次。
- 同一角色连续提交同一情绪（包括等价别名）不会重复播放。普通换句、打字机刷新也不重播。
- 新情绪才生成新的演出键。失去说话焦点、系统遮层、切后台、卸载会取消当前效果；恢复焦点不补播过期动作。
- `hydrate` 保留挂载时的表情状态并抑制旧瞬时效果；后续新情绪仍可播放。回看模式恢复表情，不重播动作／气泡。
- 新场景由整体转场带入的首批角色，只免去重复席位入场，不等同于读档／回看恢复，首个新情绪照常播放。
- 动作使用独立内层 transform，保留原进退场、取景与纵深。减少动态效果设置下不播放整体动作，漫符切静态图。
- 固定剧本的显式动作也复用`motions.ts`，不得在原席位划入上再套一层入场。首晨已撤掉临时自定义曲线，只有少数点头／轻抖；确实无法复用的重点才扩展动作库。物品展示独立使用小方形`RpgFrame`与本地PNG／SVG，不用立绘动作模拟道具飞入。

取景不裁原图：`PaperDoll` 的 `upper`／`knee` 只决定定位盒比例，图层始终完整绘制到盒外。去掉内部 `overflow:hidden`，避免把膝部硬切边跟着动作抬进画面；裁切仅交给固定的AVG舞台／RP席位框。修复前后位置、尺寸、校准矩阵不变，气泡仍使用原坐标基准。工作台共用同一组件，已抽查42px跳跃与RP近距离取景；相关12项组件测试通过。

## 校准只有一套

唯一发布位置源：[emotes.ts](../../src/shared/ui/patterns/emotes.ts) 的 `EMOTE_PLACEMENT` 与 `EMOTE_ADJUST`。本次原样回填15项基准、10人125项偏移，覆盖150种组合；两张表必须一起更新。

沿用用户校准时的 CSS 语义：`size` 相对立绘宽度，`x/y` 相对漫符自身边长；先合并基准与角色增量，再由 `Emote` 渲染。历史注释曾误称三者都参照立绘宽，现已纠正文档，**没有改变渲染算法或用户数值**。不再根据眼睛位置计算新坐标，也不按左右席位镜像偏移。

工作台和情绪联动预览共用当前状态，包括 `abyssa-studio-params-v1` 已保存的立绘校准、气泡基准和角色偏移。发布默认值会深拷贝角色偏移，避免新开工作台时清空。只有完全未经调整的旧占位缓存会迁移到新表；有改动的本地快照保留。正式游戏读取仓库发布表，不读取浏览器的工作台私有缓存。

## 使用与验证

`npm run dev:studio` →「情绪联动」，或 `studio.html?mode=emotion`。每侧可选角色和触发词，显示解析结果并重播；舞台直接使用正式 `AdvStage`。立绘画布校准共用，RP 专属舞台高度参数仍只作用于 RP。

已接入洋馆日常、成长与回忆、庄园剧情、RP 双版式。洋馆四时段对白采用手工标注情绪，其他旧剧本的 a–n 无需批量改写。游戏规则、存档结构与对白正文不因联动而变动。复杂 LLM 上下文／管线仍留给 rp-style-lab；已新增[JSON主控与受限生成接口](AVG_JSON_AND_GENERATION_CONTRACT.md)，支持Provider注入、请求身份、取消／超时／过期校验。实际模型服务尚未配置；接口仅接受14个英文标准触发词，旧显示组件的别名兼容保持不变。

验证：40项相关测试通过，覆盖映射／素材、别名、主角排除、重复触发、清理、恢复、缓存与校准传递；应用类型检查、模块边界、游戏及工作台构建通过。实机抽查尤斯缇丝不悦、玛丽埃塔不悦、艾洛拉窘迫、柯萝萝困惑；其余组合由工作台逐项审美复核，不把程序检查等同于150项视觉全部验收。
