# 美术资产命名与提示词合同

定稿日期：2026-09-16。适用范围：Abyssa 全项目新增敌人、背景和地图立牌。退潮黑礁是首个按本合同入库的批次。

## 三层命名

命名必须分离以下三层：

1. **资产层（美术库 ID）**：只描述画面上有什么，不包含地名、行为或剧情。
2. **类型层（图鉴基名）**：玩家认识的物种或兵种，可跨副本复用。
3. **实例层（遭遇显示名）**：地点／阵营前缀或专属称号，只存在于内容数据。

资产层命名公式为 `［材质／装束／族群］＋［兵种／体型］`；实例层可追加前缀或称号。入库前必须同时通过两项自查：换一张地图后名字仍成立；只看名字即可想象立绘。

现有前缀族：

- `enemy.outlaw.*`：人形强盗族。
- `enemy.slime.*`：软泥族。
- `enemy.beast.*`：野兽与原生生物族；未来湿地、冻原原生怪沿用。
- `bg.*`：战斗背景。
- `map.*`：大地图立牌。

稳定的玩法定义 ID、存档 ID 和内容版本不属于资产层；它们可以继续映射到新的资产 ID，不得为了换图破坏旧档。

## 提示词与过稿视觉锚

亡命徒族必须同时具备盐渍破衫、蒙面／包头布和麻绳捆扎三项。领口袖口带灰白盐霜；护具与武器用麻绳固定，不使用金属搭扣，以区别正规军。

滩涂海兽统一使用湿亮水膜、缝隙滩泥盐霜、藤壶海藻附着，色调压在灰蓝、泥褐和暗青。生物材质必须与人形的破布、麻绳形成清晰区分。

同屏剪影必须能立即分辨：史莱姆为馒头形，礁蟹横宽低矮，藏壳海蛭为 S 形细高，强盗为人形。藏壳海蛭走“缩壳讨嫌”路线，不使用内脏可视、齿环口盘、黏膜等恐怖元素。

走私栈道的系缆桩可保留褪色红布条，作为未来黑礁走私团红头巾的纯视觉伏笔；该元素不携带额外剧情设定。背景与地图立牌还须分别遵守批次清单里的正典物、复用范围和可切割边界。

## 入库要求

- 正式文件以完整资产 ID 命名，扩展名不计入 ID。
- 敌人抠图保留原画布、透明通道、接地阴影与合法离散细节，不在入库阶段统一紧裁或身高。
- 背景保持完整取景；场景裁切和显示比例由消费端决定。
- 每批清单必须记录源文件、正式 ID、处理方式、当前接线与明确未接线范围。
- 资产层名称禁止因副本、剧情或行为变化而改名；实例显示名只能在版本化内容数据中修改。
