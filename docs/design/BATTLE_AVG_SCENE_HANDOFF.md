# 战斗与 AVG 场景衔接

状态：已接线，2026-09-29 更新普通远征开盒与返回规则。剧情使用完整 AVG；沿用既有战斗、双侧立绘、对白框和阅读栏样式。

## 演出顺序

1. 最后一击、事件掷骰与判定先完成。战斗界面向上移动并淡出（520ms）。
2. AVG 左右立绘从各自外侧进入（800ms）；对白框保持水平居中，只上浮 12px 并淡入（延迟 60ms，时长 680ms）。
3. AVG 立绘向两侧退出并淡出（460ms）；对白框下移 10px 淡出。
4. 普通远征返回已展开的战斗面板，只淡入（420ms），不再播放骰子入场；兼容回忆／教学仍使用其原有场景衔接。

普通远征仅在地图成功提交新出征后，通过 `battleEntrance: "open-box"` 播放一次开盒：菱形搭扣解开 → 两扇盒盖向外滑开 → 骰子从盒格里依次抬起、恢复当前姿态 → 行动栏出现。沿用结算收盒的结构和皮肤，替换旧的骰子落下／弹跳。首次开盒的全部参与动画结束后解除输入锁定；减少动态或切到后台直接落定。

刷新、读档、浏览器返回、其他页面返回远征均只淡入。`SceneSequence` 记录本次挂载是否已展示战斗；进入 AVG 再回来不重新开盒。若读档落在 AVG 中，恢复标记继续传到下一次战斗显示。开盒不改骰面、不自动掷骰、不写游戏进度。

退场完成才挂载下一场景。期间锁定鼠标、键盘与阅读推进；非活动场景不保留战斗特效或骰子渲染。角色表情与背景在入场前预加载，不再让五官后补。系统减少动态效果设置使用即时切换。

教学关 AVG 换景（含段内移动与返馆）通过 `SceneFrame.backdrop` 接入同一个场景序列：旧画面淡黑 360ms → 黑幕完全遮住后更换背景、对白与地点 → 黑幕停留 140ms → 淡入 420ms。期间锁定点击、跳过和键盘推进，不重播整场人物入场；同一背景内逐句阅读不触发黑幕。读档直接恢复当前地点，不先显示上一地点。

**对白框定位约束**：`transform: translateX(-50%)` 归布局；入退场必须使用独立 `translate`。否则动画覆盖水平定位，结束时会横跳半个框宽。

## 覆盖范围

- 庄园迎宾簿、席位记录、遗物整理的开场与结果对白，第三层出口。
- 整理伙伴选择、ROLL、骰面判定和数值结果仍使用战斗操作区。对白完成返回该区，不替代规则操作。
- 首通「家宴落幕」五个阅读节点，含解线、离席、合簿与回馆。
- 回忆开场、教学、实际战斗、战后与当下对白。历史旧存档继续读取对应版本脚本。
- 数值结算及系统选项继续沿用原组件；剧情不经过结算弹窗。

## 存档与边界

回忆继续使用已有的 `read-memory`、`advance-memory` 和当下故事命令。首通继续使用原有五个 `acknowledge-story` 节点，不改变奖励和解锁条件。

事件对白及首通节点内的分句游标只存于标签页 `sessionStorage`，键包含档案、epoch、运行与房间身份，最多保留 64 项。刷新可续读；换设备或新标签可重读当前场景，不重复结算。正式游戏存档仍只认已提交的选择、骰面、结果与原有故事节点。回顾不发奖励命令。

`ManorBattleBinding` 持有同一个战斗演出队列，`ManorBattleView` 只负责原战斗页面。`SceneSequence` 留住退场画面的数据快照；`MemoryStory` 支持固定记录快照，避免实时存档更新提前卸载最后一击或最后一句。
