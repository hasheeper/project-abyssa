# 洋馆玻璃与远景材质处理

这是一道离线、可重现的 PNG 材质处理，不增加运行时画布、滤镜或分层 DOM。

## 原稿与产物

- 原 PSD：`/Users/liuhang/Downloads/abs素材/map.psd`，未修改。
- 原始导出：`public/mansion-map/manifest.json`、`layers/layer-XX.png`、`composite-reference.png`，全部保留。
- 当前游戏：`manifest-materials-v1.json` 引用 10 张局部处理的 `*-materials-v1.png`，其余图层仍用原文件。图层尺寸、坐标、顺序、显隐不变。
- 备用合成图及房间缩略图：`composite-materials-v1.png`，避免降级时又出现白昼玻璃。

## 处理范围

`scripts/mansion-materials.json` 存放以原图层像素为单位的局部蒙版。蒙版与颜色、明度选区相交，只修改玻璃里的白昼底色。

- 房间与天窗：最透明处仍保留约 **40%** 原玻璃底色，带淡灰白填充，不做成空洞；边缘原有线稿和反光保留。
- 温室：保留约 **50%** 底色；蓝、黄两株发光植物、花盆明确排除。
- 围墙：只减轻偏白的蓝灰亮部，透明度保持不变。
- 远景树冠：轻度压低泛白亮部，最多减少 6% 不透明度；树干、暗线不处理，区域边界软化。
- 不修改房间布局、家具、灯光坐标、天空算法及加载时序。

## 重建与检查

需要 Python、Pillow、numpy。重新从 PSD 导出后，运行：

```sh
python3 scripts/prepare-mansion-materials.py
python3 scripts/prepare-mansion-materials.py --check
python3 -m unittest discover -s scripts -p test_mansion_materials.py
```

每次都从原始 PNG 重建，不会在已处理图上重复叠加。`--check` 比较生成像素、备用合成图及清单。调整后刷新页面以清除已解码图片缓存。

回退只需把 `mansion-assets.ts` 的两项文件常量改回 `manifest.json`、`composite-reference.png`；原文件无需恢复。

## 海水的时段处理

`src/apps/mansion/mansion-water.ts` 在原有离屏合成内，对左下角 **1176 × 330px** 的水域做一次局部像素调色，然后继续统一编码成一张完整图片。没有新增常驻画布、图片请求、动效循环或可见叠加层。

- 晴天白昼完全跳过，像素保持原样；天气预览下的多云、阴雨白昼使用冷蓝灰水体。
- 晨间为冷蓝水体及少量漫反射暖色。
- 黄昏为蓝紫水体，朝夕照方向的原有波峰带克制铜色。
- 夜晚为深蓝水体，限制浪纹的冷色亮度并压低深处反射。
- 水域岸线范围与原图青蓝色选区相交，避免修改木船、绳索、码头、岩壁；水里的船和岩壁倒影则随水体调色。

它依据原画明度保留波纹，不新增直线反光条、月亮倒影或全区域白雾。海水调色可通过移除 `mansion-scenery.ts` 的 `paintMansionWater` 调用单独回退，不影响玻璃处理。

## 四时段云层与慢速漂移

`mansion-cloud-texture.ts` 共享多尺度噪声、形变与云团构图。晨间、白昼、黄昏沿用夜晚的疏密与絮状边缘，分别采用灰紫暖边、冷白蓝灰、藕紫铜色，而不是几条重复的云带。

- 页面首次生成一个随机种子，改变云团位置、尺度、倾角及细节；同一次访问的四个时段沿用同一构图，切换时不重新抽签。
- 云团在提前跳过的密度阈值之前连续淡出，消除程序引导轮廓的硬切边；相邻云团的受光方向连续加权，避免重叠处换色断线。
- 完整建筑、玻璃、海水、灯光仍一次性编码、解码成不透明底图，不做逐帧重绘。
- `mansion-sky-motion.ts` 额外预备两张已解码图片：纯天空底色和带左右各 320px 余量的小尺寸云纹理。只在建筑首个像素以上的露天天空内，通过 SVG 向量轮廓裁切显示；窗户、塔楼洞口及室内保持在稳定底图中。
- CSS 以约 210～300 秒单程、平滑往返的速度平移云纹理，最多 220px 世界坐标。每帧不重新生成噪声、不编码图片、不更新 React 状态，不对整幅洋馆使用滤镜、混合模式或蒙版。
- 页面隐藏、过场未完成、模态界面开启、拖动地图时暂停。减少动态效果偏好下保留静态天空；动态层准备失败也保留完整静态底图。
- 卸载会移除可见性监听、取消动画并释放额外的图片 URL；所有准备用的画布在发布前释放。

原始 PSD、导出图层及上述玻璃/海水处理不受云层动效影响。

## 临时天气预览

时段栏下方的「天气调试」按钮可选晴天、多云、阴天、雨天。状态只存在于当前洋馆组件内，刷新或离开后重置晴天；不写存档、不推进日期或时段，不影响资源、人物日程或游戏规则。四个时段各自保留相应天气的色调。

- 多云：扩大不规则云团、增加云量，保留天空缺口及少量透光。
- 阴天：连续但有絮状厚薄变化的灰蓝云底，移除直射散光与夜晚星星。
- 雨天：更冷的低天光、两层长短/速度不同的细雨丝，以及压低晴天反射的海水；不加全屏雾、闪电或镜头水滴。
- 雨丝复用建筑轮廓裁切，只落在露天区域，不穿过屋顶、房间、玻璃。两条预生成 SVG 路径沿相同的周期向量平移，循环接缝不重新随机，始终没有逐帧绘制画布。暂停及减少动态效果规则与云层一致。
- 天气更换复用整图准备/遮盖/发布流程，并以天气图标取代时钟过场。旧图保留到新图完成解码；天气只作为绘图缓存键的一部分，不通过实时全图 CSS 滤镜切换。

相关实现：`mansion-weather.ts`、`mansion-rain.ts`、`MansionWeatherDebug.tsx`。临时入口日后可直接移除，天气参数与时段渲染相互独立。
