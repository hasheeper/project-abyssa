## 一、货币定义

| 单位 | 系统记账 | 兑换 | 定位 |
| :--- | :--- | :--- | :--- |
| **铜里拉（G）** | ✔ 唯一系统单位 | 1 G | 账簿、滚轮、标价、结算全部用它 |
| 银里拉 | ✘ 不入系统 | 100 G | 口头流通单位；角色嘴里的“银币” |
| 金里拉 | ✘ 不入系统 | 10,000 G | 口头大宗/储备单位；公款文书的“金” |

- `economic_lore.txt` 中“1 金里拉＝100 银里拉＝10,000 铜里拉（即 10,000 G）”**维持不变**，不修改设定。
- 补写一条：**“系统与账簿以铜记账，凡人口头以银计价，国家文书以金计价。”**

## 二、铁律：系统单位 ≠ 口头单位

1. **UI、账簿、商店标价、战斗滚轮、结算面板：一律显示 G（铜）。**
2. **角色台词：永远说银与金，禁止说“G”“金币”。** 缇比报价“四枚银币”，界面显示 400；公款文书“四十金”，账簿显示 400,000。
3. **玩家看数字，角色说人话。** 两者不需要在同一句里同时出现。
4. 标价允许零头（380、260），不做清一色整百。

## 四、公款（维稳公款）定稿

### 4.1 结算方式

- **不按出征结算，按考核周期结算。** 周期＝7 天（28 相位）。
- 审计方：人类摄政府机要（西岸事务）＋ 深渊四席。
- 考核三指标：魔王安眠水位 / 结界完好度 / 裂隙与邪教活动压制。

### 4.2 单次拨款

| 结果 | 文书口径 | 账簿 G |
| :--- | :--- | ---: |
| 断供（政治博弈/考核崩） | 0 | 0 |
| 及格 | 十五到二十金 | 150,000～200,000 |
| 常态 | 四十到六十金 | 400,000～600,000 |
| 优异（含王庭岁贡） | 一百到一百二十金 | 1,000,000～1,200,000 |

### 4.3 支出项（仅限）

| 项 | 文书口径 | G |
| :--- | :--- | ---: |
| 结界大修一次 | 十到三十金 | 100,000～300,000 |
| 房间升级一档 | 二十到八十金 | 200,000～800,000 |
| 外围驻军月饷 | 十五金 | 150,000 |
| 四天王宴席/酒 | 五金起 | 50,000+ |

### 4.4 硬闸门

- **公款不得购买战术补给，不得转入小队资金。** 私款经济独立。
- 私款反哺公款（断供时）允许，方向单向。
- “挪用公款”若日后开放，为带政治代价的独立系统，不在本定稿。

### 4.5 两本账的刻度

- 单趟私款 ≈ 常态公款的 1/30～1/50。
- 一个周期私款总和 ≈ 常态公款的 1/3～1/2。
- 维持 1.5～2 个数量级差，不得缩小或放大。
