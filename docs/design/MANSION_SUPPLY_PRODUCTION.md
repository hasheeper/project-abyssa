# 洋馆补给来源与旧物品对应

日期：2026-09-25。状态：来源关系已在内容25／26实施。参数、兼容与验收见[实施报告](../audits/2026-09-25-mansion-facilities-implementation.md)；内容27／28在此基础上接入公款修缮与升级，见[设施合同](MANSION_FACILITIES_AND_UPKEEP.md)。

用户第一轮澄清：“原本的设计是，洋馆这些生成补给品，而不是自动产生补给品”；旧道具名需要与现行道具重新对应。第二轮明确：药水最好由商店补给，药水是二次合成物，温室提供原材料，洋馆须有承担合成的房间。

因此撤销上一稿“温室直接产药水、净光草只留在描写”的建议。保留原材料与成品两层；房间落位使用现有工坊。首份配方为药草×2＋100 G辅料费→药水×1，用时1时段；SHOP药水260 G。

同日后续已补写[基础设施、修缮升级与产出周期建议](MANSION_FACILITIES_AND_UPKEEP.md)：首次修缮、等级升级、受损维修分开；三档能力、厨房／温室周期、工坊订单、储藏室携带位、女仆工作间工程减费均有建议基线。三档能力已实施并做短期采样，长期配平留待更完整的时间压力与建设经济。下文已同步撤回未获确认的“结界室直接产护符”建议，结界室先归结界观测与维护。

实施参数与非视觉验收见[设施报告](../audits/2026-09-25-mansion-facilities-implementation.md)。内容25／26的设施报告是生产链的历史验收；当前施工与拨款规则以设施合同为准。

## 1. 已明确的来源关系

正式目标流程为：

**厨房等设施生产成品 → 成品库存 → 出征取用。**

**温室产原材料 → 原材料入库 → 工坊按配方加工 → 成品库存 → 出征取用。**

**商店购买成品 → 成品库存 → 出征取用。**

三条来源在成品库存汇合，随后统一进行战斗消耗与剩余返还。原材料不能直接放入战术补给位。

- 洋馆设施分别承担原料生产与成品加工；设施状态、生产周期和产量决定可以取得多少。药水属于加工后的成品，不由温室直接收获。
- 出征只取库存，不再凭一次出征补满食物／药水。打开商店、切换整备、读档同样不产生物品。
- 种植等生产由游戏时间驱动，到期完成；合成须选择配方与数量、消耗真实材料，不因查看工作台自动发生。当前为一单一时段、完工领取，首版不排自动循环队列，详见基础设施稿。
- 药水以商店购买作为基础供应，馆内合成作为利用原料取得成品的另一条途径。药水随商店开放成为常驻商品，不进入九件装备的随机货池，也不要求先修好工坊才能买药。无每日售罄限制，受资金与馆内库存容量限制；售价260 G。
- 商店购入和工坊制成的药水共用`item.potion`、名称、恢复2点生命的效果和既有单次携带上限；只记录来源差异，不分裂为两种强度或两种库存道具。
- 一次性的教程奖励／跳教程奖励继续是明确的初始资产。它们不成为每次出征重新领取的理由；教程脚本的专用教学配给单独保留边界。

内容25／26的[出征实现](../../src/game-core/session/d5-economy.ts)按玩家所选数量扣减馆内库存，SHOP药水已接入同一库存。旧内容继续按原配给规则运行，不在读档时转成新版。

## 2. 旧产出名对应现行道具

以下是本次整理的对应方案；“直接对应”来自现有名称与效果，“产出调整”是工作建议，不冒充旧稿已明确写过的配方。

| 旧设施／产出 | 现行对应 | 处理性质与边界 |
| --- | --- | --- |
| 厨房：热食／备餐，`hot-meal` | **食物**，`item.food` | 直接对应基础恢复补给，恢复1点生命。生产、库存、整备、战斗统一叫“食物”；热食可用于生活描写，不再另占一个道具定义 |
| 温室：净光草，`clearlight-herb` | **净光草，原材料** | 保留旧名称及实际物品身份，接入材料库存；不改名为药水，不直接提供治疗效果。哪些草药用于治疗药水、需要多少，由配方表另定 |
| 现行补给：药水，`item.potion` | **药水，合成成品** | 商店销售；工坊按已解锁配方消耗材料制成。恢复2点生命，沿用现行道具身份 |
| 工坊：保养工具，`maintenance-kit` | **保养工具**，`item.maintenance-kit` | 直接对应，统一身份；清除角色一面的本趟临时锈。不能写成修复装备耐久、永久锈或提升装备等级 |
| 储藏室：外围补给，`outpost-supplies` | **原材料／成品库存与携带位职能** | 旧名是抽象物资批次，没有一个现行战术效果可直接对齐。建议撤掉独立产出，储藏室承担储存／出征整备与4→5→6携带位成长；不把“外围补给”强改成某一瓶药或礼包 |
| 结界核心室：结界记录，`ward-records` | **结界观测信息** | 后续基础设施稿撤回直接改成护符的提案；记录留在房间／日志，不作为战术补给。护符保留现行商店来源，未来加工须另有配方 |

现行名称与效果以[道具展示定义](../../src/content/presentation/supply-icons.ts)及[核心使用规则](../../src/game-core/session/demo-items-events.ts)为准。旧产量2／3／1不是新配方比例，三束草不自动等于三瓶药。净光草已有擦拭法杖等设定，不能仅凭药圃位置就断言它是治疗药水的唯一原料；具体用途在配方收口时核对。

## 3. 七种补给全部归位

| 现行补给 | 洋馆接线方向 | 商店关系 |
| --- | --- | --- |
| 食物 | 厨房生产 | 现行无出售条目；取消出征自动生成后由实际库存提供 |
| 药水 | 工坊二次合成，消耗已入库材料 | 基础常驻成品补给，260 G／份 |
| 保养工具 | 工坊按配方加工，材料表待定；不沿用自动发工具 | 已有600 G／份购买来源可以并存 |
| 护符 | 首批不分配自动产出设施；未来有配方再接加工 | 保留现行400 G／份购买来源 |
| 圣水 | 旧五项产出没有明确对应设施，暂不指定 | 保留现行300 G／份购买来源 |
| 幸运符 | 旧五项产出没有明确对应设施，暂不指定 | 保留现行800 G／份购买来源 |
| 卦签 | 旧五项产出没有明确对应设施，暂不指定 | 保留现行300 G／份购买来源 |

后三项没有对应并不表示永久只允许商店出售，也不表示洋馆必须一次生产齐七种。后续若扩合成配方，再定义材料与解锁条件。净光草等原料另属材料库存，不因为新增合成就变成第八种战术补给。

## 4. 承担合成的房间

**房间方案：使用现有`workshop`工坊，承担成品加工；第一批新增制药工作台。** 现有工坊承担加工，不将地图区域另改名为药房；药锅／蒸馏器等设备美术仍待补充。

| 空间 | 负责什么 | 玩家得到的结果 |
| --- | --- | --- |
| 温室药圃 | 培育、收获药草原材料 | 实际材料库存 |
| 工坊 | 选择配方与数量，消耗材料，制备成品；保留原有工具加工职能 | 药水等实际成品，不因房间开启自动发药 |
| 储藏室 | 保管材料、成品；管理出征取用与携带位成长 | 看清能加工多少、能带走多少 |
| 商店 | 直接出售现成药水与现有战术补给 | 花小队资金取得成品，无须自行备齐原料 |

现有[工坊定义](../../src/apps/mansion/data.ts)有炉台与工具基础，可以先以功能子区承载制药，不需要立刻扩一张地图或改人物卧室用途。原房间美术目前未证明存在完整制药设备；实施时登记药锅／蒸馏器／药瓶架等工作台美术需求，不能把现有锻造图当作药房已经完成。

首批合成只围绕现有药水建立最短流程：**选药水配方 → 显示材料需求与持有量 → 选择数量 → 确认加工 → 成品入库。** 不增加随机失败、品质抽奖、中间半成品或一串空配方来撑系统。

升级收益应与职能相连：温室影响原料供给，工坊影响加工批量，储藏室影响储存／取用能力。具体三档收益已有基础设施稿的建议表；配方取得与工作台能力分别判断，设备解锁与材料扣除都须持久保存。

## 5. 与装备、槽位和拾获的边界

- **生产的“补给”是消耗品。** 第一波九件通用装备仍按SHOP日期投放与限购。应急药囊和磨刃石改变骰面；药水和保养工具消耗库存执行一次效果，不能因外观或名称相近而混为一类。
- **仓库存量、单次携带量、携带种类位是三件事。** 原料和成品均有真实库存；只有成品补给可按携带上限取出；储藏室4→5→6指可带的种类数，不是每类数量，也不是仓库页面格数。
- 内容25／26已拆分馆内容量与单趟容量；成品上限为单趟上限的3／4／6倍。满仓保留待领，出征返还和订单预留空间，不照搬旧原型的无上限累加。
- 由馆内带入的补给沿用消耗与剩余返还规则。副本中新拾获的战利品保留本层未入袋／已入袋结算机制，两者不因同在库存界面而混用损失规则。
- 新增材料及配方不自动把现有十二种出售用战利品全部变成合成材料。后续选择哪些掉落物可入配方，需明确留用／出售取舍及实际消费规则。
- 合成必须保证扣除材料与交付成品一致，重复提交不能多扣或多发；先检查并预留成品空间，再启动加工。计时加工按基础设施稿的一单一配方、完工领取和首版不可取消建议处理。
- 旧原型的品质色不能直接给战术补给增加等级效果。复用现行食物、药水等图标与说明，不保留两套名字、身份和效果。

内容25／26对应储藏室Lv.1／2／3的4／5／6类携带位；[历史携带位](../../src/game-core/contracts/journey-limits.ts)继续服务旧档，现行27／28房间费用见设施合同，旧档不缩容。实际库存与出征限制见[机制总览](../GAME_SYSTEMS_AND_CONTENT_SPEC.md)。

## 6. 已落地与后续范围

- 厨房／储藏室在自由行动开始具备Lv.1能力；现行27／28在第2／3／4日分别开放温室、工坊、女仆工作间的公款首次修缮；旧25／26仍可免费启用。
- 温室提供药草与净光草两种原料。首份药水配方只用药草，净光草不直接治疗，不冒充药水材料。
- 基础备餐与种植只占用游戏时间，不暗扣任何账目。合成需真实材料与辅料费，成品必须领取。
- 收取、购买、加工、领取、部分数量出征与返还均有可重放事实；满仓保留待领，打开页面与现实时间不产物。
- 内容27／28已接修缮付款与两档升级；后续损坏维修、保养工具材料配方、高级研究尚未开放。制药设备美术未定稿，现阶段复用房间背景与既有物品图标。
