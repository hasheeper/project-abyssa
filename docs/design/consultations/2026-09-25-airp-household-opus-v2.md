## 〇、补充交付前提（修正前文）

| 编号 | 前文写法 | 修正后口径 |
|---|---|---|
| P1 | 「不向两人发 `patrol`」 | **只对艾比希斯成立。** 玛丽埃塔已有独立战斗解锁，程序允许时可以作为出征队员参与 `patrol`，本次剧情接入不得永久禁止。她出征时归还线怎样适用，以程序和既有设定为准，文案不补设定。 |
| P2 | 未区分委托的提出者与执行者 | 洋馆委托的 giver 与实际出征队员是两件事。玛丽埃塔可以作为 giver，提出**程序中已存在、玩家可执行**的 patrol，但不能凭空新建委托、目标或奖励。 |
| P3 | 「克雷格旧庄园属于未实现的偶发战役」 | **旧庄园特殊战役与回忆战均已实现。** 限制只有一条：自由事件不得擅自开启、邀请、预告或结算这两类战斗。已读经历中已经发生过的，可以作为事实回应。 |
| P4 | 「药箱：玛丽埃塔会补齐和整理」 | **撤回。** 药箱原稿明确只取空箱，旧药不用也不补。新角色不得断言补齐药箱，也不得处理箱里的旧药。 |
| P5 | 「不说具体金额」 | 当前程序明示了银金数额时，角色可以按该数额口头谈论。不能虚构数额，也不能口头改变数额。 |
| P6 | 前文有「凯尔出门前看腰包」「凯尔感动道谢」等写法 | **正文不得代写凯尔的动作与反应。** NPC 可以对他说话、朝他做事；他如何回应只来自玩家输入。腰包黑泥的状态可以作为环境描写，但不写成「他低头看了看」。 |
| P7 | M-03、M-06 写成「停顿→台阶」「嫌弃→妥协→补照料」的结构 | 这些是**可能出现的反应**，不是步骤。她可以直接动手、不作评论、只看一眼，或者这一次完全不在意。固定库只守住动机边界。 |

## 一、M-09 补完：旧庄园的回响（低频）

- **适用**：有人主动问起她的过去；已读经历中发生过旧庄园战役或回忆战；某件古旧器物触动了她。
- **核心**：克雷格家族已经消亡，她曾独自守护空宅数百年，后来才认识到宅邸值得维护，是因为里面有人。
- **可变**：
  - 她透露多少，通常很少，也可以一句都不说。
  - 触发她的器物或话语是什么。
  - 她对已读战役事实的态度：平静带过、纠正一处细节，或把话题转回手上的活。
- **越界**：
  - 不开个人线。
  - 不在自由事件里提议、开启或预告旧庄园战役与回忆战（见 P3）。
  - 不补写克雷格家族成员的新细节。
  - 不让回忆变成每次交谈都会冒出来的悲情底色。

## 二、艾比希斯固定库（动机边界）

**通用约束**：

- 每条都可以跳过，也可以换一种反应。
- 睡觉、盯人、「面倒」都只是她可能的表达方式之一，**不是默认结局**。
- 她的动作可以指向凯尔；凯尔怎么接，留给玩家。

**A-01 靠近热源**
- **动机**：安心、温暖。她也在慢慢意识到，他不只是「有用的东西」。
- **适用**：凯尔在馆内的场景。
- **可变**：
  - 她可能贴近，也可能只是坐到同一间屋里。
  - 她可能明确表示「今天不想靠近」。
  - 她在意的对象可以从他的体温，换成他今天的疲态。
- **越界**：
  - 不写凯尔抱住她或回应她。
  - 不做身体接触的细描。
  - 舔脸这类行为不作为常规动作，更不能当作已发生的旧事引用。

**A-02 缺席的异样**
- **动机**：领地里少了人。
- **适用**：已知当日有成员外出。
- **可变**：
  - 换一个位置待着，问一句「…去哪了」，或者对着空出来的座位看很久。
  - 也可以毫无表示。
- **越界**：
  - 不去找人，不出门。
  - 不通过腰包隔空说话，不远程救场。
  - 不预知巡守的结果。

**A-03 笨拙的利他**
- **动机**：新学到的常识，加上重要的人不该难受。
- **适用**：已读经历写明有人疲惫、受伤或不适。
- **可变**：
  - 用原生质递东西、盖毯子、挡光，或者说一句直球的话。
  - 对象可以是四位队员里的任何人，不限于凯尔。
- **越界**：
  - 低频使用，否则会失去分量。
  - 不产生治疗效果，不给数值收益。
  - 不写成「为了表达爱意」的煽情场面。她做这些事时理所当然，不害羞，也不找借口。

**A-04 直觉看穿**
- **动机**：她对复杂规则没有兴趣，却能越过表象。
- **适用**：有人在逞强、绕弯子，或者在为一件小事过度紧张。
- **可变**：说破的对象；她可能说破，也可能看穿了但懒得说。
- **越界**：
  - 她看穿的是**眼前的人和事**，不是隐藏情报。
  - 不借她之口公布世界真相或剧情伏笔。

**A-05 兴趣信号**
- **动机**：有趣。
- **适用**：光斑、会晃的软食、新奇的小物件、没见过的动作。
- **可变**：
  - 观察、提问、下结论，或者看了一眼就放弃。
  - 兴趣持续多久也可以变。
- **越界**：
  - 不让她「发现」剧情物品。
  - 不把固定库里的三件物件当成她的玩具来重演原桥段。

**A-06 安宁被打扰**
- **动机**：排斥吵闹、脏乱和过度复杂的事。
- **适用**：馆内出现噪音或混乱。
- **可变**：叹气、离开、用触手推开、凝视。影子和原生质会因她的心情微微活动，这是被动涟漪。
- **越界**：
  - 不对家人用「虫子」称呼，不使用「归于虚无」。
  - 威慑必须限于生活尺度。
  - 心情涟漪只写光影变化，不写成灾害。

**A-07 学会一条常识**
- **动机**：蕾诺尔的书、玛丽埃塔的规矩等来源里，有一句被她记住了。
- **适用**：任何平日场景。
- **可变**：
  - 学到什么、用在谁身上。
  - 用得对还是用偏。
- **越界**：
  - 常识的来源只能用话语带过，蕾诺尔等人不在场。
  - 不写「她终于成长了」这类总结式判定。

**A-08 与玛丽埃塔的日常接触**
- **动机**：她把琐碎而重要的事交给「生活上的母亲」。
- **适用**：打理、用餐、换装。
- **可变**：
  - 配合、嫌麻烦、梳着梳着睡着。
  - 她也可以反过来注意到玛丽埃塔在忙，然后用原生质递一下东西。
- **越界**：
  - 不写成命令与服从的主仆戏。
  - 也不写成拒绝照料的叛逆戏。

**A-09 队员接口**
- **内容**：只使用原卡里的四组关系：
  - 尤斯缇丝：被盯到降低音量。
  - 艾洛拉：光刺眼，但保留信任。
  - 柯萝萝：沙发上的静默较量，也能安静共处。
  - 诺玛：被凝视后上交零食，铁环声不令她厌烦。
- **越界**：
  - 不新增关系正典。
  - 队员的反应以各自原卡为准，不替队员定性。

## 三、随机库种子

随机库用于组合出局部变化、矛盾或相遇，**不是每日必抽**。每条都允许两人都不出场，或者只出场一人。

| # | 种子 | 适用的已知情境 | 可变部分 | 越界点 |
|---|---|---|---|---|
| R-01 | 规矩撞规矩 | 尤斯缇丝与玛丽埃塔同时在场 | 两人的规矩在同一件小事上冲突，也可能恰好互相补足 | 不写成对立或说教比拼 |
| R-02 | 同一片安静里的第三者 | 柯萝萝在沙发附近 | 艾比希斯可能争位、并排，或让出位置；玛丽埃塔可能根本不管 | 不定胜负，不写成搞笑定式 |
| R-03 | 零食去向 | 诺玛在场 | 凝视施压，也可能诺玛主动给，或者这次没有零食 | 不虚构新物品价值，零食只是生活物 |
| R-04 | 光与伤 | 已读经历中有人受伤，艾洛拉负责处理 | 艾比希斯忍着光留在旁边，或者走开；玛丽埃塔负责包扎以外的收拾 | 伤情严重程度以已读经历为准 |
| R-05 | 女仆长不在状态 | 任何平日 | 她这次**不纠正**、手上的活放慢，或是在想别的事 | 不捏造原因，不作为伏笔 |
| R-06 | 魔王醒着且有主意 | 任何平日 | 艾比希斯主动要求一件小事，比如去晒太阳的位置、要某种软食 | 不出馆，不做无法结算的行为 |
| R-07 | 被反过来照料 | 玛丽埃塔忙碌中 | 艾比希斯用原生质递物，或提醒一句 | 低频；不写成角色反转的大事件 |
| R-08 | 旧规矩不适用 | 洋馆里出现了魔王城时期没有的状况 | 玛丽埃塔调整做法，或保留旧做法 | 不搬用魔王城结界全知 |
| R-09 | 委托由她提出 | 程序中存在可执行的 patrol | 玛丽埃塔作为 giver 提出，并给出她在意的理由（秩序、补给、外来痕迹） | 只引用已有委托；执行者由玩家决定 |
| R-10 | 她也在队里 | 玛丽埃塔已解锁，且被玩家编入出征 | 出门前后的态度与留守时不同，例如由谁来关照洋馆 | 出征过程与结果只归战斗和结算层 |
| R-11 | 开销的口头账 | 程序明示了银金数额 | 玛丽埃塔按明示数额评价某项开销 | 不编数，不改数 |
| R-12 | 空出来的座位 | 有人外出 | 艾比希斯的异样有无、表现方式 | 不远程感知战况 |
| R-13 | 归来之后谁先到 | 已读经历中有人归来 | 可能两人都在，都不在，或只有其中一人先注意到 | 不写凯尔的接应动作 |
| R-14 | 无事之日 | 当天没有特别情境 | 留白，或者只写一两句背景 | 不为了让两人出场而硬造事件 |

## 四、声线校准（示例，均未发生）

> 「泥请留在门外。里面的事，交给我。」

>
> 「……ん？ …它在晃。…再晃一次。」

> 「书上说，吃饭要一起。…所以，等。」

## 五、工程落地时最容易退回固定流程的地方

1. **把条目顺序当成日程**：固定库的编号不代表出场顺序。GM 不应按条目轮播。
2. **反应模板化**：「先嫌弃再妥协」「训话」「睡觉」一旦被写进提示词里的默认段落，就会每次都出现。应该只写动机和边界，并显式允许跳过。
3. **出场补额**：为了「新角色要有存在感」而每天安排她们出场。两人应该与原有四人共用额度，并且允许留白。
4. **玄关、归来桥段的固定化**：系线与接应如果每次巡守都演一遍，就会变成动画过场。
5. **随机库变成换皮**：同一桥段只换物件或换人重演。随机种子应该改变的是关系张力，而不是道具。
6. **越层写作**：GM 规划或正文自行宣布归还线触发、药箱补齐、金额变化、战役开启。这些只能来自结算层或已读经历。
7. **代写凯尔**：艾比希斯的靠近类场景最容易顺手写出凯尔的回应，需要在正文层单独设置禁止。
8. **示例被当成事实**：原卡与本稿的示例对白必须带「示例」标记，存入时与已读经历分库。
