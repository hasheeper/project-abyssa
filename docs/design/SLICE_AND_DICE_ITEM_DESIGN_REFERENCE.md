# 《Slice & Dice》道具设计参考与 ABYSSA 商店映射

日期：2026-09-24。状态：参考研究，非商品定稿，未改游戏代码、价格或存档规则。

对应问题：在现有角色引擎上，商店除了五种战术补给，还能提供什么有意思的购买选择？本篇承接[SHOP 日期货架与交易合同](SHOP_SCHEDULE.md)。

## 1. 研究结论

**最值得借鉴的是「装备改变角色六面如何工作」：同一件物品给不同角色，会得到不同用途；简单效果可以与原生骰面、其他装备和队友形成组合。**

这比增加一批只换名称、恢复量和伤害量的消耗品，更适合 ABYSSA 已有的六面／战面／铭约结构。商店扩充应先提供可比较的配装选择，然后再逐步加入触发型小件。

但两款游戏的经济循环不同。Slice & Dice 的官方介绍是五名英雄、20关、战后升级英雄或获得物品、单场失败重开；ABYSSA 有持续角色、馆内持有、出征准备和 G 交易。可以借装备的设计方法，不能直接照搬其物品等级、奖励密度、价格或整套组合规模。

## 2. 已核实到的具体设计案例

中文仅作释义，保留英文检索名；「资料记载」与右栏设计分析分开。

| 物品／来源 | 资料记载的效果 | 可借鉴的设计点 |
| --- | --- | --- |
| [Worn Arms](https://slice-and-dice.fandom.com/wiki/Worn_Arms) | 顶面、底面分别替换为伤害2、护盾2 | 一件物品提供两种基础用途；替换的是面位，不保证原来是空面，因此可能补弱，也可能覆盖强面 |
| [Twin Daggers](https://slice-and-dice.fandom.com/wiki/Twin_Daggers) | 顶面、底面替换为伤害1＋Cantrip；该页说明掷到时对前排随机目标造成伤害，与重掷配合 | 不靠大数值，改变收益发生的时机；重掷从纠正坏结果扩展为争取再次触发 |
| [Cloak](https://slice-and-dice.fandom.com/wiki/Cloak) | 中间面替换为躲避敌方攻击／效果的动作 | 给角色增加一个有选择时机的防御面，与永久闪避率是不同设计 |
| [Pendulum](https://slice-and-dice.fandom.com/wiki/Pendulum) | 交换左面与中间面 | 单独看未必增加总力度，但能改变面位限定装备作用在哪个动作上；价值来自组合关系 |
| [Toy Sword](https://slice-and-dice.fandom.com/wiki/Toy_Sword) | 最右面替换为伤害0；词条的策略说明提到可由其他物品提高伤害 | 「零伤攻击」仍是攻击类型，与空面不同；弱效果可以成为另一条规则的作用对象 |
| [Glass Helm](https://slice-and-dice.fandom.com/wiki/Glass_Helm) | 最大HP＋3，但角色死亡后无法复活 | 好处与明确代价成对出现；玩家需要判断队伍是否承受得起代价，不是无条件升级 |
| [Iron Pendant](https://slice-and-dice.fandom.com/wiki/Iron_Pendant) | 装备者收到的护盾＋1，来源不限 | 装备的价值可以来自队友；保护脆弱角色不一定要提高其自身输出 |
| [Infused Herbs](https://slice-and-dice.fandom.com/wiki/Infused_Herbs) | 底面替换为治疗2，并带 regen、cleanse、mana-cost | 同一基础动作可以同时携带收益与成本；不是每加一种效果就必须造一套独立操作 |

这里的顶／底／左／中／最右是 Slice & Dice 的骰面排布位置，不能直接翻译为 ABYSSA 的命数点数。

### 2.1 为什么缺点也能成为配装资源

上述 Steam 指南用英雄 Dice 展示了一个完整例子：其面值力度高，但角色给各面施加 Lucky，使力度每回合发生随机变化。

指南记录了两类应对：

1. **Blindfold 清除词条**：去掉 Lucky 的不稳定，同时也失去护盾面的 Cantrip。取得稳定性要放弃一种有利能力。
2. **Ice Cube 给左面 Stasis**：阻止该面后续改变，从而保留其原力度；同样也阻止正面增益继续修改。它不是「所有坏处都免疫而好处照收」。

指南进一步记录 Ice Cube＋Ballet Shoes 的组合：先让左面不能被改写，再利用移动面位的物品形成复制结果。该指南也明确提醒 Eyepatch 等装备要注意顺序。

这组资料说明：**短规则的相互作用可以产生远大于单件文案的变化，同时要求玩家能看到最终骰面。** 本次不从这个案例推断所有物品的全局结算顺序，也不建议第一批就照搬这类复制组合。

## 3. 将案例提炼成可用的设计方法

### 3.1 先看角色的六面，再评价一件装备

一个替换装备至少要比较三件事：它改了多少面、覆盖了什么原动作、是否改变角色原有长短处。

Worn Arms 的价值不只来自伤害2或护盾2。给顶底面很弱的角色，它提高下限；给这两面已有关键能力的角色，它可能不值得装备。这个结构天然提供跨角色复用，不必所有商品都写成专武。

对应 ABYSSA：应急药囊给柯萝萝会增加三个治疗面，给艾洛拉只改一个面；凯尔和玛丽埃塔没有原生空面，当前完全不能用。不能只按「一件装备」衡量收益。

### 3.2 用小范围规则建立差异

可按以下顺序扩大规则范围：

1. 替换指定范围的普通战面。
2. 提高一个普通动作面的力度。
3. 在有条件时改变成本、收益或时机。
4. 复制、交换或传递战面效果。

前两类易解释、易预览，也容易限制作用范围。后两类能形成更丰富的组合，但需要可靠的触发次数、目标和计算顺序。不能将后两类伪装成「再填一条商品数据」。

### 3.3 稳定与爆发都应该有代价

代价不必总写成减HP。装备位置、覆盖原动作、保留空面、放弃另一个强面，都能成为可感知的选择。

ABYSSA 已有一个很好的天然取舍：诺玛的铭约需要两对，并且队伍仍有空面。补掉自己或队友的空面，能增加普通动作的可用性，却可能减少铭约机会。这里的冲突由现有规则产生，不需要先发明「诅咒装备」。

### 3.4 组合可以先来自队伍，不急于增加个人槽位

Iron Pendant 的例子是接收队友护盾；ABYSSA 则已经有治疗、防护、空面条件和队伍铭约。第一阶段即使每人只有一个通用装备位，也能围绕队伍构成产生选择。

同一人双装备的复制／词条组合属于下一层能力。若为了套用参考游戏就立刻加多槽、随机词缀、镶嵌与强化，当前五件补给的扩货会变成另一个完整系统。

### 3.5 装备预览是规则可读性的一部分

列表继续保持物品名、图标、价格等必要信息。详情选定角色后，复用已有六面展示，指出实际变化，例如「空面 → 治疗1」或「招架1 → 招架2」。不适用时解释「没有原生空面」。

只有说明「提升防护」不能让玩家判断值不值得买。要能看出覆盖了什么、改了几个面，以及命数部分是否变化；无需因此重建商店或增加多层说明面板。

## 4. 映射到当前引擎时必须分清的边界

| 参考游戏概念 | ABYSSA 现状 | 本项目的处理建议 |
| --- | --- | --- |
| pips 表达伤害、护盾、治疗等骰面力度 | `power`是战面力度；`pip`另用于命数点数／万能点数 | 引用「＋1 pip」时先解释为力度，不直接实现成命数点数＋1 |
| 指定骰网面位进行替换／移动 | 面有稳定ID与slot，同时携带命数、花色、醒眠、品质 | 首批修饰动作／力度，保留其余字段；面位与动作类型的选择规则需写清 |
| 词条操作、Cantrip、Stasis等 | 目前没有通用装备词条与被动触发系统 | 自动触发、免疫修改、复制等必须新增规则；不能只加中文描述 |
| 同一角色组合多件物品 | 配装校验至多两条全队装备记录，同一角色不得重复；当前只有通用槽 | 是否放宽全队上限需独立决定；第一批可保持单人一槽，不能宣称已有双装备组合 |
| 获得一件新装备 | 现有两件支持持久实例、归属、转交、装卸、出征冻结，来源为一次性赠物 | 购买需补交付、额外实例与限购；玩家持有列表不等于购买命令已存在 |
| 叠加HP／动作强度 | 六人基础HP均为3，特殊动作另有规则 | 不照抄＋3HP或全六面＋1；玛丽埃塔最大HP还参与提线目标阈值，影响不限于生存 |
| 改写骰面 | 沉眠只限制命数计分，仍能使用该面的战面动作 | 空面改治疗不同时唤醒、不赠送品质提升，保持已有成长价值 |

当前装备定义与校验只接受 `equipment.spare-blade`、`equipment.emergency-pouch`；替换动作只接受攻击／治疗，力度固定1，作用域固定全部原生空面。因此，连「空面转格挡1」也需要实际扩展合同与解析。

## 5. 对商店扩充建议的具体修订

以下是 ABYSSA 候选设计，不是 Slice & Dice 原物品，也不是本轮获批的商品清单。名称仅占位，售价和解锁阶段待平衡后定。

| 顺序 | 商品方向 | 候选规则 | 角色／队伍决策 | 接线状态 |
| --- | --- | --- | --- | --- |
| A | 现有两件成为可购买的配装物 | 备用短刃：原生空面→攻击1；应急药囊：原生空面→治疗1 | 同一空面范围选择攻击或续航；评估柯萝萝的多面收益与诺玛条件 | 效果已存在，购买来源与额外持有限制待建 |
| A | 防护方向的空面装备 | 原生空面→格挡1 | 补齐攻／治／挡选择，但没有空面的角色仍不适用 | 新动作映射、定义与校验待建 |
| B | 普通战面强化配件 | 装配时指定一个普通攻击面或普通格挡面，力度＋1 | 提高强项，或补最低效的一面；让无空面角色也有可买装备 | 面位选择、保存与修饰规则待建 |
| C | 角色机制小件 | 例如限制次数地降低昂贵治疗成本；保留空面时给一次小收益 | 改变既有机制的成本或节奏，保留角色身份 | 触发与计数能力待建，具体效果未定 |
| 后续 | 战面复制／交换 | 首先只允许复制普通动作与力度，保留目的面的命数字段 | 牺牲某个动作换另一类能力；避免万能复制直接吃掉角色特长 | 完整范围、顺序和预览协议待建 |

对B类要特别明确「普通」指动作种类为`attack`／`guard`，不是以文案或颜色判断。初期不统一增强顺劈、全体格挡、护卫、万能楔、提线，也不顺带提高其副目标效果。

例子：凯尔的「招架」力度1→2，和玛丽埃塔的「体面」力度3→4，虽然都是＋1，但基础体量与玩法价值不同；不可直接判定同价就同收益。这些数值只说明候选规则，没有做平衡验收。

建议沿原商店勘探的S0—S3推进，**先把A、B构成一轮可比较的候选池，再决定首发件数**。只把五种补给加成八件商品，还不能证明配装选择已足够：若新增三件都只作用于空面，凯尔和玛丽埃塔仍没有购买目标。

### 经济与掉落的分工

- 五件既有补给继续承担反复出征的消耗，不改已定稿价格来掩盖货架缺口。
- 基础配装提供积攒 G 的短中期目标；永久买断物只能带来一次性支出，不能独自解决后续资金积累。
- 更特殊的战面改造可以以后交给进度解锁或副本奖励，不要求普通店一次卖齐全部组合。
- 当前常规战利品仍走变现，鉴定品仍走既有鉴定／出售；若将来鉴定出可装备用途，需要新增明确交付类型，不在这份参考研究中自动改掉落结果。
- 本研究当时未纳入公款；后续DEMO已单独接入周一拨款与修缮升级，见[设施合同](MANSION_FACILITIES_AND_UPKEEP.md)，不用于装备采购。晶石占位保留；战备新拾获的装入／容量问题仍是独立待办。

## 6. 下一步需要定稿什么

在实施前收敛以下四点即可，无需先设计数十件装备：

1. **首批覆盖面**：空面攻／治／挡，以及至少一种无空面也可使用的普通战面强化，哪些进入首发。
2. **装配边界**：是否放宽旧的全队两件限制；单人先维持一槽还是增加第二槽。两者不能混为一项。
3. **购买边界**：赠物能否再买、每种数量、何时上架、是否允许装备转售；与新掉落入袋规则分开定义。
4. **非视觉验证**：各角色实际改动面、特殊动作不误增益、诺玛空面条件、出征冻结、交易原子性与读档一致性；平衡评估分别看角色和队伍，不能只比较商品说明。

参考研究支持的方向已经明确：**商店优先出售能调整角色战面分布的基础装备，让购买决定改变队伍打法。** 自动施法、复杂复制与词条连锁留待相应引擎能力建立后再扩。
