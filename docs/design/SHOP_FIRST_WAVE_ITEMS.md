# SHOP 第一波基础道具设计 v0.1

日期：2026-09-24。状态：第一波已接入内容23／24；九件规则、日期投放与交易已实施，价格仍为首轮试行值。非视觉验收与收益采样见[实施记录](../audits/2026-09-24-shop-wave-implementation.md)。

当前27／28继承这九件装备。补给来自设施／商店并按库存取用；工坊已接药草制药，SHOP药水常驻260 G。来源与旧名称见[补给说明](MANSION_SUPPLY_PRODUCTION.md)。原23／24的食物／药水配给属于历史版本，不再作为当前经济前提；公款不能支付装备或补给。

用户已明确的方向：第一波基础道具；按游戏日期分阶段，以固定与随机两种方式投入。本文负责物品本身，具体投放、补货与存档合同见[SHOP 日期货架与交易合同](SHOP_SCHEDULE.md)。

## 1. 首批范围与体验

保留现有五种付费补给，第一波设计**九种通用装备**：其中备用短刃、应急药囊沿用已有定义，其余七种为新增。九种不会开局全部上架，也不会自动发到背包。

这批装备解决四种购买动机：补足空面、保留部分空面、增强一个普通战面、牺牲一种动作换另一种。每人仍只有一个通用装备位，换装意味着放弃另一件的作用。

第一批不增加自动施法、复制、复合动作、专属动作迁移或随机词缀。所有物件使用既有的攻击／格挡／治疗／空面四种普通动作关系；不改变命数点数、花色、醒眠、品质、最大HP和铭约等级。

### 2.1 基础补空面：E01／E03／E04

- 短刃提高空掷时的补刀能力；药囊提供续航；软革护腕提供防护。
- 对尤斯缇丝、艾洛拉、诺玛，各改一个面；对柯萝萝改三个面。凯尔和玛丽埃塔没有原生空面，不能装这三件。
- 它们改的是战面。沉眠面改为治疗后能执行治疗，但命数仍沉眠；不额外获得唤醒或金面成长。
- 药囊的三个治疗面不等于一次投掷治疗三次，更不等于自动治疗；仍由实际掷出面及合法行动决定。

价格仅为初稿。柯萝萝获得三面改动的收益明显高于单空面角色，首轮平衡要分别测，不能只按平均面数定价。

### 2.2 保留空面：E06守夜铜铃

这是第一批随机货中最有辨识度的一件。它把一个空面改成较强的格挡，但没有抹掉全部空面。

- 给柯萝萝：可选择一个空面变为格挡2，保留两个空面；与软革护腕的「三个格挡1」形成取舍。
- 给尤斯缇丝、艾洛拉、诺玛：唯一空面变成格挡2，防护更强，但不再保留该人的空面。
- 诺玛检查的是**队伍掷出结果是否有空面**，不是背包里是否有空面装备、也不是只有她自己的空面。保留两个空面只是保留触发机会，仍需满足两对等条件。

以柯萝萝为例，仅作均匀单次掷面、无重掷与其他效果的结构比较：原生空面概率3/6；软革护腕后空面0/6、格挡面3/6且各1点；铜铃后空面2/6、格挡面1/6且2点。这不是实战胜率或装备强度排名。

### 2.3 单面强化：E02／E05／E07

三件都在馆内装配时指定一个合法面。每件只改一个面，转交后要重新指定，不能自动把力度＋1加到全部六面。

- 嵌铁护腕：凯尔的「招架」1→2，玛丽埃塔的「体面」3→4，均可使用。D2固定提供它，避免首次上新只照顾有空面的角色。
- 磨刃石：可增强尤斯缇丝的一面普通攻击，或增强柯萝萝的一个高力度攻击面；选择某个面不改变其出现概率。
- 药师针匣：可强化凯尔的普通包扎，或艾洛拉的一面普通圣光；**不作用于「越限奇迹」**，也不改变其扣款。

「普通动作」由原生动作种类`attack`／`guard`／`heal`判定，与面是否金色、是否沉眠无关。增强金面时保留原品质；锈蚀等既有规则照常解析，不因道具偷偷修复。

### 2.4 普通动作互换：E08／E09

这两件提供职责调整，转换力度是固定值，不把旧力度全部带到新动作上。

- 佣兵肩带：用一个攻击面换格挡2。凯尔可以减少攻击、增加防护面；柯萝萝可以牺牲一个高伤面保住三个空面，与铜铃的取舍不同。
- 袖藏短刃：用一个普通格挡面换攻击2。尤斯缇丝可放弃唯一普通格挡增加攻击面；玛丽埃塔可把普通格挡3换为普通攻击2，但会失去该面的高防护。
- 两者都不是额外追加动作。肩带不产生护卫，短刃不产生顺劈，也不拷贝任何角色专属效果。

转换仍保留目的面的命数、花色、醒眠和品质。详情要同时展示牺牲的原动作和取得的新动作，不能只写「获得攻击2」。

## 4. 装配与持有合同

### 4.1 一人一槽，全队上限分开处理

- 保留每人一个通用槽，不增加饰品槽或第二槽。
- 新版本放宽旧的「全队最多两条装备记录」：每个已解锁角色最多一件，当前六人即最多六条合法配置。当前出征最多五人，只让实际上阵角色的装备在本趟生效。
- 替换装备前先卸下；转交与重新选面在馆内免费，不加入转交收费。
- 远征／回忆期间沿用装配冻结，不能战斗中换成另一套效果。

### 4.2 选面与解析

指定面装备持久保存`targetFaceId`；全空面装备不携带该字段。适用性检查原生动作，不能通过装备之间的结果再转成新的合法目标。

每次解析从内容原生六面重建：应用已获得成长，再应用当前一件装备。装备只写动作／力度；临时状态按既有战斗流程处理。不在上一次已加成结果上继续加1，反复装卸不会叠加。

首次装配或转交需要明确选面，并显示变化预览。选择只在确认装配时提交；取消详情不会改配置。当前成长不改变动作类型，后续版本若会改，需要自己的失效目标规则，不擅自挪到另一面。

### 4.3 商店购买与赠物独立

每种装备**每档商店购买一次**，售出后不恢复该购买额度。第一批暂不开放装备转售或丢弃，因此也不增加回购、折旧和倒卖机制。

备用短刃和应急药囊的既有剧情赠物保持原获取条件，各另得一件。先买后领赠物、先领后买都合法，各最多持有两件；赠物不消耗商店购买额度，其余七种各最多一件。第一波正常来源合计最多11个装备实例。

新版本赠物按来源追加并去重，保留已经买到的装备，不再整表覆盖库存；旧包按原内容读取。

### 4.4 与远征掉落分开

购买得到的是馆内持久装备，不占战备种类携带名额。已装配的随出征冻结，返回后仍归角色；延续现有装备保留规则。

它们不走「本层未入袋丢失／失败带回一半」的新拾获战利品规则。本批不把九件投进普通掉落表或现有鉴定结果，避免在同一批里同时改变购买、拾获与归属协议。

## 5. 数值与表现验收边界

本版暂定价格为1,200～1,680 G，多件带零头，避免所有标价整百。总价13,380 G接近一次庄园全通的赏金目标带下沿，但日期与限购决定购买节奏；它只能提供一次性支出，不被视作解决长期资金积累。

玩家详情优先显示：物品名称、价格、持有量／商店余量、所选角色的实际改动面。类型用「配装」；列表复用现有样式和分页，随机属性不伪装成新分类。装备成功后的获得提示只在真实交付时触发。

验证至少覆盖：柯萝萝三空面的差异、诺玛的队伍空面条件、凯尔与玛丽埃塔可用性、特殊动作排除、选面转交、反复装卸、赠物追加、全队配置上限、出征冻结与读档。参考模型只验证商店时序，不代替上述战斗与交易验证。
