整体没有明显视觉矛盾，可以按这五条推进。下面针对三个取舍补充，另附三处小隐患。

## 一、底部轻边界：成立，但要满足三个条件

横跨目录与主图区的底部记录，能把左侧和中间连成同一页幅，这正是参考二的延展感来源，保留是对的。成立条件如下：

1. **它是主内容区唯一的边界，且最淡。** 视觉重量必须明显低于 Menu 外壳，接近若有若无的切角线，不加底色或只加极低的暗化。目录选中项和掉落图标都不能比它更"框"。
2. **没有内容时不能留下空框。** 不虚构引言后，很多条目可能只有一两行，甚至没有记录。空框或半空框会比没有框更显眼。建议规则：
   - 无记录时，整个底部区不出现，主图区与目录自然向下延伸；
   - 有记录时，高度随内容收放，但保留一个最小高度，避免出现细条。

   这条需要主 Agent 在数据层面确认"有无记录"可以判断。
3. **与上方的关系要清楚。**
   - 草图最低点（积泥边缘）与底部边界之间要留出足够空隙，不能让边界像是在切草图。
   - 目录的滚动区以它为下界，不与之重叠。
   - 右栏掉落区的底边最好与它的底边齐平，让整页底部收在同一水平。

## 二、无圆环无基线时如何撑住主图

靠三件事共同完成，缺一不可：

1. **按视觉重心定位，而不是按包围盒居中。**
   - 水平方向：取可见形体的重心落在主图区中线上。
   - 垂直方向：不居中，而是让形体的"落地处"统一落在主图区下部某个固定高度。

   史莱姆的积泥本身就是地面，不需要另画基线。对于没有明显落地处的形体，元数据中需要单独指定这个锚点。这样换条目时页面不会跳动。
2. **尺度要够大。** 草图宽度应占主图区的大部分，同时设高度上限，避免瘦高形体顶到编号或页签。去掉圆环后，中心的分量只能靠形体本身撑起，尺寸偏小会立刻显得松散。
3. **压暗要比想象中更柔、更大。** 压暗中心放在视觉重心略偏下的位置。边缘一旦能被看出是椭圆，就等于把圆环换了个形式又画了回来。

编号 No.001 靠在形体左上，作为唯一的记录性小锚点就够了。

## 三、暖暗形体层的取舍

核心取舍在于：**这一层既要挡住背景，又不能读成剪影。**

- **亮度方向：比周围压暗后的背景略亮、略暖，而不是更暗。** 更暗的形体会读成一个洞或剪影；略亮才会读成"有体积的东西被画在这里"。
- **内部有起伏，但范围很窄。** 由原画亮度大幅压缩而来，高光处稍亮，底部和积泥处稍暗。起伏只需足以打破实心感，不能与明暗层抢活，泥斑和杂物仍由明暗层负责。
- **透明度应足以挡住走廊窗格的纹理**，这是幽灵感的来源。允许极少量背景透出，但不能看清结构。
- **边缘不能外溢。** 遮罩边缘应收在外轮廓线以内，向内羽化几个像素。超出墨线一圈的柔边，正是光晕和幽灵感的来源。
- **离散小物与主体同规则。** 溅开的泥滴同样带形体层，否则会像飘浮的线圈。
- **在缩略图中，这一层比线更重要。** 小尺寸下线会糊，主要靠形体层的明暗块来辨认。缩略版可以适当提高它的对比。

## 四、三处小隐患

1. **掉落图标与草图的风格落差。** 复用彩色共用图标可以接受，但它们会是整页唯一饱和的彩色元素。建议只统一尺寸与留白，并把图标放在比主图明显小的尺度上，让落差显得像"附录"而不是冲突。若看样时仍然太跳，再考虑轻微降饱和，不必重做图标。
2. **"无掉落"不应占图标格。** 它是数据状态，不是物品。用一行淡文字表达或直接不显示即可。未知掉落用"？"格是另一回事，可以保留。
3. **成品图合成后，游戏内无法再分层调节。** 这不矛盾，但应保留离线分层源文件和参数，方便后续统一调整整体透明度或色调时能重新导出，而不是在成品上修改。

## 五、下一步验收

单只史莱姆试样时，在真实空壳上同时检查以下四项：

- 主图尺寸下：不像剪影、不像幽灵、不像滤镜；
- 缩略图尺寸下：能认出是什么生物；
- 关掉压暗时：形体层仍能挡住走廊纹理；
- 打开压暗时：压暗看不出边界。

四项通过后，再搭整页。

## 二、参考二的组织如何吸收观察草图

- **顶部**：分类页签。
- **左侧**：目录。

需要改动的地方有三处：

## 三、纯轮廓还是保留少量明暗

**主视觉选择保留少量明暗。** 理由如下：

- 纯轮廓会丢失这只生物最重要的信息：半透明、浊泥色、体内夹杂的碎石与贝壳。剩下的只是一个穹顶形状，读起来像占位符。
- 纯轮廓在深色背景上透出背景，正是"幽灵感"的主要来源。
- 少量明暗能让它像一张有人看过、画过的观察草图，而不是滤镜效果。

纯轮廓并非没有用处，它适合承担**状态语言**：

| 状态 | 表现 |
|---|---|
| 未发现 | 剪影或"？？？" |
| 已发现 | 观察草图（线稿加明暗） |

这样两种风格各有职责，不必在主视觉上二选一。是否再加"完全解明后显示原色"这一层，本轮不做，以免增加系统负担。

### 防止幽灵化的具体手段

1. **色相保持暖灰。** 线条用接近标题暖白的灰色，例如偏米灰。不带青色，不加外发光，不加模糊光晕。
2. **形体内部不透明。** 草图身后垫一层低亮度暖深色的形体遮罩，略亮于背景且不透明，挡住洋馆走廊的纹理。幽灵感主要来自"透过形体看到背景"，这一层是关键。
3. **线条分层级。** 外轮廓最粗最实，内部结构线中等，明暗笔触最轻。形体轮廓必须一眼可读。
4. **局部压暗而非加框。** 主图区背后做一个很柔和的暗化区域，让背景亮度在主图周围稳定下来。它代替大圆环提供聚焦，但看不出边界。
5. **明暗只出现在少数位置。** 包括泥斑、体内杂物、底部积泥阴影，以及顶部的一两处高光留白。其余部分留空。

## 四、转换算法思路

离线处理，输入为透明 PNG，输出若干带透明通道的图层。按资产保存参数，可单独微调。

### 处理流程

1. **外轮廓**：由 Alpha 通道阈值得到形体蒙版，经形态学清理去掉碎边和半透明光晕，再提取轮廓。线宽用距离变换控制，底部和背光侧略粗，形成手绘的轻重变化。
2. **内部墨线**：现有素材本身带黑色墨线，这是最好的线稿来源。用"低亮度加低饱和度"的条件提取墨线，去掉面积过小的噪点，再统一重新着色为暖灰。实际效果是**沿用原画师的线，而不是让算法猜线**。
3. **明暗**：将原图亮度归纳成两到三个色阶，只保留最暗的一阶（泥斑、杂物、底部阴影），转成单色淡染或稀疏排线。中间色阶舍弃。
4. **留白与断线**：在原图高光区域打断线条，使轮廓不完全闭合，增加观察草图的感觉。这一步最容易过度，参数要保守。
5. **遮罩层**：由形体蒙版直接生成，用于游戏内垫底。
6. **元数据**：记录包围盒、视觉重心、地面基线位置、建议显示比例。页面根据这些数据排布不同比例的生物，不依赖图片本身的留白。

### 输出图层

- 线稿层
- 明暗层
- 形体遮罩层

游戏内叠加显示，可分别调节透明度，方便后期统一风格。

### 算法做不到的事

- **不会产生真正的观察信息。** 构造线、截面、局部放大、批注都需要理解形体和语义，算法只能简化已有的画面。
- **不会判断哪条线重要。** 它按明度和颜色取线，不按形体取线。原画里装饰性的笔触可能被保留，结构性的边缘可能因颜色不够深而丢失。
- **排线不会顺着形体走。** 程序生成的排线方向是机械的，容易显得像网点或滤镜。所以推荐淡染式明暗，不推荐密集排线。
- **无法统一画风差异。** 不同素材的墨线粗细、上色方式不同，同一组参数的结果会不一致。每个资产都需要单独调参，少数可能需要人工修线。
- **小尺寸会糊。** 草图细节在目录缩略图尺寸下会消失，缩略图需要单独一档更简化的参数，不能直接缩小主图。
- **半透明质感只能暗示。** 原画的通透感来自色彩叠加，转成单色后只能靠高光留白和内部杂物来暗示，无法完整保留。

### 验收标准

把草图叠在真实空壳上，在实际显示尺寸下检查以下几点：

- 一眼认得出是什么生物；
- 不像剪影，也不像幽灵；
- 不像照片滤镜；
- 和右侧暖白文字在色调上属于同一页。

## 五、重复线稿与大圆环的取舍

**参考一底部的重复线稿：去掉。** 主图已经是草图，再放一张小草图就是同一个元素重复两次，正是之前被否定的拼贴感。用户喜欢的描边语言已经完整地体现在主图上。

**参考二的大圆环：去掉，或者只留极少残余。** 大圆环的作用是聚焦和居中，但它是一个独立的装饰几何，会把主图框成"展品"，与观察草图的随手记录感冲突，同时又增加一组细线。

替代方案如下：

- 用局部压暗承担聚焦；
- 用地面基线承担落地和尺度；
- 编号 No.001 承担记录感；
- 如需一点仪式感，可以在基线两端各留一个小菱形端点，呼应 Menu 外壳的切角语言。不建议再多。

真正的取舍是：去掉圆环后，主图区在构图上会显得更松一些，需要靠草图本身的尺寸和压暗来撑住中心。所以主图的显示尺寸不能太小，应占主图区宽度的大部分。

## 六、各区域关系

页面的阅读顺序是：**选对象 → 看形体 → 读已知 → 看衍生信息**。

- **目录**：决定"看哪一个"。目录与内容属于同一页，但视觉重量最低。只有选中项带框或左侧标记，其余项只有缩略图加名称加编号，不给每项都画卡片框，避免出现通用网页列表的感觉。缩略图用简化草图，与主图属于同一种语言；未发现项为剪影加"？？？"。
- **主图**：页面的视觉重心，也是唯一的大图。
- **右栏资料**：负责文字信息。名称和英文名最重，标签次之（建议最多两个），简介和已知情报是阅读主体。已知情报保留键值形式，因为图鉴本身就是资料阅读，而且条目可以随解锁逐条出现，这是"已知知识"最直接的表达。
- **底部图鉴记录**：附在主图下方的叙述性记录，与右栏的结构化资料形成"表格"和"笔记"两种语气。两者内容不要重复，右栏写事实，底部写观察和引言。
- **可能掉落**：放在右栏底部，属于对象的衍生信息，视觉重量低于已知情报。图标同样使用草图化的小图，或者至少去掉彩色底和厚框，否则会成为页面上最花的一块，抢走主图的重心。未知掉落显示为"？"。

这里有一个需要主 Agent 判断的取舍：掉落物图标如果与背包共用彩色原图，风格会不统一；如果单独生成草图版，就会多一批衍生资源。建议使用草图版，因为它们同样只用于图鉴。

## 七、最少必要的交互

1. **分类页签切换**：生物、地点、器物、世界知识。
2. **目录选择**：支持点击，以及键盘或手柄的上下切换。内容区切换时使用短暂的淡入淡出，不做翻页动画。
3. **目录超长时滚动**：建议用滚动替代参考二底部的"1/3"分页。分页按钮放在主图区下方，归属不清，容易被误认为是在切换图鉴记录的页码。
4. **未解锁项**：可以选中，但只显示剪影、编号和"？？？"，不显示资料。

本轮不做缩放查看、悬停提示、收藏、筛选和搜索。掉落物名称已直接显示，因此也不需要悬停提示。

## 八、分阶段计划

**阶段一：规格定稿。** 确认本方案的区域关系、草图层级、颜色与透明度范围，以及资产元数据字段（包围盒、重心、基线、显示比例）。数据层面确认已知情报和掉落的解锁粒度，这一项由主 Agent 判断工程可行性。

**阶段二：史莱姆算法原型。** 只处理浊泥史莱姆，产出两三组参数版本，例如明暗轻、中，以及断线有无。全部叠在真实空壳上，在实际显示尺寸下比较，同时检查缩略图尺寸。根据第四节的验收标准选定一组参数。

**阶段三：史莱姆静态页面验证。** 用选定的草图组成完整页面，确认草图与右栏文字是否像同一页、压暗是否足以替代圆环、掉落区是否过重。这一步仍然只用这一个例子。

**阶段四：通用性验证（方案确认之后）。** 选两只形体差异大的生物，例如硬壳礁蟹（细长腿）和刻仪兽（复杂轮廓），检验同一流程是否成立。重点观察细肢体的外轮廓提取，以及墨线风格差异造成的不一致。这一阶段决定流程是"全自动"，还是"自动加逐个调参加少量人工修线"。

**阶段五：实装。** 离线批处理加资产元数据，游戏内只读取结果图层并按元数据排布。原始素材保持不变。

---

## 最大的风险

最终结果像"滤镜处理过的素材"，而不是"观察草图"。应对办法有三条：

- 优先沿用原画墨线；
- 明暗只保留最少的部分；
- 允许个别资产人工修整。

如果阶段二的原型无法达到验收标准，应该退回到"纯墨线加形体遮罩"这一最保守的版本，而不是增加更多算法效果。

# 观察草稿算法改良方案

## 一、诊断：现有算法的四个根本问题

| 问题 | 原因 | 表现 |
|---|---|---|
| 透明边界与墨线混在一起 | alpha 外部被填成白色后再算亮度，透明边缘被当作"暗于白底"的墨线 | 外轮廓变成一圈等宽、等亮的亮边，近似贴纸描边 |
| 尺度错位 | 15px 闭运算按源图像素设定，而源图 1376 宽、显示约 550 宽，比例约 2.5:1 | 换一张分辨率或体型不同的源图，结果就会变 |
| 只有暗度门限，没有形状判断 | black-hat 乘以暗度只回答"暗不暗"，不回答"是不是线" | 短笔画时断时续、线宽不稳；泥斑虽没被抽成线，也没被单独处理 |
| 淡染直接照搬低频亮度 | 宽暗块在暗底上保留了原有的相对深度 | 左右两块污渍读成眼窝 |

当前图里积泥部分还能看到块状伪影，可能来自源图压缩或闭运算本身，也需要一并处理。

**改良原则**：三层各有各的信号来源，所有尺度都从源图自身测量，最后按实际显示尺寸输出。

---

## 二、总体管线

```
源图(RGBA) → 解预乘、线性化
   ├─ A. 尺度标定：测出源墨线宽度 w，换算显示比例 s
   ├─ B. 形体层：只用 alpha
   ├─ C. 墨线层：只在 alpha 内部、只用色彩亮度，带形状约束
   ├─ D. 淡染层：去掉墨线后的源图，做色调压缩
   └─ E. 合成：在 2× 显示尺寸合成，预乘下采样到 1×，主图和缩略图各一档
```

依赖库：numpy、scipy.ndimage、scikit-image（用于 hessian/frangi、apply_hysteresis_threshold、skeletonize、形态学），opencv 可选（用于 inpaint）。不需要训练模型。

---

## 三、A. 尺度标定：消除每张图的特殊常数

1. **显示比例**：s = 目标显示宽度 × dpr ÷ 源主体包围盒宽度。用包围盒宽度而不是画布宽度。
2. **工作分辨率**：先把源图缩放到 2× 显示尺寸再处理（史莱姆约 1100 宽）。这样所有处理都发生在接近最终的尺度上，最后只需做一次 2:1 下采样。
3. **墨线宽度 w**：在 alpha 内部取"明显暗且低饱和"的像素（例如亮度低于内部亮度分布 5% 分位附近），先求距离变换，再在骨架上取值。中位数乘以 2 即为 w。

之后所有核尺寸、面积门限都写成 w 的倍数，或者"显示像素"的倍数，不再写源图像素。参数文件里只保留少数无量纲系数；个别资产可以覆盖，但默认不需要。

---

## 四、B. 形体层与外轮廓：只看 alpha

**alpha 的处理**
- 源 alpha 原样保留，不做硬阈值。
- 连通分量去除只剔除面积小于约 1.5 显示像素²、且 alpha 峰值很低的碎屑。合法的小泥滴保留。

**外轮廓带**
- 由 alpha 的有符号距离场得到：以 alpha = 0.5 等值线为边界，求亚像素精度的内侧距离 d_in。
- 轮廓全部落在 alpha 内侧，从结构上杜绝向外泛光。

**线宽不等粗，按三个因素调制**
- **源图依据**：源图本身有黑色外轮廓墨线。在边界内侧 2w 范围内测量实际墨线厚度，以它为基础宽度。源图没有外墨线的段落，回退到 0.8w。
- **受光**：根据轮廓法线方向，底部和背光侧乘约 1.3，顶部受光侧乘约 0.7，并允许极少量变细到断开。断开处用源图里对应位置的高光来决定，而不是随机生成。
- **曲率**：曲率高的尖端（如泥滴）略细。

**亮度与边缘**
- 轮廓不用统一亮度，而是对亮度做调制：受光侧较亮，背光侧下降约 20%。
- 线内外两侧都是平滑的 smoothstep，宽约 0.6 显示像素，形成抗锯齿。不做任何向外的模糊。

---

## 五、C. 内部墨线：沿用原画的线，并按线的形状筛选

这是改动最大的一层。

1. **候选强度**：在 alpha 内部（外轮廓带以内 1w 起）计算以下两项：
   - 多尺度 black-hat，结构元半径为 1.5w 和 3w，取最大值，并除以局部背景亮度做归一化，使暗区里的墨线也能被提取；
   - 再乘以低饱和门限：墨线是中性黑，泥斑偏棕，这一点能直接帮助区分泥斑。
2. **形状约束（解决泥斑问题）**：
   - 用 Hessian 脊线响应（Frangi 或 sato），尺度设为 w/2 到 w。宽暗块在这个尺度上没有脊线响应，会被自然排除。
   - 再用一个宽度检验：对候选区域做距离变换，局部最大宽度超过 2.5w 的连通区不当作线。
3. **连续性（解决断续问题）**：
   - 用滞后阈值：高门限取种子，低门限顺着种子延伸，短笔画因此能连成整笔。
   - 最终墨线的 alpha 保留软值，等于连续强度乘以滞后区域膨胀 1px 的掩膜，而不是二值化后再模糊。这样保留了原画笔触的起笔、收笔和浓淡变化。
4. **主次层级**：每个连通笔画计算一个权重，由三项组成：
   - 笔画长度，以 w 为单位，长线权重高；
   - 源图墨色深度；
   - 与外轮廓的距离，靠近轮廓的结构线权重略高。

   权重映射为亮度和不透明度。主结构线（垂流、贝壳、杂物轮廓）完整显示；顶部小气泡和碎笔约降到 50%。长度小于约 2w 的孤立点淡出或删除。
5. **亮线变细**：亮线在暗底上，看起来会比实际更粗。墨线 alpha 做约 0.3 显示像素的灰度腐蚀，或乘以一条细化系数曲线，使其看起来与源图线宽相当。用户认可的"细浅线"质感主要取决于这一步。
6. **补线**：只在形体层明显存在结构、但没有提取到墨线的区域，才用 XDoG 补线。XDoG 结果乘以"墨线缺失掩膜"和一个低权重，不进入全图。默认关闭，按资产开启。

---

## 六、D. 淡染层：去掉墨线，压缩色调，修正眼窝感

1. **去除墨线**：用墨线掩膜在亮度上做归一化卷积或 inpaint，把墨线位置填成周围的颜色。淡染不应再包含墨线的暗痕，否则线两侧会出现暗边。
2. **降噪**：引导滤波或双边滤波，半径约 1w，去除块状伪影，同时保留泥斑边界。
3. **分频压缩，这是解决眼窝问题的关键**：
   - 低频 L（高斯，σ 约为形体宽度的 1/12）：表示大块明暗。
   - 中频 M = 源 − L：表示泥斑纹理与杂物。
   - 输出亮度 = 基色 + a·L′ + b·M。其中 L′ 经过软压缩：暗部方向的振幅只保留约 40%，亮部方向保留约 70%。
   - 宽暗斑的深度因此被封顶，不再形成两个黑洞；纹理和边缘由中频保留。
4. **色相带回一点**：泥斑之所以像眼窝，部分原因是它在暗底上只是"更黑"。用源图色度给暗斑加一点偏棕的暖色，使它读成"泥渍"而不是"空洞"。饱和度上限要很低，避免整页出现颜色。
5. **体积**：在压缩后的淡染上叠一层很轻的形体光照：由距离场得到"离边缘越近略暗、底部积泥更暗"的效果，幅度很小。这也就是上一轮所说的"随形体变化的暖暗形体层"，直接内建在淡染里，不再单独成层。
6. **不透明度**：主体内部不透明度保持接近 1，用来挡住走廊纹理。只在外轮廓内侧 1 到 2 显示像素处跟随源 alpha 过渡。

---

## 七、E. 合成与输出

- **颜色顺序**：淡染为底，叠外轮廓，再叠内部墨线。线色在暖灰范围内取值，例如从 [150,145,132] 到 [205,198,180]，具体由权重与受光决定，不再统一用 [198,191,172]。
- **最终 alpha**：等于源 alpha。线条不改变 alpha，就不会出现边缘变亮或扩张的问题。
- **下采样**：在预乘、线性空间中用 Lanczos 下采样到 1×，然后转回 sRGB。
- **两档输出**：
  - 主图：按实际显示尺寸乘以 dpr；
  - 缩略图：单独以缩略尺寸重新计算 s。主次权重门限提高，只保留主结构线，外轮廓相对加粗，淡染对比略增。不直接缩小主图。

---

## 八、调试与验收

**调试输出**：每次处理同时输出以下中间结果，方便你和主 Agent 对照：
- w 的测量值；
- 外轮廓带；

## 三、算法调整（共五处）

### 1. 新增结构图 S，决定"哪里值得画线"

   - 现象：史莱姆底部摊开的泥边和右下的小泥滴，以及蟹腿外缘，在深色 UI 底上主要靠填色与背景的明度差撑着，亮边比 v4 弱很多。缩到 UI 实际尺寸后，剪影可能糊进背景。
   - 原因推测：外轮廓线也参与了 6px 网格和 14.5% 覆盖上限的竞争。
   - 建议：把 alpha 边界的轮廓线单独保底，不计入密度上限，线宽保持 1.0。这是参数和规则豁免，不是新算法。

2. **蟹的腿与地面粘连。**
   - 现象：几条步足的下段、关节与底部泥地的亮线一起被稀疏化，腿和地面的分界变弱，腿部结构的可读性比 v4 退步。
   - 建议：地面区域的线段评分权重可以再降，把配额让给腿和关节的长线段。如果第 1 条的轮廓保底已经覆盖腿外缘，这里也可能随之解决，先看第 1 条的效果再决定。

3. **千金的脸部和眼睛需要在实际 UI 尺寸下确认。**
   - 现象：对照图里脸部已经很淡，红眼被淡染压得接近不可见。
   - 原因推测：小暗点筛选是为暗点设计的，原画的眼睛偏亮，可能没被选中。
   - 处理：如果实际 UI 中看不清，就单独放宽面部区域的覆盖上限，或允许亮色小点进入保留通道。

## 可接受、不必处理的变化

- **整体变暗**：这是亮线面积减少的自然结果，alpha 和线色都没动，符合约束。
- **千金裙摆褶皱减少、丝线保留**：取舍合理。
- **史莱姆内部气泡和贝壳**：保留得当。

## 给主 Agent 检查 17 张 UI 时的重点

- 小尺寸下的剪影是否成立
- 细长肢体（腿、触须、武器）是否断开或粘进背景、地面
- 眼睛等焦点是否保留

除以上第 1 条为确定要修的问题外，其余可以按实际 UI 的检查结果决定是否处理。
