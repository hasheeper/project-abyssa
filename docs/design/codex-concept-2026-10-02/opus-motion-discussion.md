# 《守望者之崖》图鉴动效设计方案

## 一、总原则

- **页幅不动，内容在页幅里显现。** 面板边框、分隔线、栏位尺寸都是静态的"纸"。动效只发生在内容层，以此传达"资料被展开"。
- **观察图是主角，其余是陪衬。** 进入时观察图压轴；浏览时它最先交接，文字随后。
- **只用三种手段：透明度、轻微模糊、遮罩。**
  - 文字和图像都不位移、不缩放。
  - 稳态的线宽、尺寸、亮度、外围淡化全部不碰。
  - 遮罩只决定"看得见多少"，不改变图本身。
- **进入可以有层次，退出和切换必须利落。** 分层出现的总跨度控制在一次呼吸内，不做逐行表演。

曲线约定：

| 用途 | 曲线 | 特点 |
|---|---|---|
| in | cubic-bezier(.22,.61,.36,1) | 起步干脆、尾部柔和 |
| out | cubic-bezier(.4,0,.7,.2) | 加速离开，不拖尾 |
| switch | cubic-bezier(.33,0,.2,1) | 用于内部切换 |

## 二、层级划分：哪些保留，哪些动

| 层 | 进入/离开 | 内部切换 |
|---|---|---|
| 洋馆背景、左侧 Menu、顶部四类标签 | 保留（标签条随栏目由 Menu 处理） | 保留 |
| 图鉴面板框、分隔线、栏标题（"生物·软泥族"标签位、"已知情报""可能掉落"等小标题） | 随页面淡入淡出，作为第一层 | **保留不动** |
| 左目录列表 | 作为一组出现 | 只换高亮态 |
| 弱轮盘、光晕 | 随观察图出现 | 保留，仅做轻微响应 |
| 观察线稿 | 主角 | 交接 |
| 编号、族别、名称、英文名、标签、情报、简介、图鉴记录、掉落 | 分层出现 | 原位交接 |

## 三、进入图鉴

图鉴不再借用 settingsPanel，改为独立编排，总长约 **760ms**，全部由 `SystemSceneMotion.clock` 驱动，保证可反向。

| 时间 (ms) | 层 | 动作 |
|---|---|---|
| 0–220 | 面板框、分隔线、栏标题 | opacity 0→1，无模糊（框线要清楚，模糊会脏） |
| 60–360 | 左目录（整组） | opacity 0→1 + blur 2→0px；可见条目最多做 4 档、每档 18ms 的微差，让它读起来是"一列"而不是"一串" |
| 120–620 | 观察图 | 见下方说明 |
| 140–520 | 光晕 | 0→稳态值，无过冲 |
| 160–560 | 弱轮盘 | 0→稳态透明度，同时回转一次，之后静止 |
| 260–560 | 右栏：名称组 → 情报组 → 掉落组 | 三组各差 60ms；每组 opacity + blur 2→0px，280ms |
| 340–640 | 底部图鉴记录、footer | 同上 |

**观察图的出现方式：中心向外的径向遮罩展开。**

- 遮罩半径从约 35% 扩到 110%，同时 opacity 0→1、blur 3→0px，时长 500ms。
- 遮罩边缘羽化要宽，与线稿本身的四角淡化叠乘。展开结束时遮罩完全透明，稳态与现在一模一样。
- 观感应是"视线聚焦到标本上"，不是扫描线。

**弱轮盘的回转。** 从 −6° 减速转到 0°，只在进入时发生一次，之后保持静止。这是它唯一一次"表态"。

**右栏文字的约束：**

- 不加 translate，消除用户否定过的"飞来"感。
- 节奏比记忆页更紧，各组几乎首尾相接，不会形成迟缓的队列。

## 四、离开图鉴

离开总长约 **380ms**，是进入的一半。原则是不倒放整套编排，而是压缩成两拍。

| 时间 (ms) | 层 | 动作 |
|---|---|---|
| 0–200 | 所有文字、掉落、目录 | 同时 opacity→0，blur 0→1.5px，out 曲线 |
| 0–300 | 观察图 | 遮罩向中心收拢到约 60%，同时淡出；比文字晚约 80ms 消失，作为最后的视觉落点 |
| 0–260 | 轮盘、光晕 | 直接淡出，不转 |
| 160–380 | 面板框 | 淡出 |

**中途离开**（进入尚未完成时就点了别的栏目）：

- 进入和离开共享同一个 clock，从当前值反向走，不跳到满值再退。
- 反向速度使用离开曲线和时长比例，所以中途退出天然更快。
- 若当时正在进行内部切换，切换冻结在当前混合状态，由整页离开统一接管淡出，不再完成切换。

## 五、内部切换（核心）

目标：**约 300ms 完成一次交接，观察图先换，文字原位换字。**

### 1. 观察图：先出后入，短重叠

- **旧图**：0–140ms，opacity→0，blur 0→1.5px，遮罩向中心收到约 80%。
- **新图**：100–320ms，opacity 0→1，blur 1.5→0px，遮罩从约 80% 展开到 110%。
- **防止糊成一团**：两图同时可见只有约 40ms，且此时旧图透明度已低于 0.3。
  - 史莱姆和细高人形的轮廓差异很大，必须避免两张线稿以中等透明度叠在一起。
  - 交接处靠光晕和轮盘撑住画面，不会出现空洞感。
- 遮罩始终以图像框中心为圆心，不随生物外形变化，保证矮宽体和细高体的交接节奏一致。

### 2. 弱轮盘：做"选择器"

- 每次切换按目录方向转一小格：向下 +8°，向上 −8°。跨多项时最多也只转一格。
- 320ms 减速停住，停后静止。
- 这一下是"换了一页观察记录"的唯一机械暗示。它很轻，所以不廉价。

### 3. 光晕：呼吸一次

- 在 0–300ms 内降到稳态的约 85%，再回到稳态。
- 不提亮、不变色，避免整页发光。

### 4. 文字与资料：原位交接

适用于编号 NO.xxx、族别、名称、英文名、标签、情报四行、简介、底部图鉴记录、掉落四格。

- **旧内容**：0–110ms 淡出，无模糊。快速淡出比模糊更干净。
- **新内容**：110–270ms 淡入，blur 1→0px。
- 名称组与情报组同时进行；简介和底部记录晚 30ms；掉落四格从左到右各差 20ms。整体仍在约 330ms 内完成。

为避免"文字随布局跳闪"：

- 每个文本槽在交接期间锁定当前盒高，等新内容淡入后再释放。
- 简介、记录区设 min-height，覆盖 14 项中的常见长度。
- 编号直接换字，不做数字滚动或计数。

**资料区回顶**放在旧内容透明度为 0 的那一帧瞬间完成，用户看不到滚动。

### 5. 左目录

- 选中高亮在 120ms 内交叉淡入淡出，不做滑块移动，以免列表区产生位移感。
- 目录滚动位置照旧保留。
- 键盘导航把新选中项滚进视野时，使用短距离平滑滚动（≤160ms）。

## 六、快速连续点击与按键连发

结构上区分两个状态：

- **`selectedId`**：立即更新，驱动目录高亮。
- **`displayedId`**：驱动右栏、观察图和记录，通过交接管线更新。

管线规则：

1. **旧内容淡出阶段又收到新目标**：只改写待入目标，不重启淡出。淡出结束后直接进入最新条目，中间条目不显示。
2. **新内容淡入阶段又收到新目标**：从当前透明度开始淡出，不先补满。
3. **同时最多两层观察图**（出、入各一层）。更旧的立即卸载。
4. **方向键连发**（两次间隔 < 140ms）进入"翻阅模式"：
   - 文字改为 80ms 纯透明度换字，保证能读到名称。
   - 观察图停在低透明度的过渡态，不逐张闪。
   - 轮盘每次仍转一格，提供连续的触感。
   - 按键停止约 150ms 后，观察图按正常 220ms 入场落定。
5. **Home/End 等大跨度跳转**按普通单次切换处理，轮盘只转一格。

## 七、降级

- **减少动态效果**：进入、离开、切换都只保留 120ms 透明度变化；无模糊、无遮罩、轮盘不转。
- **页面隐藏或 skip**：直接到稳态，沿用现有机制。

## 八、明确不做

- 扫描线、网格扫过、粒子、描边动画、线稿逐笔绘制
- 整页或面板发光、选中时的高亮闪光
- 任何对线稿稳态的缩放、亮度、线宽、外围淡化改动，包括过冲回弹
- 文字的位移、缩放、打字机效果、逐字出现
- 翻书拟物、卡片翻转
- 轮盘持续旋转或在悬停时转动

## 九、落地顺序建议

1. 先做内部切换。它使用频率最高，直接决定"轻快"是否成立：
   - 观察图出入与遮罩
   - 文本槽锁高与交接管线
   - 轮盘一格转动
2. 再做独立的进入/离开编排，接入 clock，替换 settingsPanel 的时长。
3. 最后调参：遮罩羽化宽度、光晕呼吸幅度、轮盘角度。建议在史莱姆 ↔ 细高人形之间反复切换来调，这两者差异最大，最容易暴露叠影和空洞问题。

# 图鉴动效设计（修正稿）

## 一、对六点修正的判断

六点都成立，我全部采纳。

- **主图 mask 不做动画**，第一稿的径向揭示作废。显形感只靠两件事：主图在原位提高透明度；模糊比透明度更早消失。观感是"焦点落定"，而不是"边界扩张"。
- **轮盘和底光是固定的观察台**。首次进入时随场景淡入，此后在内部切换中完全不变。画面的连续性正是靠它们撑住，因此不需要任何机械暗示。
- **顶部四类归 CodexPanel**，随图鉴的第一层（结构层）进出。Menu 只负责全局大标题和左侧导航。
- **"独立时序"和"可反向"的关系要拆开说**：
  - 共享的 `SystemSceneMotion` 只提供三样东西：生命周期（entering / exiting）、skip、退出完成通知。
  - 图鉴局部各组用自己的进/退时序。
  - 中断时，以各组当前实际渲染的透明度为起点接管，不读取 clock 的位置，也不重置到满值。
- **减少动态效果沿用 skip**，直接稳定，不另设分支。
- **取消翻阅模式和锁高**。改为固定栏位，在透明度为 0 时一次排入最终位置，然后再显现。

**节奏判断：1000 / 620 / 560ms 合适。** 前提是"慢"体现在曲线尾部的余韵上，而不是开头的等待。验收时看三个点：

- 进入时，名称约在 400ms 可读。
- 切换时，点击后 140ms 内旧内容已经清空，名称约在 440ms 落稳。
- 退出时，每层都平滑归零后才卸载，没有残影突然消失。

## 二、曲线

| 用途 | 曲线 | 说明 |
|---|---|---|
| 显现 | cubic-bezier(.2,.6,.3,1) | 起步不拖，尾部长 |
| 退出 | cubic-bezier(.45,0,.55,1) | 对称缓入缓出，归零时不会"啪"一下没掉 |
| 切换清空 | cubic-bezier(.4,0,1,1) | 只有 140ms，干脆即可 |

**模糊的使用范围：**

- 主图：最大 1.5px。
- 大标题（名称）：最大 0.8px。
- 小字号正文、标签、情报、编号：只用透明度。细笔画中文一模糊就发脏。

## 三、进入（约 1000ms）

阅读顺序是：页幅 → 观察台 → 名称 → 资料 → 标本落定。

| ms | 组 | 动作 |
|---|---|---|
| 0–320 | 结构层：面板框、分隔线、顶部四类、栏标题 | 透明度 |
| 80–480 | 左目录（整组，含当前高亮） | 透明度，模糊 1px→0 |
| 120–520 | 轮盘、底光 | 透明度到稳态，不转 |
| 180–1000 | 主图 | 透明度 0→1；模糊 1.5px→0 在约 760ms 先完成，最后一段只剩透明度收尾 |
| 200–600 | 标题组：编号、族别、名称、英文名、标签 | 名称约 400ms 可读 |
| 260–680 | 已知情报 | 透明度 |
| 320–760 | 简介、底部图鉴记录、页码 | 透明度 |
| 380–820 | 掉落四格（整组）、footer | 透明度 |

几组之间大幅重叠，读起来是"一页资料展开"，而不是排队登场。主图最后落定，是全页的句号。

## 四、退出（约 620ms，两拍）

阅读顺序是：先收起文字资料，再撤下标本和页幅。

| ms | 组 | 动作 |
|---|---|---|
| 0–360 | 目录、标题组、情报、简介、记录、掉落 | 近乎同时淡出，组间差 ≤30ms；名称加 0→0.6px 的模糊 |
| 140–560 | 主图 | 透明度→0，模糊 0→1px |
| 180–600 | 轮盘、底光 | 透明度→0 |
| 220–620 | 结构层（含顶部四类） | 透明度→0 |

- 620ms 时所有组都已到 0，再发出退出完成通知。
- 退出曲线尾部平缓，避免最后一帧骤然消失。

## 五、内部切换（约 560ms）

阅读顺序是：目录立即回应 → 旧内容清空 → 名称先落 → 资料跟上 → 线稿最后落定。

| ms | 组 | 动作 |
|---|---|---|
| 0 | 目录 | `selectedId` 立即更新；高亮底色 90ms 交叉淡化，文字色和左标记即时切换 |
| 0–140 | 全部 displayed 组（主图、标题、情报、简介、记录、掉落） | 同步淡出到 0；主图附加 0→0.6px 模糊 |
| 140 | — | 提交 `displayedId`，资料区回顶，新条目一次排入最终栏位 |
| 140–560 | 主图 | 透明度 0→1；模糊 1px→0 在约 420ms 完成 |
| 160–440 | 标题组 | 名称最先落稳 |
| 210–490 | 已知情报 | — |
| 260–530 | 简介、底部记录、页码 | — |
| 300–560 | 掉落四格（整组） | — |

- 轮盘、底光、结构层和栏标题全程不动。
- 主图只有一个元素，先归零再换图，两张轮廓不会同屏。

**为了让 140ms 那一刻能可靠换图，14 张线稿需预加载并完成解码。** 如果新图尚未就绪，主图停在 0 等待，文字组照常显现，不要让旧图回来。

## 六、中断规则（只有一套）

1. **淡出阶段收到新目标**：不重启淡出，只改写待入目标。全部组到 0 时，提交最新目标。
2. **入场阶段收到新目标**：各组从当前透明度开始淡出，时长按 `140ms × 当前值` 计算（不少于 60ms）。归零后提交最新目标。
3. **提交闸门**：只有所有 displayed 组同时为 0，`displayedId` 才会改变。因此任何时刻屏上同一组内容都属于同一条目。
4. **切换中途离开图鉴**：丢弃待入目标，各组从当前值按退出时序走向 0。已经是 0 的组直接视为完成。
5. **进入中途离开，或退出中途返回**：同样从当前渲染值出发，按目标方向的曲线走完剩余部分，不跳到满值或零值再开始。
6. **方向键、Home/End 连按**：全部套用规则 1–3，没有额外模式。

## 七、值得保留的细微动效

这些都很小，作用是让"通透观察记录"有手感，而不是增加表演：

- **焦点落定**：主图的模糊早于透明度消失，最后约 140ms 只剩透明度收尾。这是唯一体现"观察"的动态，也是本方案的签名。
- **观察台先于标本出现**：进入时轮盘和底光在主图之前达到稳态。之后它们完全静止，反衬出内容的流动。
- **目录悬停**：底色 120ms 淡入、160ms 淡出，不做位移。
- **页码随标题组更新**：底部记录的 "01/14" 与标题组同一拍更新，让"翻到第几条"有一致的节拍。

除此之外的一切都保持静止。这个页面的通透感，来自于大部分东西不动。
