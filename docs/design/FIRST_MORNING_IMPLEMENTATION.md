复用 `AdvStage` 底部对话框与 `RpScene` 左右立绘／中央消息流，默认AVG，底栏可切RP。原对话框、底栏、纵向 `RibbonButton`、头像、尺寸及气泡校准保持共用。AVG隐藏的是RP演示页外框，未重做原对白框。

背景铺满1600×900共享画布；RP内容仍按1350px居中，左右席位各276px、中栏798px。背景使用仓库内 `mansion-first-morning.webp`：源图2752×1536，Lanczos等比缩至2048×1143，近无损WebP 2,051,550字节，保留ICC，无模糊、拉伸或强裁切。编码相对缩图最大通道误差1/255。

完整PaperDoll始终保留，下半身由固定舞台边界遮挡，不能给大动作制造随身移动的膝部切线。反应使用独立变换层调用原`motions.ts`，不覆盖站位、景深、已有校准；显式反应不叠加通用情绪动作。已删除10种临时自定义动作，显式动作从36处减至7处；角色入场只由原席位负责。角色差分没有新造表情，缺姿态采用上表的近似。

后续幅度修订：保留上述7处显式动作与原情绪触发范围，跳跃／抖动统一提高原库与角色映射的行程，具体参数见[情绪联动契约](AVG_EMOTION_CUE_CONTRACT.md#动作幅度复核2026-09-09)。不通过增加动作次数或再加划入来提高存在感。
