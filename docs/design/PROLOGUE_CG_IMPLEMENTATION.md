# 序幕 CG：实现与验收边界

日期：2026-09-08。台词以作者最新「神话／现实／决断／日常」中文稿为准，开头为「很久很久以前，世界曾被黑暗笼罩。」见[原文分屏稿](PROLOGUE_SCREENPLAY.md)；保留原句，只调整分屏、换行和停顿，不删减或改写。[运镜规格原文](PROLOGUE_CG_DIRECTION_SOURCE_V1.md)保留为来源。表现口径：**第一幕以记事插画为主；拥抱与触手共用一次短促冲击与衰减回弹，其余沿用现有运镜、转场和统一滤镜。** 本轮视觉、阅读与进度链路已收口；音频、角色局部动作及后续洋馆 AVG 仍有缺口。

## 1. 从哪里进入

标题「新的开始」创建规则4／内容4新档，进入 `prologue.html`。顺序为神话4镜→现实4镜→决断4镜→黑场时间字卡→日常3镜→标题→现有洋馆。CG 全部本地打包，素材映射及源图见[素材清单](../../src/assets/cg/prologue/README.md)。

台词在 [`script.ts`](../../src/apps/prologue/script.ts)按作者最新修订登记。全篇按完整语意分段，同一句中的主语与判断、条件与后果、比较与结论连读；关键反转、动作落点和角色换人另起一段。默认逐段手动点击，自动模式另留阅读时间，不把全文强行塞进约90秒的基础镜头时长。

后续洋馆开场稿尚未提供，当前标题结束进入现有洋馆。此入口不能视为已完成洋馆介绍、强盗教学、委托钩子或初章奖励。

附件对 A3-03 写「无字幕」，最新正文为「我迎着风暴走上去，伸手一把抱住了她。刚才还疯了一样的黑泥，在碰到的那一瞬间，全停下了。」以直接消息为准：两句旁白分别点击显示，不在同一屏出现；第二句读完后进入至少3.2秒无字停顿；不能靠普通继续键误点掉该停顿，长按跳过仍可结束整个序幕。A3-02的消光从「——所以我扔了剑。」出现时计时，A3-03的复色从拥抱旁白出现时计时；这些是局部表现状态，不写入存档。

拥抱与触手入场共用 `entrance: contact` 和同一组相机曲线，只作用于CG，字幕和操作栏保持原位。相机最大偏移约11px、旋转0.2°，配合短促的1.4%推进与逐次减小的回弹，560ms后归零；取景保留安全裁切，原图边缘不进入画面。震动随该镜头的时间轴播放一次，换屏与关闭回看不会重播；减少动态效果模式保留短溶解，关闭震动。入场动作与各镜头的调色／光效分开配置，触手不继承拥抱的暖光。

## 3. 正式存档契约

- 新增 `abyssa.demo` 内容4，规则／协议仍为4。内容2、内容3及各旧 reader 的定义与摘要不变；新包继承现行刻仪兽、商店和成长规则。
- `campaign.prologue = { shotId, status: playing | viewed | skipped }` 由事实重放得到。`advance-prologue`要求当前镜头身份并只推进下一镜；`complete-prologue/continue`只在标题镜头接受，`skip`可在当前镜头接受。
- 每次跨镜提交一次，刷新从已提交镜头开头重播。单镜内的局部阅读位置不当作剧情完成证据；完成／跳过不推进世界时间、不送物品、不加成长或金币。
- 提交失败留在当前镜头并提供重试，幂等请求与双页签CAS仍由已有应用服务处理。未完成序幕时普通游戏进度命令受核心校验，其他游戏页由GameGate引回序幕。
- 旧档继续原路；显式复制升级到新包时标记已跳过序幕，不强迫重播。导入复制保留原包与当前镜头。新周目重新开场，可显式跳过。
- 跨页面静帧仅属临时演出资料，存在 sessionStorage 的短期handoff中；不是进度依据。空间不足时降级交接，不能卡住已完成的存档。
