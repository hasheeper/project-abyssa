> 来源保留，正文不改写。当前实现以用户后续修订和[序幕实施记录](PROLOGUE_CG_IMPLEMENTATION.md)为准：包括第一幕记事定镜、拥抱旁白、中央「三年后」字卡、拥抱／触手的入场回弹、原Logo，以及分层／音频素材待补边界。本附件不作为重新覆盖现有表现的指令。

> 对齐已定稿脚本（日文原文+汉化版）。本稿为工程可直接落地的逐镜执行表：分层拆解 → 运镜参数 → 粒子/Shader 效果 → 转场规则 → 字幕与音效对齐点。

## 〇、全局规格（所有镜头共用）

### 0.1 运镜与缓动基准

| 项 | 规格 |
|---|---|
| 出图尺寸 | 3840×2160，画布四周预留 10% 运镜安全边（实际显示区 3456×1944 起裁） |
| 运镜幅度上限 | 推拉 ≤ 108%（避免像素糊化）；平移 ≤ 画幅 8%；旋转禁用（除 A3-01 特批） |
| 缓动曲线 | 史诗镜（一~三幕）：`easeInOutSine`（匀称庄重）；生活镜（四幕）：`easeOutQuad` + 手持噪声（自然随性） |
| 手持噪声 | Perlin Noise 双轴位移，振幅 2~3px，频率 0.4Hz——**仅第二幕与第四幕启用**，第一、三幕绝对稳定（神性/死寂不许晃） |
| 视差层数基准 | 每镜 3~4 层：BG（背景）/ MG（主体）/ FG（前景遮挡）/ FX（粒子特效层，程序生成不出图） |
| 字幕节奏 | 逐字浮现（Fade-per-char，25ms/字）；段落间空拍 ≥ 0.8s；字幕层永远在 FX 层之上 |
| 帧率目标 | 动效 60fps；粒子密度按低端设备自动降档 50% |

### 0.2 全片色彩与后处理曲线（Post-Processing Timeline）

```
第一幕：暖金滤镜 + 轻微 Bloom（圣光溢出）+ 暗角 15%
第二幕：去饱和 -40% + 冷蓝色偏 + 胶片颗粒 8% + 暗角 25%
第三幕：去饱和 -70%（近单色）→ A3-03 起局部恢复饱和（仅暖光区域）
声桥：  纯黑 #000000，无任何后处理
第四幕：饱和 +10% + 暖黄色偏 + 柔焦 Bloom + 暗角 8%（几乎无压迫）
```

**执行铁律**：第三幕的饱和度恢复必须是「径向遮罩驱动」——暖光扩散到哪里，颜色才活到哪里。这是全片最重要的一个 Shader 需求。

## 一、第一幕【伪史】——仪式化的谎言（4 镜 / 约 22s）

> 幕内运镜语法：**绝对水平垂直、轴对称、匀速、无晃动**。像教堂仪式一样刻板——这份"过度工整"本身就是伏笔（真实的东西不会这么干净）。

## 三、第三幕【拥抱】——静与光的两分钟（4 镜 / 约 21s）

### 【A3-03】拥抱 · 6.5s ★★全片核心镜（无字幕）

| 项 | 参数 |

## 四、【声桥】· 2.5s ★全片神经中枢

> **这 2.5 秒没有任何画面动效，但它是全片最需要精密执行的一段。**

| 时间码 | 事件 | 技术要求 |
|---|---|---|
| 0.00s | 纯黑 #000000，绝对静音 | 音频总线静音（不是音量为 0 的环境声——是**没有声音**，需清空混响尾巴） |
| 1.00s | **「咚。」** 菜刀剁入案板 | 干声、近场、无混响；建议单独拟音精修——这一声的质感值一个音效师的整天 |
| 1.05s | （可选彩蛋）黑屏上极淡的一次白色微闪（透明度 4%，1 帧） | 模拟"惊醒"的视觉残感，低调到只有潜意识能捕捉 |
| 1.60s | 平底锅油爆滋滋声渐入（0.4s 内铺满） | 声像从中央展开至立体声全宽 |
| 2.00s | 海鸟两三声长鸣（远景声像，偏右） | 空间瞬间被"打开" |
| 2.50s | 画面从黑淡入 A4-01（0.8s，暖色先于轮廓浮现——先看到光的颜色，再看清是厨房） | 淡入曲线 easeInSine |

### 7.4 验收基准

1. 全片总时长 88~92s（含标题卡）；
2. 暖色配给规则逐帧检查：第三幕 A3-03 之前不允许出现任何饱和暖色像素区（营火除外，且营火已做去饱和压制）；
3. A3-03 暖光诞生与琴音的对齐误差 ≤ 2 帧；
4. 声桥的静音段必须是真静音（示波器验收，不是低音量）；
5. SKIP 长按跳过后直接写入初章阶段标记，进入洋馆 AVG——与 O2 持久化契约一致。
