# 全稿排查：「旁白替引擎演戏」问题清单

> 排查范围：Scene 01 + Scene 02 全部定稿。
> 判定标准：**文本框正文里出现了应该由「立绘差分 / 图层动画 / SE / 震屏」承担的动作播报**。
> 同时警惕反向矫枉过正：**不是所有描写都要删**——ADV 的旁白仍然承担「镜头看不到的信息」（气味、温度、触感、时间流逝、画面外的动静）。这些必须保留，否则戏就干了。

---

## 一、判定原则（先立尺子再量）

| 类型 | 处置 | 理由 |
|---|---|---|
| ❌ 立绘能演的表情/动作（拔剑、后退、脸红、竖角） | 移出正文 → 演出指令 + 差分 | 玩家看得见 |
| ❌ 图层/SE能演的（茶具浮空、触手伸缩、破窗） | 移出正文 → 演出指令 | 玩家看得见听得见 |
| ⭕ 画面演不出来的（气味、温度、重量、触感） | **保留在旁白** | 这是文字的专属领地 |
| ⭕ 镜头外的信息（画外音、远处海面、腰包里的黑泥） | **保留在旁白** | 玩家看不见 |
| ⭕ 极简的节奏留白（「一拍安静」「没人接话」） | **保留** | 节奏信息，非动作播报 |

## 二、Scene 01 问题点排查

### 【S1-1 拖猫工程】——问题 3 处

**❌ 问题 1：**
> // 凯尔弯下腰，双手熟练地从两侧腋下一捞，连同拖曳在地的银白长发，像提一只脱力的大猫一样把少女端了起来。艾比希斯两脚悬在半空，完全没有借力，两只黑角歪向一边。

「两脚悬空」「黑角歪向一边」——这是**拎猫合体差分**本身画着的内容，正文复述了一遍。
**修正**：正文只留一行短旁白（如「毛毯里没有任何抵抗的迹象」），拎猫姿态交给差分。「像提一只脱力的大猫」这种比喻整句删除——差分画出来就是这个样子，不需要文字再比喻一次。

**❌ 问题 2：**
> // 艾比希斯顺势把下巴直接枕在木桌边缘，整个人像没有骨头一样软趴趴地散开。

「下巴枕桌」= 趴桌差分的画面内容。「像没有骨头一样软趴趴」又是替画面打比方。
**修正**：切趴桌差分即可，正文可完全留白或只留艾比希斯的台词。

**❌ 问题 3（分支 B 内）：**
> （两只黑角瞬间竖起，细瘦的双手啪地按住盘子，眼神无机质地盯过来「（じーっ）」）

「黑角竖起」「按住盘子」是差分+道具动画；但注意——**这一条里「（じーっ）」是角色卡钦定的拟声演出，必须保留**。
**修正**：动作拆成演出指令；括号内只留 `（じーっ）` 作为演技标注。

**⭕ 保留项（勿动）**：
> 「盛着煎蛋和香肠的瓷盘推到她鼻子底下，**散发着油脂的热气**」——热气与香味是画面外信息，保留；
> 触手偷香肠段落的 `（ぷよん）`、`ペシッ` 已经是正确写法（SE 标注 + 极简白描），不动。

---

### 【S1-2 女仆长晨巡】——问题 1 处

**❌ 问题 4：**
> // 玛丽埃塔极其自然地递出一张折叠得规整的白餐巾，按在她的唇角。

「递餐巾按唇角」是立绘小动作 + 道具图层。但此处**情有可原**——如果玛丽埃塔没有「递手帕」专用差分，旁白代演是合理的降级方案。
**修正（条件式）**：有差分资产 → 移出正文；没有 → 保留但压缩成半句（「白色的餐巾先一步按在了魔王的唇角」，突出「先一步」这个速度感，那才是文字该干的活）。

**⭕ 保留项**：
> 「倾泻出的红茶精准切在茶杯边缘，**蒸汽带着柑橘的冷香**」——香气保留，是文字专属。

---

### 【S1-3 剑姬牢骚】——问题 1 处

**❌ 问题 5：**
> // 她大步走到自己的固定席位前，顺手把佩剑稳稳挂在椅背专用的黄铜扣上。

挂剑动作 = 立绘位移 + SE（金属挂扣声）。
**修正**：SE 一声「カチャ」+ 尤斯缇丝落座差分即可。但「**椅背专用的黄铜扣**」这个信息值得保——它是「她早已有固定位置」的伏笔证据。压缩为一句极短旁白：「椅背的黄铜挂钩，早就被她磨得发亮。」——**把动作删掉，把痕迹留下**。这是标准处理法：动作交给引擎，岁月感交给文字。

---

### 【S1-4 沙发攻防】——问题 2 处，但要谨慎

**❌ 问题 6：**
> // 柯萝萝伸出两根指头把黑泥拎起来丢到茶几上。黑泥果冻一样弹了弹，哧溜一下又弹回了沙发正中央。

这是「拎-滚循环」小动画的完整脚本，正文全念了一遍。
**修正（但注意分寸）**：这段是本场核心喜剧节拍，**如果小动画资产做不出来，文字版反而是唯一载体**。建议：动画做得出 → 正文清空只留柯萝萝的死鱼眼台词；做不出 → 保留文字但砍掉「果冻一样」「哧溜」的拟态修辞，压成两短句。**这一处属于「资产依赖型」，标记为待定而非直接删。**

**❌ 问题 7：**
> // 就在她准备顺势倒下的刹那，沙发中间的一团黑泥精「（ぷよん）」地鼓起，硬生生顶住了她的额头。

同上，资产依赖型。`（ぷよん）` 保留。

---

### 【S1-6 满员餐桌】——问题 1 处

**❌ 问题 8：**
> // 少女无声无息地从高背椅上滑落，赤裸的脚底踏在地板上没有半分动静。她拖曳着长长的银白发丝与微乱的睡衣下摆，像只散步的家猫一样，径直朝着客厅中央的大沙发走去。

「滑落椅子走向沙发」是立绘退场移动；「像只散步的家猫」又是比喻代演。
**修正**：立绘淡出 + 脚步无声（=没有SE，静默本身就是演出）。正文只留一句功能性旁白交代**去向**（玩家需要知道她去沙发了，因为下一拍要出事）：「艾比希斯离席了。方向是沙发。」这种电报式短句反而带着不祥的节奏感。

**⭕ 保留项**：
> 「背景轻快的吉他旋律悄然淡出，窗外的海浪声仿佛沉入水底」——这是**音响演出指令**，位置正确（写在 // 指令行），不是正文问题。

---

### 【S1-7 断裂的平静】——问题 2 处（本场重灾区已在前次修正，残留如下）

**❌ 问题 9：**
> // 少女慢吞吞地低下头，凑到新毯子前嗅了嗅「……（くんくん/嗅嗅）」。随后，她脑袋向右微微一歪「（こてっ）」，转过身来。

「低头嗅+歪头+转身」三连是差分序列。但 `（くんくん）` `（こてっ）` 是角色卡钦定拟态，**必须保留**。
**修正**：动作行为拆到演出指令；拟声词以演技标注形式跟随立绘差分出现（差分切换时在角色名旁或立绘旁以小字气泡呈现——这是很多商业 ADV 的成熟做法），正文不再用完整句子描述动作过程。

**❌ 问题 10：**
> // 惺忪的睡意从那双猩红的眼眸里褪去，只剩下一片毫无起伏的深潭。

「睡意褪去的眼神变化」= 无高光差分的画面内容，「深潭」是替画面抒情。
**修正**：切【瞳孔无高光】差分，正文删除。这里最好的文字是**没有文字**——差分切换 + BGM 抽离 + 两拍空白，然后她开口。

**⭕ 保留项（本场最重要的保留）**：
> 「取而代之的，是一叠整整齐齐、**散发着全新羊毛油脂与防蛀草药味**的深蓝色备用毯」——气味！这是艾比希斯发现「不对」的核心感官证据，玩家看画面绝对得不到这个信息，**必须保留在旁白**。这一句是全场「文字不可替代性」的典范。

## 三、Scene 02 问题点排查

### 【S2-1 破窗与落地】——问题 2 处

**❌ 问题 11：**
> // 诺玛在湿滑的大理石地砖上滑出数尺，单膝触地刹停，胸口剧烈起伏。斗篷滴着灰泥，额角淌下一缕被碎石划破的血痕，但右手死死压在靴侧的短刀柄上。

前半（滑铲刹停、喘气）= 入场演出 + 带伤差分的画面内容。
**修正**：入场动画 + 带泥带伤差分承担。**但「右手死死压在靴侧的短刀柄上」建议保留**——这是一个立绘不一定画得清、且信息量极高的细节（她带着敌情回来的，进自己家门手还没离开武器），一句旁白点出，专业斥候的警觉立住。

**❌ 问题 12：**
> // 诺玛一把夺过，仰头灌得干干净净，袖口胡乱擦了擦嘴上的水渍与血迹。

喝水动作 = SE（咕咚声）+ 差分。
**修正**：SE 承担。正文可留半句「杯底朝天」级别的极简收束，或直接删。

**⭕ 保留项**：
> 「啪！一枚**带着海腥泥浆与扭曲齿印**的断裂车轴铁销，被她重重拍在餐桌正中」——拍桌是 SE+道具图层，但「海腥味、齿印」是近距离观察信息，玩家在全景立绘视角下看不清道具细节。**压缩保留**：SE 承担「拍」，旁白只写销钉上的细节（「断口上有干了的黑血」这个量级）。

---

### 【S2-2 情报挤压】——问题 1 处

**❌ 问题 13：**
> // 艾洛拉肩膀猛地一缩，下唇咬得泛白，紧紧按住了胸前空瘪的草药筐。

「肩缩+咬唇」= 受创差分。这一处**正是你截图批判的同类**：她此时的正文台词已经是「…………っ。」——完全正确的写法——但后面又跟了一整句旁白把差分内容念了一遍，画蛇添足。
**修正**：删旁白，「…………っ。」+ 受创差分 + 一拍静默，完。

**⭕ 保留项**：
> 诺玛「视线微微低垂，避开了艾洛拉的目光」——立绘视线方向的微差分很多项目做不了，且「心虚避视」是重要人物信息。**条件保留**（同问题 4 逻辑）。

---

### 【S2-3 死寂沉降】——问题 2 处（冷峰段，最需要洁癖）

**❌ 问题 14：**
> // 少女那头银白的长发脱离了重力，在空气中微微浮动；猩红的眼眸平静得没有一丝波澜。

浮发 = 威压差分的画面本体。「平静得没有一丝波澜」= 替画面定性。
**修正**：切威压差分，全删。此处正文越空，差分越吓人。

**❌ 问题 15：**
> // 咔。茶几一角坚硬的胡桃木像是被抽干了所有结合力，瞬间风化剥落成一片灰白碎屑。

**这一处要辩证看**：茶几角风化如果做成图层动画成本不低；且「被抽干结合力」的物理质感文字表达其实优于粗糙的图片替换。
**修正（折中）**：SE（干裂的「パキ……」声）必须有；文字压缩为最短白描：「咔。茶几的一角，无声地化成了灰。」删掉「像是被抽干了所有结合力」的机制解说——**现象保留，原理删除**。玩家不需要知道为什么，只需要知道木头刚才还好好的。

**⭕ 保留项（重要）**：
> 「窗外原本狂暴倒灌的海风仿佛撞上了一堵无形的墙，风声彻底归于死寂」——这是**音响演出**（环境音骤停），本身就该写在指令行。指令行写法没错，别误伤。
> 「地板下的木梁发出极其沉闷的咯吱声」——画面外的声音信息，保留（或转为 SE 指令）。

---

### 【S2-4 整备】——问题 3 处

**❌ 问题 16：**
> // 凯尔顺势解下腰间的粗布围裙，随手搭在椅背上。啪嗒。武装带的金属搭扣利落咬合，剑鞘沉稳地挂在皮带左侧。没有豪言壮语，唯有老兵临阵的熟练动作。

前面动作交给差分切换（围裙版→佩剑版立绘）+ SE。**「没有豪言壮语，唯有老兵临阵的熟练动作」是旁白在总结陈词、替玩家下结论**——这是比动作播报更隐蔽的病，叫「旁白抢答」。
**修正**：立绘切换 + 两个 SE（布料声、金属扣合声），正文全删。玩家自己会得出「这人很熟练」的结论，不需要旁白按头。

**❌ 问题 17：**
> // 尤斯缇丝顺手抄起挂在椅背上的长剑，剑刃在皮扣中顺滑归位。原本的烦躁全数敛去，只剩下将领的冷峻。

「烦躁敛去只剩冷峻」= 差分切换的定性解说，删。取剑 = SE + 差分。
**修正**：全段移出正文。她那句战术台词（「潮溜まりの岩窟ね……」）本身就是「切换成将领模式」的证明，台词已经干了这个活。

**❌ 问题 18：**
> // 艾洛拉快步绕进吧台，将两卷急救亚麻布和三瓶止血粉塞进腰包，双手死死握住纯金星盘圣杖。眼眶虽红，但站得笔直。

「眼眶红但站得笔直」= 差分内容 + 旁白抢答。收拾药品的动作可以简化。
**修正**：保留极简版「吧台后传来利落的收拾声」（画外音信息，合法）→ 艾洛拉入画（换战斗立绘）→ 她的台词「止血帯持ちました」自己完成了全部人物证明。

### 【S2-5 出门】——问题 1 处

**❌ 问题 19：**
> // 玛丽埃塔立在门廊内侧，手指微动，五道若隐若现的暗红细线如蛛丝般垂落，分别在五人的左腕上挽成一道无形的暗扣。

红线系腕是关键机制演出，应该做专门的演出资产（这是安全机制的教学时刻，值得花演出预算）。
**修正**：若有演出资产 → 正文删；若无 → 保留但砍掉「如蛛丝般」。**注意「左腕」这个细节无论如何要在某处可见**（后续战斗 UI 的归还线标识对应左手腕），这属于机制一致性信息。

**⭕ 保留项（本场典范）**：
> 「一小团指甲盖大小的深黑泥块贴着地面飞射而来，不偏不倚撞进凯尔腰侧的行军皮袋，**化作一小团安分的温热**」——「温热」是触觉，文字专属，保留。这一句和 S1-7 的「防蛀草药味」是全稿最好的两处「文字做文字该做的事」。

---

### 【S2-6 行军】——无问题

本段整体是演出指令段（// 开头），无正文，写法正确。「耳畔只有沉重、规律的靴底踩碎海沙与泥水的声响」是音响指令，位置合法。

## 四、汇总统计与处置分级

| 级别 | 数量 | 处置 |
|---|---|---|
| **A级：直接删除**（差分/SE 完全可承担，旁白纯冗余） | 问题 1,2,8,10,13,14,16,17 | 移出正文，转演出指令 |
| **B级：压缩保留**（动作删除，但痕迹/细节/速度感保留半句） | 问题 3,5,11,12,15,18 | 「动作给引擎，质感留文字」 |
| **C级：资产依赖**（有差分/动画则删，没有则文字代偿） | 问题 4,6,7,19 + 诺玛避视 | 标记待定，跟资产清单联动 |

**三条沉淀为写作规约的原则**：

1. **「现象保留，原理删除」**——茶几化灰可以写，「被抽干结合力」不能写；
2. **「动作给引擎，痕迹给文字」**——挂剑动作删，被磨亮的黄铜钩留；
3. **「旁白禁止抢答」**——「老兵的熟练」「将领的冷峻」「站得笔直」这类定性总结全部违规，结论必须由玩家从台词和差分里自己得出。

同时明确**反向红线**：气味（草药味/油烟味）、温度（黑泥的温热/额头的凉）、触觉（毯子硬）、画外信息（腰包里、吧台后、远处海面）——这些是 ADV 文字的不可替代领地，**一个都不许删**。删了这些，就从「亵渎视觉小说」跳进另一个坑：「把视觉小说写成纯演出脚本」。
