- 原1600×900舞台、PaperDoll、AVG／RP、差分与动作库继续复用；不另建教程专用战斗界面。
- 开场总览与实战手册共享[handbook.json](../../src/content/presentation/tutorial/handbook.json)：五章13节，含界面六区、五步操作、远征流程、骰面与倍率、道具／角色能力等。文案修改随热更新／构建生效，不写玩家存档或rp数据库。
- 规则总览在S3-1读完／跳过后显示，确认“开始战斗”才提交原教学阅读命令。查阅手册不改变玩法状态。
- 高亮与说明使用原控件锚点，在菜单、账本、物品、AVG及转场期间暂停。×只收起提示，保留目标与“继续教学”；下一步自动展开。明确“退出带做”才解除限制。

- 系统提示应完整、渐进，不恢复20字硬限；同伴战术对白与操作说明分工，不重复机械播报。
- 五张正式教学敌人PNG已接入；美术ID和资产位置见[退潮黑礁清单](../../src/assets/battle/tide-reef/README.md)。各战背景由[tide-cave.ts](../../src/content/presentation/tide-cave.ts)按该版前置AVG的终点决定，不照搬旧设计中的固定场地表。

## 4. 待办与G5验收

G1～G4与章一定稿已有工程证据；G5／O4-T真人试教仍未完成。下一步按以下清单验收，不把自动测试通过当作玩家学会：

1. 从完整开场与教学快捷起点分别试玩，确认玩家能找到骰子、意图、固定、角色和目标，并能解释下一步为何可做。
2. 检查从逐步带做到自主战术的交接、治疗／格挡／牌型与倍率的理解；记录卡点和提示干扰，不强迫玩家背术语。
3. 验证E1的单人判定、结果确认和战3衔接；不把多人事件提案当成已上线功能。
4. 覆盖失败后本场重试／整章重来、刷新恢复、手册往返、收起提示／退出带做、键盘与小窗口。
5. 从归来正文到手动领取走完一次真实结算，确认不漏奖、不双领、不凭跳过生成通关事实。
6. 单独评审角色口吻、剧情节奏、连续性和素材缺口；不等待rp后端或多人系统改造才做此批。

固定剧情的模型辅助制作归rp开发Session，但固定章节不会因AIRP接入而自动生成或写回。新章节作者任务须另定义并人工审稿，不存在自动批量写回游戏的承诺。
