# 洋馆基础设施：修缮、升级与补给节奏

日期：2026-09-25。状态：普通内容27／正式AIRP内容28已接入每周公款、首次修缮和两档升级。内容25／26的生产链继续沿用，旧档按原版本读取；不自动迁移、不追收旧设施费用。受损维修仍待具体事件，不在DEMO内开启。

沿用[补给来源与旧名称对应](MANSION_SUPPLY_PRODUCTION.md)：厨房产食物，温室产原料，工坊加工药水，SHOP提供现成药水；出征使用真实库存。工程只使用公款，商店与加工辅料费只使用小队资金。

## 1. DEMO每周公款

- 以**游戏日期**计，D1为周一；D8、D15等周一清晨再次到账，周期28时段。
- 第一次进入自由行动（正常教学领奖或快捷起点）发放 **500,000 G**，只发一次。厨房和储藏室已为Lv.1，不补扣初始建设费。
- 后续每周从 **450,000／475,000／500,000／525,000／550,000 G** 五档等概率选择。结果由存档初始凭据和周次决定，与现实时间、其他随机流、页面和请求重试无关。
- 已领周次、累计拨款与施工单从提交事实回放。刷新、读档、备份恢复和允许的普通档复制不重复领款，不重新抽金额。
- 余额结转；**公款只扣首次修缮和升级**，不转入小队资金，不买补给、不付鉴定费或制药辅料费。
- DEMO不加考核、断供、维护税、随机损坏、捐款或挪用系统。允许主动等待推进游戏日期；这是当前演示范围，不宣称已有完整经营压力。
- 到账、开工与完工复用通用侧上通知。房间面板展示公款余额、下一次周一日期、施工报价／工期／收益；进入页面不自动领款或推进时间。

## 2. 修缮与升级：一条成长线，另记受损状态

首版实装前两项；第三项仅保留未来规则方向：

| 操作 | 触发条件与结果 | 收费与用时建议 |
| --- | --- | --- |
| **首次修缮** | 待整备 → Lv.1；修好设备、恢复基础用途，只做一次 | 一份完整工程报价；2时段 |
| **升级** | 正常Lv.1 → Lv.2 → Lv.3；永久增加产能、批量或功能 | 每档一次报价，施工已含必要修整；分别4／8时段 |
| **维修（未开放）** | 明确事件导致受损后，恢复原有能力，等级不变 | 按原等级与损伤程度报价；轻损1时段／重损2时段 |

- **Lv.0＝待整备，Lv.1＝可用，Lv.2＝改良，Lv.3＝完备。** Lv.0表示该设施设备尚未启用，不代表角色无处居住，也不关闭该房间的日常会面与剧情。
- “受损”与“施工中”是状态，不是下一等级的经验条。Lv.3受损维修后仍为Lv.3；修三次不会自动升一级。
- 升级要求设施正常且没有未完成加工订单。受损时先展示独立维修报价；升级工程自身不再附送一串修缮前置步骤。
- D2／D3／D4分别开放温室、工坊、女仆工作间的首次付费修缮。重复损坏入口随具体灾害／剧情事件再接，**不设置按天衰败、随机坏房、日常维修税**。不为让减费Buff有用而强迫房间反复损坏。
- 施工由游戏时间推进，全馆同时只开一项建筑工程；玩家仍可出征或处理其他事务。下单不自动跳过全部工期，查看房间不消耗时段。
- 扩建期间保留原等级的基础产出与已生效能力，新能力完工后生效；未启用与重损设施停产。加工工坊须完成当前订单再开工，施工期间不接新加工单。
- 后续若启用损坏：轻损将该设施生产／加工周期乘2，重损暂停剩余进度；库存和完工待领物品不销毁，维修完成后恢复。既有携带位不因损伤减少；已开工工程不受新的随机损伤打断。

## 3. 补给频率与升级收益

一天沿用游戏现有晨／昼／昏／夜四时段。以下均为**游戏时间**，不按现实分钟、离线时长或进入页面次数计算。

| 设施 | Lv.1 | Lv.2 | Lv.3 | 频率与作用 |
| --- | --- | --- | --- | --- |
| 厨房 | 食物×2 | 食物×3 | 食物×4 | 每4时段一批；来自厨房分装备餐，提供基础恢复底线 |
| 温室药圃 | 原材料×3 | 原材料×4 | 原材料×6 | 每8时段一批；数量指所选种植项目的一种材料，不是每种药材各给一批，更不是药水数量 |
| 工坊 | 每单最多1份成品 | 每单最多2份 | 每单最多3份 | 玩家选配方、投入相应倍数材料，每单1时段；首批验证药水配方，工具配方核定材料后再接 |
| 储藏室 | 4种补给携带位 | 5种 | 6种 | 永久解锁；同时提高材料与成品储备容量，不定时产出物品 |
| 女仆工作间 | 工程费用－5% | －10% | －15% | 设施正常时提供全馆后勤减费，不产补给 |

这套成长先增加“每批有多少／一次能做多少”，不把厨房与温室升级成一时段一收，也不增加现有药水或食物的单件治疗强度。工坊高等级每份耗材不变，不自动减免药材。配方是否可用还取决于实际取得的配方；工作台等级与配方收集是不同条件。

### 3.1 完成、收取与满仓

1. 厨房、温室每处只保留**一批待领取产物**。到期后停在“可收取”，收走才开始下一轮，不补发积压天数。升级在途的一批沿用开批时的数量，新一批才采用新等级。
2. 工坊首版一张订单、一个配方，不自动循环、不排无限队列。确认时扣材料并预留成品空间，完成后领取；订单期间不能再拿同份材料合成或出售。首版不提供开工后取消，失败／重复提交均不得重复扣发。
3. 待领物品不衰败。仓库空间不足时留在设施，允许一次领取可放入的数量，余量领取完才重新开批；订单占用的预留空间须从剩余容量中扣除。
4. 收取用通用侧上获得提示，同次多种产物可以叠加；提示只在取得库存的操作成功时出现，读档和再次打开房间不重播赠物。
5. 原材料容量与成品容量独立配置。储藏室每种原料上限12／24／36份；每种战术补给上限为该物品**单次携带上限的3／4／6倍**。这与携带种类位4／5／6分开。装备和剧情物品不套材料数量上限，仓库分页也不是容量。
6. 出征需可选实际携带数量，仅扣除所选数量，剩余留在馆内；补给返还要保留位置。副本带回的合法奖励若超过容量，进入待整理领取区，不能删去结算成果；待整理只接系统返还／奖励，不能充当购买或生产的无限仓库。

### 3.2 SHOP与时间边界

- 药水为常驻商品，不掺进九件装备的随机轮换。首版延续现有基础补给的供应方式：**无商人每日售罄限制，购买受资金和馆内库存容量限制**。售价与配方仍须配平。
- 买药是及时获取成品，温室加工作坊是定期利用原料。修好工坊不改变商店的刷新日期，也不自动领取商店商品。
- [现行战役推进](../../src/game-core/session/d5-progress.ts)在远征结算领取时前进一个时段，主动等待也前进一个时段。设施应接统一时钟；一趟四层战斗不应额外按四层收四次生产。
- 不加离线收入。读档、页面切换、浏览仓库、重复收取、普通购物均不推进生产；新游戏的一次性初始库存与教程奖励单独记录。
- 当前时间尚未具有完整经营压力。因此“等待取得有限补给”是有意保留的失败后恢复路径，不能声称上述周期已经解决经济配平。首版不开放自产原材料／补给的额外批量回收赚钱渠道，现有普通战利品出售规则继续有效。

## 4. 是否越来越贵

**升级逐档变贵；维修不按历史次数涨价。** 同房间、同等级、同损伤，未打折报价相同。日期、小队资金多少、修过多少次都不影响基础价格。

每间房独立基价`B`是Lv.1→Lv.2的未打折费用；首次修缮为0.25B，Lv.2→Lv.3为2B。

| 房间 | 首次修缮0→1 | 升级1→2 | 升级2→3 |
| --- | ---: | ---: | ---: |
| 厨房 | 50,000 G | 200,000 G | 400,000 G |
| 温室药圃 | 65,000 G | 260,000 G | 520,000 G |
| 工坊 | 60,000 G | 240,000 G | 480,000 G |
| 储藏室 | 75,000 G | 300,000 G | 600,000 G |
| 女仆工作间 | 20,000 G | 80,000 G | 160,000 G |

厨房／储藏室初始Lv.1，首次修缮价只作为规则完整表，不另收钱。女仆工作间独立降价：它主要提供折扣，不能用普通产能设施的基价而失去建设价值。

工期依次为2／4／8时段，开工一次扣清并锁价，完工提升一级；不提供取消、退款或重复点击连升。命令核验房间当前等级和报价，过期报价不能购买下一档。施工不自动快进，使用统一游戏时钟，等待和远征结算均可推进。

五个房间从Lv.1全部升至Lv.3，未打折合计 **3,240,000 G**；先把女仆工作间升满后做其余升级，合计 **2,790,000 G**。从实际新档起点计算，还需温室／工坊／女仆的首次修缮：不打折总计 **3,385,000 G**，优先后勤的最低路径约 **2,916,250 G**。以每次平均500,000 G估算，约6～7次拨款（含首款，约5～6游戏周）；低额拨款或较晚建设后勤可能更久。这是预算基线，尚非完整玩家平衡验收。

公款与小队资金分别扣账；旧原型工坊／武备库的`party`字段不具备正式建筑付款权限。其他生活房间不增加无功能的收费升级。未来损伤维修才考虑轻损0.05B／0.075B／0.10B、重损双倍；本版不扣这部分钱，结界专项大修也不开放。

## 5. 减少修缮成本的Buff放在哪里

**使用女仆工作间`maid`，承担统筹修缮。** 它是现有设定中的地下后勤中心，已有修缮提案和全宅排班内容，所需语义与图面都比另建一个“管理所”自然。

- Lv.1／2／3分别减少符合条件工程的G费用5%／10%／15%，同一间工作间只取当前一档，不叠加三档。
- 作用于其他自有设施的首次修缮、升级和普通维修。结界专项大修是否适用由将来的专项工程规则决定，不默认套用。
- 不作用于工作间自身工程、工期、配方材料数量、SHOP价格、鉴定费、补给购买或人物奖励。缇比的店和私人码头不是玩家自有施工项目。
- 工程下单时锁定折后价并一次支付，`实付G＝向上取整(基础G×(1－折扣))`；之后升工作间不返差价。可选材料需求若以后增加，不自动受G折扣影响。
- 工作间受损时停止提供新订单折扣，已开工订单不补收差价；扩建期间沿用旧等级折扣。角色在不在房间不影响已建立的后勤能力，不强迫玛丽埃塔驻守而不能出征。
- 首版仅此一个通用工程减费来源，上限15%。禁书库负责知识，工坊负责加工，沙龙保留外务；不让三个房间叠相同折扣。

例如未打折200,000 G的工程，工作间Lv.2后报价180,000 G。要不要先修工作间取决于后续建设量，它不成为所有房间的强制前置。

## 6. 其他基础设施如何分工

| 现有房间 | 建议功能 | 本轮边界 |
| --- | --- | --- |
| 厨房 | 备餐，定期产出可出征食物 | 首批核心；生活用餐与战术库存分开，不模拟全宅饥饿 |
| 温室药圃 | 种植、收获真实药材 | 首批核心；保留净光草名字，具体药水材料需核对，不能只凭种植位置指定其治疗效果 |
| 工坊 | 制药及工具加工；按配方消费材料 | 首批核心；制药台需补设备美术；不增加现行不存在的装备耐久维修 |
| 储藏室 | 原料、成品库存；出征取用；4→5→6种携带位 | 首批核心；移除“外围补给”定时产出 |
| 女仆工作间 | 全馆工程单与修缮折扣 | 已接入修缮／升级报价；不减自身费用 |
| 武备库 | 接入已有配装、装备保管和六面预览 | 复用现有角色引擎能力，不额外付费才允许使用既有装备位；本轮无独立产出／升级线 |
| 禁书库 | 配方和技艺记录，后续作为新配方的研究入口 | 基础药水配方随制药台开放；高级配方可来自探索／事件／研究，研究成本与等级另定 |
| 结界核心室 | 领地结界状态、异常与大修入口；未来承担防护 | 与事件／结界系统一起设计；本稿不指定随机损坏减免率，也不把核心当护符生产机 |
| 沙龙 | 外务、工程委托及未来公款事务的叙事入口 | 未来若接供应商协商，应是具体订单内容；首版不另加全局减费；拨款由游戏时钟处理 |
| 瞭望台／岗哨厅／正门 | 警戒信息、出征与领地事件入口 | 后续预警须有真实事件支持，不自动奖励额外战斗属性 |
| 浴室／洗衣房 | 生活照料、休整场景 | 当前无持久疲劳和衣物耐久系统，先不编造必须付费清除的负面状态 |
| 餐厅／大厅／娱乐室／露台／酒窖 | 用餐、会面、娱乐与人物事件 | 不为填满设施表而逐间塞生产或永久Buff |
| 卧室／守望小屋／小广场／门厅 | 居住与日常互动 | 保持生活场景；不把角色卧室改成合成房或全局Buff设备 |
| 阁楼观星室／封印之门 | 前者职能待定，后者保持封闭剧情边界 | 不据现有美术直接开放占卜、稀有资源或永久加成 |
| SHOP／小码头 | 商店已有销售与日期上新，码头保留现有入口 | 属缇比经营，不纳入玩家自有设施升级树 |

此前“结界记录改为护符产出”只是助手建议，未获确认。**本稿建议不纳入首批生产链**：结界记录属于观测信息，护符继续由商店提供；未来若加工护符，要有材料与配方，不能仅改名字就转成战术补给。

## 7. 版本、验收与后续范围

内容27／28新档：厨房、储藏室初始Lv.1；温室D2、工坊D3、女仆工作间D4起可申请首次修缮，人物活动不受设备等级影响。旧内容25／26保留当时的免费启用与无拨款规则；更早版本继续按其库存／携带约束运行。本次没有跨内容版本迁移入口。

规则来源：[内容27](../../src/content/gameplay/demo-v27/content.ts)、[施工报价](../../src/game-core/session/facility-construction.ts)、[设施与拨款回放](../../src/game-core/session/facilities.ts)。拨款和工程均在同一次存档事务中提交，不由前端定时器写余额。

定向验收覆盖：首款与周一到账、刷新／导入／恢复、写入前后故障重试、折扣与不足额、单工程互斥、完工生效、旧批次不膨胀、工坊订单互斥、出征归来跨周、正式AIRP出征，以及房间按钮／侧上通知的DOM交互。遵照当前验收要求，不录屏、不做视觉验收，不调用在线模型。

后续仅在有真实内容时再接事件损伤、结界大修、高级配方与研究。制药设备美术仍待定稿。公款考核与断供不属于本DEMO。
