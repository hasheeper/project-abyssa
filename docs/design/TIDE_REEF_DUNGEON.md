# 潮声溶洞／退潮黑礁路线与资源合同

更新：2026-09-25。普通路线从内容20起接入，当前27／28继承；内容21后的物品改用[正式随机表](ORDINARY_DUNGEON_DROPS.md)，不再沿用内容20的五次固定掉落。教学仍是四层，普通路线是三层。

## 1. 身份与素材

地图目的地为潮声溶洞，美术批次为退潮黑礁。资产名只描述图中实体，类型名可跨地图复用，地名／阵营／称号只放实例数据。正式命名见[资产合同](ART_ASSET_NAMING_CONTRACT.md)。

复用浊泥史莱姆、刀手、弩手、扛夫，新增硬壳礁蟹和藏壳海蛭；普通路线不重复使用教程匪首「礁钩」或三件货。`bg.tide-reef.shore`用于浅滩，洞内使用现有溶洞背景，`bg.tide-reef.boardwalk`用于末战；货台背景保留教学剧情用途。地图使用`map.tide-reef`，不在立牌加入天空／月亮／海鸟。

## 3. 敌人机制与首轮数值

以下值已写入内容 20，完成固定种子可通关验证；**尚未进行多种子与多编队的正式平衡评估**。以现有基础五人队、不依赖付费补给为可通关验证起点；继续允许玩家用现有编队选择调节难度。

边界：

- 「前排铁罐头」是美术／定位比喻。当前战斗没有强制前后排保护，本轮不承诺蟹能替海蛭挡刀。
- 封骰使用现有目标选择规则，不写成「必封最高点数」或「潮水逐渐永久吞骰」。意图说明必须明确生效在下一回合。
- 不为海蛭添加开花口器、寄生人体、撕裂或可见内脏表现；一只、低血量、干扰为主。
- 教程的 HP、赏金与固定引导种子不受普通定义调整影响。新的 G 数值直接按铜填入，不再乘一次 100。

## 4. 资源与边界

普通场景只放残骸／空容器，不画可捡的完整箱袋；完整货物仅用于有剧情依据的教学货台。藏壳海蛭使用缩壳讨嫌方向，首层不透支人体／内脏恐怖元素。红布只作视觉伏笔，不据此新增走私团剧情。
