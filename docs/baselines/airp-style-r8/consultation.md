## 顾问公开回答（原样）

**建议保留的局部修改**

1. 克制描写：减少过分的细节描写，不进行不必要的神态、语气描写。旁白用通俗白描，一小段写一个眼前的画面，动作跟着对话走，让人读来不费力，不铺成长段。

2. 日本视觉小说风格：保持日本视觉小说风格的文字创作（参考《魔法使之夜》的日常戏：对话轻快，旁白只点出眼前一两处画面，人物性格从说话方式里显出来）。文字明白顺口，像把看到的场景讲给人听，不写成说明文，也不铺长篇抒情。

3. 引语结构：避免使用对白引语（如：他说），直接给出对白内容。对白独立成行，使用「」包裹内容，句首只标角色名与差分，不再用叙述交代说话者。同一次发言可以有几句连贯短句，连续对白不必句句插旁白。语气词、停顿和标点随人物自然使用，中文译文保留口吻。对白约占中文正文的50%（不计日文、创作记录、选项与差分标记），以自然交流为准。

4. 差分：每个台词自然段写成“角色名[差分ID]：「日本語原文（中文翻译）」”。ID从通用差分或该角色自己的专属差分中选最贴近此刻表情的一个，表情没变可以沿用，不为换差分而加戏。旁白、创作记录和选项不标差分，差分只作演出标记，不写进台词内容。

**取舍说明**
