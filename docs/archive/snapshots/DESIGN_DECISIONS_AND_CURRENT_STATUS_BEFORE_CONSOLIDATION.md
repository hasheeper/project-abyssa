## 1. 如何读这份讨论

原文件是连续讨论记录，混合了四种东西：旧版本盘点、用户贴出的定稿、助手解释，以及新提案。助手的赞评或“全线完成”表述不等于用户确认。

设计状态与实现状态分开判断：

- **已定稿**：用户明确提交冻结文本，或明确指定范围。
- **方向已定**：原则成立，具体条款、数值或内容仍留待设计。
- **提案**：供讨论与模拟的方案，不自动升级为定稿。
- **待对齐**：前后版本、同一文件条款或设计与数据之间存在缺口。
- **已实现／已有底座／未接入**：只描述代码，不表示设计是否通过。

同一范围发生冲突时，后续明确修订覆盖早稿；未被修订的内容继续有效。跨范围的冻结不互相扩大：骰面冻结不意味着铭约、装备、Boss 与剧情一起冻结。

## 2. 已定稿的作品定位与内容结构

### 2.1 叙事优先

作品是围绕守望者之崖共同生活展开的治愈群像。秩序与混沌、大天平、伪典圣战、凯尔与艾比希斯的关系，以及勇者小队与四天王的共同体，继续作为世界与人物基础。

游戏循环承担三项任务：展示角色、提供成牌与战术满足、产生能回到洋馆生活中的真实经历。

明确保留的原则：

- 日常出征面对的是已有强大实力、但受性格与心结影响的角色。
- 成长主要表现为羁绊加深、命数苏醒与力量恢复。
- 不以永久死亡、重伤报废和高压资源损耗推动循环。
- 战斗不能被当作自动治好心结、证明凯尔永远正确的工具。
- 普通刷取和构筑试验可以只是工作，不要求每趟都承担重大情感剧情。

### 2.2 三轨并行

| 内容线 | 正式职责 | 边界 |
| --- | --- | --- |
| 当下冒险 | 主题副本、异变、委托、搜打撤和资源获取 | 固定规则与内容，允许受限的事件组织；当下关底使用独立敌人 |
| 角色回忆篇 | 亲历历史交锋，展示四天王本尊 Boss，开放角色操作 | 手写剧情与确定性战斗；短篇结构，不复制完整地牢 |
| 洋馆日常 | 经营、生活交流、关系延续、冒险后反馈 | AIRP 使用既定设定与真正发生的事实 |

洋馆从开局就是据点。四天王已经存在、合作、履职；未完成角色篇章，只限制玩家的亲征操作与相关功能，不解释为尚未认识、尚未收服或拒绝信任凯尔。

一周目完成角色篇章后开放亲征；二周目可以跳过已经完成的篇章。回忆失败只重试片段，不损耗当下资产，不改写既定历史，也不写成今天又一次败北。

回忆后的赠物、功能开放与互动发生在当下。奖励不必是毕业专武。

阿尔薇特移至后续章节，其既有骰面和战术设计仍有效。累计已有七人的六面设计；其中当前 DEMO 使用六人、36 面，阿尔薇特六面留待后续接入。

艾比希斯不进入普通四人自选席，保留特殊魔王亲征方向。缇比不入队，保留中立商人与隐藏 Boss 方向。两者和全力模式均不在原六人战术全案的冻结范围内。

## 4. 战术五层：哪些已经明确

### 4.1 五层分工

| 层 | 已明确的职责 |
| --- | --- |
| 骰面 | 点数、战面、命数、品质和花色描述角色；主副花色通常按 4／2 分布 |
| 铭约 | 成牌后的自动角色效果；不修改牌型倍率与底盘 |
| 好感成长 | 永久唤醒命数与提升品质；奇数级铭约、偶数级磨骰 |
| 契约物 | 改战面动作、强度或非牌型规则；不越权改点数、花色、永久命数与品质 |
| 编队共鸣 | 由带谁出门触发；战中自动生效，不增加操作 |

基础动作收敛为攻击、格挡、治疗、空面、万能；偷钱退出基础面，转为装备等特化效果。玛丽埃塔补入专属顺劈和束缚规则。

两种万能必须区分：

- 凯尔：战面可选攻／防／医，命点可代 1–6，不能代花色。
- 诺玛：只在战面上选攻／防／医，仍以原生 1 点参与成牌，不能代点。

早期“万能都可百搭点数”的笼统说法已被后续独占规则细化。

### 4.2 铭约

牌型结算后、敌方行动前自动执行。倍率只取一个最高牌型；铭约则按图案存在性独立判定，可同时满足多约。每约每回合至多一次，不因派生效果循环触发其他约。

持约者未力竭、未封锁即可，不要求其本人骰面参与成牌；目标自动决定，不增加手选目标步骤。

| 角色 | 条件 | 效果方向 |
| --- | --- | --- |
| 尤斯缇丝 | 同花 | 对最高攻击威胁造成伤害；终铭追加击杀后的布防 |
| 艾洛拉 | 三条，按约定宽判 | 治疗伤员；后续净化、溢出治疗成盾 |
| 柯萝萝 | 小顺，大顺也触发 | 重压最适合击杀的敌人；终铭追加伤害溢出 |
| 诺玛 | 两对且有朝上空面 | 随机飞刀；终铭追加一次击杀补刀 |
| 阿尔薇特 | 两对，按约定宽判 | 给危险意图加格挡；保留供后续章节使用 |
| 玛丽埃塔 | 葫芦 | 敌方阵位重排已定；初铭／现行参数待细化，Lv.5 后续 |
| 凯尔 | 无成牌触发铭约 | 静谧之楔与守护能力常驻 |

旧表的结算顺序包含阿尔薇特，没有定义玛丽埃塔加入后的重排时机；对象现已确定为敌方阵位，但具体时序不能从旧表自动补写。

### 4.3 成长与装备

成长通则：

- Lv.1／3／5 对应初铭、现行、重铭与终铭词条。
- Lv.2／4 分别提供两个骰面升级点，按已列逐人表使用。
- Lv.4 验收普通可成长角色沉眠为零、永久锈不超过一面。
- 唤醒不把空面改成攻击或治疗；空面改写是装备构筑的另一回事。
- 凯尔的可除锈面走晶石线；永久锈不是力竭损伤，不能用保养工具去掉。

装备槽位定为专武、小件、通用槽各一。原全案已有六套专武与小件，以及五件通用装备；阿尔薇特移出 DEMO 后，她的装备保留为后续内容，不等于自动得到一套玛丽埃塔装备。

原表的专武包括家传刺剑、无铭之剑、星盘圣杖、拉普拉斯星盘、无限制武装和贯神枪；采用双效面、蚀毒、连斩、局内成长等规则。它们是已写出的设计，尚不能据此宣称正式装备系统已经接入。

| 面位 | 名称 | 效果 | 命数／品质／花色 |
| --- | --- | --- | --- |
| 1 | 横扫 | 主目标 2，右邻 1 | 醒／永久锈／尘世 |
| 2 | 回扫 | 主目标 2，左邻 1 | 醒／素／尘世 |

### 4.5 编队规则及换人后的重新核算

花色词条按主色或副色持有者至少四人计；同一人同一色只算一票。凯尔计花色，不计勇者小队／四天王身份票。词条使用单档门槛。

已写效果包括：

- 圣辉·列阵：每战斗第一回合，所有指向我方的攻击意图各加 2 格挡。
- 尘世·市井之道：清层入袋增加 10%。
- 雨夜之盟：勇者小队四席齐全时的力竭保护与归队加成。
- 四席威压：至少一位四天王在场，每战斗首回合敌方攻击意图伤害各减 1。

以下是依据最新六人名单计算的结果，不是新改规则。只考察凯尔＋四名队员的满编亲征：

## 5. 已定稿的地牢与常备包框架

### 5.1 地牢、力竭与失败

固定出口层与非出口层的结构已经确定：通过出口守门人才能主动撤离，继续深入意味着承担一段有限承诺。庄园采用第 3 层中继考核、第 5 层 Boss 的分工；具体场次与敌群仍待按[新版设计稿](../../design/OLD_MANOR_DESIGN.md)复核。

每层可以含战斗、事件、宝箱和休整节点。事件复用角色骰：战面专业匹配优先，命数弱判定托底。

收益预期改为模糊的环境指标，当前战斗的决策信息仍需清楚；具体界面替换尚未实现。

普通挫折的基线：

- 战后不自动满血。
- 力竭是退场与受挫，后续战斗以低血归队。
- 新增退化只属于本趟远征；离场清除，不转成永久创伤。
- 普通回馆至多产生心结、闭门复盘等日常；不使用强制重伤住院作为日常经济压力。
- 主动出口撤离保留收益；全员退场保留此前成果、丢失本层未入袋奖励并承担金币损失。

“金币减半”的资产范围尚需最终统一；庄园 v0.1 建议只扣本趟金币、不扣洋馆旧存款，但该澄清仍属于提案。

全力模式的框架方向保留：特殊强敌场景短时解限，不另造第二套骰子；只有全力倒地才有真正疗养代价。具体积累、解限、LLM 许可接口及 DEMO 是否启用未在战术全案中冻结。庄园 v0.1 建议首版不启用，不能将此建议写成用户已确认的排期。

### 5.2 七件常备道具

| 道具 | 已定效果 | 生产／取得 |
| --- | --- | --- |
| 食物 | 单人回复 1；每人整趟最多两次 | 温室食材，经厨房加工 |
| 药水 | 单人回复 2；受充能限制 | 商店 |
| 护符 | 一条攻击意图加 2 格挡 | 女仆工作间 |
| 圣水 | 优先解除封锁，否则净化一项负面 | 温室原料调制，原料也可购买 |
| 保养工具 | 清一人的一面远征内临时锈蚀 | 工坊 |
| 幸运符 | 本回合增加一次重掷 | 商店 |
| 卦签 | 下一层情报，或事件选项的判定与代价 | 禁书库 |

储藏室槽位按 4→5→6 成长，七件永远不能全带。卦签归书库，结界核心不再生产卦签，其防御职责另议。

道具不占骰、不占行动，战斗中每回合最多两件；不得复活力竭者，不改永久状态、点数和花色，不绕过非出口层撤退限制。各道具仍按各自使用时机执行，不是所有道具都能在任何阶段使用。

设施产物未用完可以带回；购买品使用后消耗。设施升级提高对应配额，具体成本与充能需要配平。初始 4／2／2／2／1／1／2 是占位表，不应当作最终数值。

## 6. 克雷格旧庄园：美术修订后的当前状态

以[新版设计稿](../../design/OLD_MANOR_DESIGN.md)为准。旧 v0.1 中迎宾衣橱、纯家具长桌 Boss 和屏风管家的小怪席位已作废；旧 HP／敌群预算不能直接套给新版。

### 6.1 已确立的内容

主视觉为白布、黑木、红线；红线是唯一强饱和色。普通怪、守门人和当下 Boss 被头顶红线吊住；玛丽埃塔本尊从指尖向外执线。畸变来自家用器物取代身体与错误体态，器物比例保持写实。

规约自行运行，污染的是解释核心。“备好家宴”被越权执行成“补齐宾客”。权限锁、入座锁和工程锁共同解释玛丽埃塔为何无法独自取消家宴。主题是“规矩比人活得久”。

| 维护／回忆最终Boss | 刻仪兽；2026-09-07已确定席位，替换规则与脚本待补 |
