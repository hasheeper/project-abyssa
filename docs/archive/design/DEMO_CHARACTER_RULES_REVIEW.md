## 2. R01：行动结束以后，谁还在牌桌上

**建议**：同一枚骰有两个独立资格：能否执行战面、能否参与成牌。朝上、骰主未力竭、未封锁且命数醒的面可成牌；固定、已经行动、动作为空不取消成牌。沉眠只排除点数／花色，不排除行动。

| 情况 | 行动 | 成牌 | 建议理由 |
| --- | --- | --- | --- |
| 玛面 6 沉眠绞杀 | 可以，未用时 | 不可以 | 保留天王白值与牌型经济的交换 |
| 尤面 6 在 Lv.2 苏醒 | 仍为空面 | 可以，点数 6／圣辉 | 成长补的是出勤，不是凭空获得新攻击 |
| 已使用的醒攻击面 | 不能重复行动 | 可以 | 不能让认真战斗反而丢牌 |
| 当前被封锁 | 不可以 | 不可以 | 圣水解除后按当前未用／已用状态恢复资格 |
| 骰主力竭 | 不可以 | 不可以 | 不凭保留的画面加入成牌 |

另需明确终结最后敌人的时点。推荐保留当前完整回合收束路径：不在每次击杀回调里额外结算牌型；同一回合只在唯一收束点入账一次。玩家清空敌人后能否继续治疗、使用道具或重掷，须明确选择：建议立即进入不可追加行动的收束，避免把空战场变成免费整备回合。后者是新增建议，不能直接沿用为定稿。

## 3. R02：同花、品质与凯尔万能点数

建议首发同花采用 **四个自然同色的有效面，基础加成 +0.6**。五个同色但不连续时只取最优四个贡献面；品质只计算最终贡献者，金 +0.1、素 0、锈 −0.1，修正结果最低 0。

同花顺存在两种可选范围：

| 方案 | 规则 | 影响 |
| --- | --- | --- |
| 首发仅同花（当前建议） | 同花已使花色与尤铭约成立；同花顺本次不加入 | 少一项未配平的高倍率，首发可聚焦基本构筑 |
| 同时加入同花顺 | 五个自然同色且点数为 1–5／2–6；`+2.4` 作为模拟起点 | 多一个高阶回报，需补优先级、万能点和平衡用例 |

这两个倍率来自旧总规格的提案，不是用户已冻结数字。不能因为写进此表就出现在正式 Catalog。

建议候选比较依次为：基础加成高者→最终贡献品质高者→固定牌型顺序→解析点数组降序→固定花色顺序→队伍稳定槽位→面位。先选基础牌型再看品质，还是以最终修正收益择优，是本组需要明确的一点；这里推荐前者以保持“更高牌型”的可解释性。

凯尔面 6 的代点只在这次牌型求解中确定，保存为回合快照；之后所有铭约使用同一个代点，不为每份铭约再任选一次。即便同花不使用点数，也需用统一的稳定规则锁定代点，不能让成牌与铭约各自给他不同的数字。

例：诺玛面 1 只能按 1 成牌，不能为了凑三条改成 3；凯尔可代 3，但花色仍为圣辉，不可补成第四枚尘世。

## 4. R03：宽判铭约与“有人在摆烂”

已有两对／三条的宽判保留；不能用最高牌型名称直接判断所有铭约。建议以同一份有效骰快照建立独立布尔结果。

| 有效点数样例 | 诺的两对条件 | 艾的三条条件 | 玛的葫芦条件（建议） |
| --- | --- | --- | --- |
| 1,1,2,2 | 是 | 否 | 否 |
| 1,1,1,2 | 否 | 是 | 否 |
| 1,1,1,2,2 | 是 | 是 | 是 |
| 1,1,1,1（只有四个有效面） | 是 | 是 | 否 |
| 1,1,1,1,2 | 是 | 是 | 是，作为五面高阶包含 |
| 1,1,1,1,1 | 是 | 是 | 是 |

玛的后两项是**新增推荐**：保留五个有效面成本，又让更高重复牌型不失约。另一种清楚的选择是仅真正 3＋2 满足葫芦；二者都能实现，需要选定，不能混用。小顺被大顺包含；同花检测独立于最高点数牌型。

诺玛的附加条件推荐读取“存活且未封锁者的当前朝上战面是否为空”，**允许沉眠空面满足附加条件**。成牌点数仍只从醒面获取。装备把该空面改成攻／治后，它就不再喂空面条件。

例：其他四骰已形成两对，柯的沉眠空面朝上，诺可以触发；柯力竭或空面被装备改写后，该附加条件不成立。这个条件会直接改变空面装备的价值，必须与 R07 一起确认。

## 5. R04：顺劈与提线的边界

建议一次顺劈在命令通过校验时锁定主目标与当时邻位。`A-B-C` 中对 B 右顺劈：B 死后队列收拢，但本次仍打 C；下一次攻击才读新邻接。不对缺失邻位补找其他目标。

提线建议采用冻结骰面稿的绝对上限 6，生命 +1 小件暂不进入首发，以免同一能力同时声称“绝对 6”又可以吊起 8。

以玛 maxHP 3 为例：

| 敌人当前／最大 HP | 当前状态 | 建议判定 |
| --- | --- | --- |
| 5／10 | 未严格低于一半 | 常态门槛 5，可提 |
| 6／12 | 恰好一半 | 不进入重伤档，超过 5，不可提 |
| 6／13 | 严格低于一半 | 重伤门槛 6，可提 |
| 7／20 | 重伤但超过绝对上限 | 不可提 |

建议状态收口：定身本轮，取消行动但保留蓄力；挣脱本场，同一敌人只被定身一次；缠线直到绞杀命中消费或该实例结束。重复挂线不叠层，多个敌人可各有线，有挣脱仍可挂线。

绞杀的 +2 和消费应属于同一已成功动作；被拒绝命令不能先删线。未来出现零实际伤害的防御时，建议以“合法命中”而非“扣了至少 1 HP”决定消费，避免对特殊防御无限保留强化。若不接受，需写出替代语义。

## 6. R05：下一场归队与下一层归队

原文有两个不同边界：基础“下一场 1 HP”；雨夜之盟“下一层 2 HP”。一层多战后它们不再等价。

**建议保留字面差异**：基础在下一场归队至 1 HP；雨夜之盟为本场力竭者登记下一层回到至少 2 HP 的标记。已治疗到更高血量者不被降血，maxHP 低于 2 时按实际上限处理。

例如第二层有 A、B 两场：A 力竭后进 B 以 1 HP 归队；进入第三层时兑现雨夜标记至至少 2 HP。若第一层只有一场，则下一场正是下一层，直接以 2 HP 归队。

另一种方案是将雨夜改成“下一场 2 HP”，实现简单但改变原冻结措辞，应明确修订，不能趁一层一战看不出差异而悄悄替换。

本组另有两项必须定：

- “其余成员格挡 +1 至本场结束”到底改动作强度、角色通用盾还是每条意图？推荐存活成员获得本场格挡动作 +1 的状态，同一角色不叠多层，已施加的格挡不追补；这是解释提案。
- 局内退化怎样选面？推荐使用确定的受影响面记录，带来源和持续期；不能只存一个 rustLevel 便丢失原面品质。选面规则、重复倒地与全锈上限仍需讨论，保养工具必须能明确选择／指出清的是哪一面。

## 7. R06：初铭、现行与结算顺序

首发现在可达 Lv.3，必须同时覆盖初铭与现行。先明确基础目标，再实现现行的数值／数量扩展；Lv.5 的溢出递推、见血补刀等终铭不进入本次范围。

| 角色 | Lv.3 现行（沿用既定表） | 本次需要覆盖 |
| --- | --- | --- |
| 尤斯缇丝 | 2–4 伤 | 持久 RNG、目标选择和随机范围 |
| 艾洛拉 | 1–2 名各治 1，并净化最低血者一项负面 | 互异目标、目标不足、净化名单及先后；不能仅加治疗数量而漏掉净化 |
| 柯萝萝 | 1–2 名各 3 伤 | 互异目标、目标不足、击杀后的合法目标；不提前加入溢伤贯穿 |
| 诺玛 | 2–3 把飞刀，各 1 伤 | 数量抽取与逐刀独立随机；不提前加入击杀追加刀 |
| 玛丽埃塔 | 敌方阵位重排的现行阶 | 具体自动策略、范围与初铭差异待机制卡，不编造数值 |

以下初铭目标算法继续作为细则建议，不因本次范围定稿而自动全部确认：

| 初铭 | 推荐目标算法 | 需要保留的边界 |
| --- | --- | --- |
| 尤 2 伤 | 按当前修正后、尚未扣格挡的最高单条攻击意图选敌；平局按敌阵位；无攻击意图则选最低 HP 存活敌人 | 不是 UI 自选；击杀后后续约读新的敌群 |
| 柯 3 伤 | 有可击杀目标时优先其中 HP 最大者，再按威胁／阵位；都不可击杀则取最低 HP 者 | 自动目标需能用同一 selector 解释，不能写“最优”却不定义排序 |
| 诺 1–2 刀 | 刀数在 1、2 均匀抽取；每刀从当前存活敌人均匀抽取，可重复命中 | 每刀死亡先处理再抽下一刀；持久 RNG，拒绝／重试不多抽 |
| 艾治 1 | 存活者按当前 HP 绝对值升序，再按稳定队伍槽位；选最低者 | 不复活；全满血时空过；晚期溢光成盾另定义满血目标 |

保留尤→柯→诺→艾的现有设计顺序。玛插入位置必须由 R08 的实际用途决定，不能先塞一个无效果空步骤冒称完整五约。触发集合从同一回合快照读取，实际目标随先前已发生的伤害变化。

还需在定稿时核对：初铭持有者在判定时未力竭／未封锁；同一约一回合最多一次；派生效果不再次触发铭约；目标全部消失时结束剩余无目标效果，不产生负数量或无穷抽取。

## 8. R07：首发成长与配装范围

**已定：五名可成长角色提供 Lv.1→Lv.2→Lv.3；只提供备用短刃、应急药囊两件空面装备。** Lv.2 沿用原醒面／品质奖励，Lv.3 进入现行铭约；不提前应用 Lv.4 全醒、Lv.5 重铭或终铭。

凯尔不套个人好感等级；既定“任意两人 Lv.3，面 4 护卫素→金”现在必须可达，且只能生效一次。该变化仅改品质，不把护卫的战面强度再次增加。晶石除锈／无铭之剑不在本次两件装备范围内。

成长事件建议基于真实归来：勇者曾参与一次第三层撤离或完整通关后，可在洋馆完成各自一次手写关系片段；玛在篇章开放后参加维护委托归来，再获得对应片段。不是按击杀数磨好感，也不是模型判“她感动了”就升级。

Lv.3 另需为每名角色安排实际可达的手写成长条件，不能沿用只有 Lv.2 事件的清单就宣称 Lv.3 可玩。条件仍待内容细则，不默认首通或回忆完成就直接升满。

两件装备采用各一件的整备赠物作为现有获取建议，进入通用槽；一个角色不能同时装两件通用物品。只改战面，不把沉眠叫醒、不改点数花色品质；没有可改写空面的角色应显示不适用。旧案的 Lv.3 专武赠礼在本 DEMO 后置，不能因达到三级又额外发专武。

尚需收口的执行细则：

1. Lv.2／Lv.3 事件的具体门槛和实际可达路径，以及是否消耗当下时间。
2. 整备赠物的领取时点／数量和容量不足处理；不重新扩大装备种类。
3. 现行铭约的目标不足、净化名单与确定性随机规则。
4. 装备改写后的空面与诺玛条件按 R03 联动；玛没有空面，不强行为她制造装备收益。
5. D1 勘探补充：原文未明确两件装备改写全部空面还是指定一面，需在配置解析前收口；若指定一面，再补装配 faceId 输入，不先擅加选面操作。

成长后的数值仍严格采用已有逐面表；本次不改基础 36 面，也不把“三级封顶”误写成全员已经全醒。

## 9. R08：红线重排到底重排什么

**已定：重排敌方阵位。** 玛的葫芦铭约改变存活敌人的横排排列，为左右顺劈创造邻接。旧样稿“重排本回合结算顺序，最先行动友方 +2 格挡”不再作为本能力依据；已执行的玩家动作不回滚重算。

定义边界：

- 移动的是敌人实例的阵位；不改变其 ID、HP、缠线状态或已有意图目标。
- 阵位与行动队列是不同概念；不因移动横排位置自动重排已生成的敌方执行队列，也不移动执行游标。
- 沿用铭约自动触发原则，不增加玩家手动拖拽排位的操作。
- 本尊战与角色铭约共用阵位原语；本尊具体影响哪一侧、怎样预告和限制，仍由本尊卡定义，不默认本次已经确认移动我方队伍。
