## 3. 玛丽埃塔自动铭约卡

### 3.1 触发与结算时机

**女仆长的领域**：回合收束的同一冻结手牌中，恰好五个有效醒骰形成3＋2、4＋1或5时触发。铭约匹配单列；经济牌型 `fullHouse` 仍严格为3＋2。

| 冻结有效点数组 | 匹配 |
| --- | --- |
| 1、1、1、2、2 | 是 |
| 1、1、1、1、2 | 是 |
| 1、1、1、1、1 | 是 |
| 1、1、1、1，仅四骰 | 否 |
| 1、1、1、2、3 | 否 |
| 五名角色，但其中一骰沉眠／封锁／力竭，仅四个有效点数 | 否 |

有效骰、持约者资格继续用 D1 冻结结果：已使用面仍可成牌，沉眠面不成牌；持约者必须在快照中存活且未封锁。凯尔代点只用已选定的 `hand.wildValue`，不可为玛再次求解，诺玛点数1不变。

结算顺序固定 **尤→柯→诺→艾→玛**。触发集合先冻结，具体目标与玛的排列读取前约完成后的实际存活状态。前约已清场时玛记无目标，不制造动画。完整批次中的合法治疗照常收尾。

此时本轮 `enemyOrder/cursor` 已确定。阵位变化不改变任何已锁定意图的来源、目标、格挡和出手顺序；下轮按正常规则生成新队列。没有额外攻击、骰子返还或追溯顺劈。

### 3.2 两阶与评分

| 参数 | 初铭：Lv.1／2 | 现行：Lv.3 |
| --- | --- | --- |
| 相邻交换预算 | 最多1次 | 最多2次 |
| 作用对象 | 当前存活敌阵 | 相同 |
| 目标 | 聚拢下一回合可用原始2＋1顺劈同时清理的敌人 | 同目标，扩大可达集合 |
| 持续 | 保留最终阵位，直到死亡收拢、召唤或新的合法重排 | 相同 |
| 额外伤害／格挡 | 无 | 无 |

确定性策略如下：

1. 输入重排前的存活阵位，给各单位记临时序号0…n−1。枚举预算内可达排列，包含原排列；同一排列按最短相邻交换距离去重。
2. 对每个候选计算 `K`：所有**有向**相邻对 `(主目标, 邻目标)` 中，主目标HP≤2且邻目标HP≤1的数量。两个1HP敌人相邻贡献两个方向，2HP与1HP相邻只贡献一个方向。
3. 对上述符合条件的每一对，累加两者的公开威胁，得 `T`。一名敌人参与多对时逐对计入，不按单位去重。威胁是当前攻击意图在扣格挡前的强度；非攻击、无意图、本轮被定身者为0。读取当下可见意图，不预测下轮意图、骰面或随机结果。
4. 最大化 `(K,T)` 的字典序；平局依次取最少相邻交换、最少移动单位、最小原阵位序号序列。移动单位指最终槽位不同者。不能用可能在导入时重命名的实例ID破平局。
5. 评分不优于原排列就保持原位；只记录一次触发和无改善原因。0／1敌直接空过；2敌的两个方向对称，当前指标下也不移动。

`K` 衡量裸2＋1伤害的组合机会，不把多组机会加总成一次伤害。D5当下敌人没有本尊护域；固定历史队又不含玩家玛，两个机制不会在生产遭遇中混成这类评分。后续若把减伤敌人加入可亲征路线，必须扩展为候选阵位下的有效伤害预测，不能照搬HP阈值声称能双杀。

最大四敌时，初铭最多4个、现行最多9个不同候选；工程实现按有限交换展开，不对通用20敌上限进行全排列。D5所有已发布敌人都可移动，不新增固定锚点机制或 Boss 体型免疫。

### 3.3 已核验例子

以下敌人威胁均为1；字母是重排前从左到右的固定序号。

| 初始阵位及HP | 初始K／T | 初铭结果 | 现行结果 |
| --- | --- | --- | --- |
| A1—B5—C2—D6 | 0／0 | A—C—B—D，1／2，交换1次 | 相同；不为用满预算多动一次 |
| A1—B1—C2—D2 | 3／6 | 原位，3／6；单次交换没有提升 | C—A—B—D，4／8；先B/C再A/C，共2次 |
| A1—B6—C1—D2 | 1／2 | B—A—C—D，3／6，交换A/B一次 | 相同；此例**不能**用来展示两阶差异 |
| A3—B3—C3—D3 | 0／0 | 原位 | 原位 |

第二行的现行结果包含四对：C→A、A→B、B→A、D→B。初铭最优分数没有提升，因此保持原位。现行候选包含初铭全部候选，分数不会因升级下降；这不等于实战胜率一定提高。

### 3.4 共用排列原语与表现边界

输入必须是同一存活实例集合的完整排列，无重复、死者或已解除单位；验证来源、预算、排列合法性后原子提交。事件至少带before／after、source、reason和round。身份、HP、缠线、挣脱、定身、意图与队列全部随实例保持。

死亡继续即时移除并收拢，召唤继续右端入阵且下轮行动。原排列不作为需要每次恢复的持续法阵。动画只能消费已提交排列；元素按实例保持绑定，局部平移，结束／降动效／离页恢复都到同一终态。不得借重排改原骰子旋转或归位时序。

### 5.2 死亡收拢后的护域

护域是实时派生值，**不可把“相邻侍偶死亡”直接实现成护域减1**。

| 状态／动作 | 收拢后阵位 | 护域 |
| --- | --- | --- |
| A—M—B—C | 原阵位 | 2 |
| 上行击倒A | M—B—C | 1 |
| 从A—M—B—C击倒B | A—M—C | 2；C补成右邻 |
| 从M—B—C击倒B | M—C | 1；C补位 |
| 从M—B—C执行下一次重排 | B—M—C | 2 |
| 最后一只侍偶离场 | M | 0 |

护域图标、目标伤害预览与实际扣血共用同一计算。一般地，移除侍偶不增加当前护域，但可能不降低；下一次重排可以重新提高它。玩家可先清无后继补位的一侧，或用高伤穿过护域，不要求固定解法。

### 5.3 每次命中、自动选敌与终局

对本尊：先求当前原始伤害，再扣本次命中时的护域，钳至0，最后以当前HP封顶扣血；吸收量为 `min(原始伤害, 护域)`。例如原伤3、护域2，实际伤害1；原伤1、护域2，伤害0。护域不消耗，不与玩家给敌方意图加的格挡共用字段。

普通动作与所有铭约逐命中走同一入口。每次击倒／解除后立即收拢，下一次命中再算护域；不能在整批开始时把减伤快照沿用到最后，也不能让多刀共用一个减伤预算。顺劈仍在合法命令时锁定具体邻居，波及不能追随收拢去打另一个实例。伤害0仍是合法命中，已有绞杀消费目标线的语义保持；相关组合用夹具覆盖。

柯萝萝“优先可击杀”在新规则下必须使用**护域后的有效伤害预测**。例如本尊HP2／护域2时，原伤3只能扣1，不能按旧 `HP≤3` 判断可击杀；旁边3HP无护域侍偶才是可击杀目标。保留D1的最大HP、威胁、阵位顺序；旧v2／v3无此护域，不改变轨迹。

本尊归零即锁住新的玩家行动／重掷／撤回，按D4收尾纪律完成这一动作、应有的手牌一次收束与已冻结铭约批次；未完成的必要治疗仍完成。终局标记使后续敌对效果不再追杀剩余侍偶，随后整体判双方存活并出结果。该标记属于耐势终局，不提前把本尊替换为普通尸体，也不让死亡动画回调决定输赢。D5-C须明确测试“动作归零”和“铭约中途归零”两条路径。

战斗胜利只有**突破防线**这一历史结果。本尊无伤痕、不碎裂、不被斩断头顶吊线；线从她指尖主动收回。不能复用千金救离、碎刀、抱起或重新招募叙事。

## 7. 十个成长事件卡

### 7.1 共同资格与完成语义

**本人合法归来 Q**：本人属于一趟已正式结算的出征名单，结果为第三层撤离或五层通关。途中力竭但被队伍带回仍算；普通失败、memory、simulation、纯导入动作均不算新归来。

四位勇者Lv.2需一次Q。四人Lv.3需已接管庄园、本人已领取Lv.2、再有一趟**开始于Lv.2领取之后**的Q。比较权威事务先后及run起点，不能拿客户端时间或“结算晚于领取”替代。玛Lv.2需回忆兑现后本人参加维护Q；玛Lv.3需本人Lv.2后新开始的维护Q。

事件不额外推进时间、不扣物资；不要求特定骰面、击杀、治疗次数、赠礼、浪漫答案或日历冷却。可在任意馆内时段观看，台词不强称“刚刚回来／今晚／刚受伤”。资格证明固定引用满足条件的settlement；旧v3安全升级只适配已验证归来为Lv.2／赠物资格，不伪造新run。

事件入口保存事件ID、资格引用和持久游标。选择“稍后”保留资格与阅读位置；可先做其他事，回来再看，领取时重新检查无活动远征／memory。最后“完成片段”依据权威最终节点和资格，**同一事务**写事件完成与对应growth；不先标完成再要求第二次“领奖”。允许跳过文本到合法结果节点，不能跳过门槛。重复领取业务去重；回顾只读。
