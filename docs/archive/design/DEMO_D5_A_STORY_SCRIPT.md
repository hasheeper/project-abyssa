## 1. 接入约定

每段列出的“前缀”与两位行号组成稳定行ID，例如 `story.marietta.memory.present-intro.01`。表格顺序就是播放顺序；演出提示不属于角色台词，也不自动生成战斗事实。脚本标题不用作数据库身份。

对话沿原AVG组件和现有立绘，保留角色页、战斗页全部样式。每次“继续”推进已保存游标；“跳过对白”到该段合法出口；“稍后”保存位置。成长／赠物在最后“完成片段”时一并提交事件完成与奖励，无额外第二次领奖。回顾所有对白均只读。

人物不必因成长变成另一种性格：尤斯缇丝仍严格，艾洛拉仍珍惜物资，柯萝萝仍会偷懒，诺玛仍有锋芒，玛仍维持她的分寸。片段写出一次具体相处，不宣布心结已经治愈。不根据未发生的战斗动作生成台词。

### MF 失败、暂离、重试和重复游玩

前缀：`story.marietta.memory.status`。以下是系统文案，不追加新的历史分支或玛的嘲讽台词。

| 后缀／状态 | 文案 | 操作与边界 |
| --- | --- | --- |
| failed | 这次未能突破防线。可以重新挑战；当下的物资与时间没有变化。 | 重新挑战／返回洋馆；无完成证明 |
| retry | 从本尊战起点重新开始。勇者配置与局部补给恢复，开局随机序列保持不变。 | 新attempt，同检查点seed |
| leave | 暂时离开这段回忆。下次挑战会从战斗起点开始。 | 结束未完成attempt；教学未完成则下次先回教学 |
| pending | 回廊的交锋已经结束，还有一段当下对话待完成。 | 继续对话／跳至结果；不能再次索取历史奖励 |
| replay | 重新挑战这段回忆。已开放的亲征与已领取结果保持不变。 | 使用局部模板，重复胜利无新增奖励 |
| recap | 正在回顾已完成的片段。 | 只读，不进入战斗、不推进时间、不领奖 |
| inherited | 本档已接管庄园，并持有已完成这段回忆的记录。 | 沿用记录／重新挑战；仅D5-F合法派生档显示 |
