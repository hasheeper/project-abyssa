# D5-D：回忆与当下结果实施记录

日期：2026-09-06。依据：[D5分包计划](../plans/DEMO_D5_MEMORY_AND_GROWTH_PLAN.md)、[D5-A规则规格](../design/DEMO_D5_A_RULES_AND_STORY_SPEC.md)、[完整脚本](../design/DEMO_D5_A_STORY_SCRIPT.md)。

本包接通显式v4档案的“庄园首通→洋馆引入→历史本尊战→当下对话→玛丽埃塔亲征”。默认新档继续D4／v3；默认切换属于D5-H。成长／赠物／装备、旧档升级与二周目仍分别由E、F实现。

## 1. 已实现行为

| 环节 | 实际行为 |
| --- | --- |
| 普通远征前置 | v4复用原五层房间、战斗、事件、配给、撤离与结算规则；完整首通及家宴落幕后开放回忆，不能用手写结果跳过实际旅程 |
| 洋馆入口 | 原归来面板显示回忆门槛、引入、恢复、重试与回顾；没有新造一套主菜单或战斗页面 |
| 固定历史 | 凯尔、尤斯缇丝、艾洛拉、柯萝萝、诺玛的固定Lv.2模板；局部药水／护符；独立seed、attempt、撤回与战斗状态 |
| 可恢复对白 | 逐句游标由事务提交；重读不推进，跳过只到本段合法出口；不能跳过真实本尊战。回馆对话支持稍后继续和最终确认 |
| 失败／暂离 | 不产生普通败绩，不改变当下资金、时钟、补给与成长；从教学／战斗起点重试，沿用seed，attempt递增；旧attempt链接失效 |
| 历史完成 | 本尊耐势终局与memory-ended证据同一事务提交；历史胜利先进入“越过红线”，此时尚未开放玛亲征 |
| 当下兑现 | 读完或跳到当下末句，再确认同行；chapter claim、开放角色和清活动run一次提交；重复请求、不同请求重复业务均不多发 |
| 玛亲征 | 角色页、地图编队和core出征验证读取同一availableCharacterIds；可加入维护委托并正常归来 |
| 事实与记事 | 历史战与当下结果分清origin；排除撤回；战斗短句和回顾是只读呈现，不新增伪造事实，不依赖LLM |

战斗短句遵守M04条件：首次开战、首次实际提高护域、首次有效裁定、首次未终局的护域降为0。每attempt只投影一次；重试不重复首次宣言。

## 2. 接线与工程边界

- [普通远征v4入口](../../../src/game-core/session/d5-expedition.ts)显式绑定v4读取器；公共旧入口继续限制v2／v3，不把内容引用临时改成旧版本执行。
- [应用服务](../../../src/game-application/versions/d5-service.ts)负责所有旅程、memory和当下故事事务；[旅程证据](../../../src/game-application/versions/d5-journey-evidence.ts)与原combat证据一样保存操作、摘要、事件及撤回，不把完整前后存档塞进每条fact。
- [严格记录校验](../../../src/game-application/versions/d5-validate.ts)重放普通旅程并绑定真实终局。出发事务是journey＋expedition-started两份事实；回忆终局是combat＋memory-ended两份事实。生产读取器拒绝孤立的出发／完成声明。
- 服务、runtime注册表复用已验证的不可变前缀，避免每次点击从第一场战斗重演；只有先前由验证器确认的对象可成为前缀，且目录、读取器、save／epoch、全部前序commit和fact必须一致。新snapshot仍独立校验，不能只比较head就信任。
- 修正了更新head时的别名问题：新revision通过新对象赋值，不改到初始化commit共享的head。
- [导航](../../../src/game-client/navigation.ts)使用独立memory＋attempt参数；[客户端协调器](../../../src/game-client/session.ts)按精确run定位恢复，包括回忆页当下领取的回执丢失。陈旧链接不能代替当前run执行内部续步。
- [故事适配](../../../src/game-client/MemoryStory.tsx)复用原AVG及按钮；[脚本数据](../../../src/content/presentation/marietta-memory.ts)不依赖UI类型。共享AVG保留原非受控行为，新增受控游标和历史立绘输入。

未调用rp-style-lab，未引入模型／网络依赖，未启停用户5190服务。未重置既有工作树，未提交或清理此前改动。

## 3. 原界面中的呈现

仍使用原Battle Surface、骰盘、角色卡、意图线、侧栏、雾、红线边框和配色。回忆只替换标题、历史立绘、敌人内容及侧栏说明：护域、当前选定动作的实伤、局部补给、不计当下收益。

阵位先由核心提交，再以稳定敌人ID分段投影相邻交换，采用局部短弧线。动画期间锁住新操作；降动效、离页、后台及刷新都落到已提交阵位。伤害／治疗不再因同批含重排而跳过原有演出。旧投骰、固定骰和归位时间未改。

没有改CSS或新造美术。历史正式回廊背景、指尖及线缆拆层锚点仍待补；本轮复用既有本尊透明立绘；旧日侍偶按A稿暂复用候席客器物图，其原顶部吊线仍需拆层审查。不能把空缺背景／锚点算作美术交付。D4千金沉睡／抱起缺图继续独立保留。
