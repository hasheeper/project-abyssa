# MAP 主体与出征面板尺寸核查

2026-09-07。用户确认本次调整对象为中央地图及出征面板。

## 发现

MAP 与骰局原来共用 `0.78024` 的主体缩放。地图采用更薄的木轨和垫边后，主框高度只有约681px，比骰局约737px矮56px，底部空出约117px。委托正文14px再随画框缩放，1600×900下实际仅约11px。

检查了 MAP、战斗、洋馆、骰局及角色页面。通用菜单在这些接入页面的尺寸一致；本次调整地图主体。

## 调整

地图主框使用局部缩放 `0.85`，继续在共享1600×900画布内等比适配。地图、木框、地标、队伍、委托和编队抽屉整组放大。招牌保留共享位置与尺寸，主框顶边仍位于约101px。

| 1600×900下的可见尺寸 | 调整前 | 调整后 |
| --- | --- | --- |
| 地图主框 | 1091×681 | 1188×742 |
| 地图内容区 | 1023×614 | 1115×669 |
| 委托侧板 | 321×570 | 350×621 |
| 委托正文实际字号 | 10.9px | 13.6px |

地图内容面积增加约19%；主体底边落在约844px，与通用主界面的占屏高度接近。主框左边约206px，展开菜单右边194px，保留约12px间距。

委托标题调到23设计px，正文与出发标签16px，次级说明14px，禁用原因13px。配色、现有组件、队伍站位和地图交互沿用原实现。

修改文件：`src/apps/map/map.css`、`src/apps/map/sortie/sortie.css`。
