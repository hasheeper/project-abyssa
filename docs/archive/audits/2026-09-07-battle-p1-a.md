# P1-A 侧栏与机械监视器实施记录

更新：2026-09-07。状态：已接线，按用户反馈迭代视觉；不代表P1-B及后续包完成。

## 当前实现

- `ExpeditionBattleFrame` 提供框外附件槽；`ExpeditionBattleLedger` 在主框上方偏右悬挂机械监视器。原倍率滚轮、包裹滚轮与晶石集中在顶部；下拉面板等宽连接、沿竖向收放，有厚边和底部投影。
- `ExpeditionLedger` 只保留日志／配给。用户明确取消重复倍率、散金、BAG标题和逐层结算公式；日志获得更多高度，长句正常换行。
- `ExpeditionBattleSidebar` 只承载状态刻板、立绘和反应。`CompanionStatus` 复用主标题的阶梯轮廓与皮肤材质；红线仅在 `old-manor` 显示，其余四套皮肤使用普通边框。
- 立绘越过内框上沿，按角色处理透明留白；反应框改为内容自适应高度，标题凹口中的文字内收。
- 本地反应表包含六人、九类、每类两句，共108句；只消费已提交事件，以回执／事件ID稳定选句。查看／固定骰子不产生伪动作；请求失败不刷反应；刷新／撤销回到待机句。回忆排除未参战角色。
- 回忆保留护域、实伤预览、局部配给和暂离命令。道具目标弹窗仍沿用原实现，等待P1-B。
