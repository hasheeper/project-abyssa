# ABYSSA 定稿、完成度与当前工作

更新：2026-09-07。本页只登记有效决策、交付状态与下一步；完整当前机制见[机制与游戏闭环总览](GAME_SYSTEMS_AND_CONTENT_SPEC.md)。旧阶段日志已移至[历史档案](archive/README.md)，不再混排在当前状态前面。

## 1. 当前结论

**正式角色、庄园三种战斗、成长装备、基础商店与存档已经建立工程闭环。初章尚未接入，战斗压力和剧作仍不合格，不能按“工程通过”宣布 Demo 内容完成。**

当前新档使用 `abyssa.demo / contentVersion 3 / rulesVersion 4`，点击“新的开始”仍然直接进入菜单。完整路径、数值、资产和兼容边界以总览为准。

| 范围 | 有效决策 |

| 底座 | Abyssa独立拥有确定性规则、存档与游戏闭环；复杂LLM上下文／管线再按需调用rp-style-lab |
| 初章（最新） | 新的开始先进CG，简要世界介绍，再转洋馆介绍、基础教程与简单初始副本，包含强盗／经典小怪和简单钩子 |
| 首发范围修订 | 初章前置；庄园仍是首个完整主题地牢。早期“庄园唯一副本”不再排除新增教学内容 |
| 正式角色 | 凯尔、尤斯缇丝、艾洛拉、柯萝萝、诺玛、玛丽埃塔；最多五人，凯尔必带 |
| 成长／装备 | Lv.3封顶，只开放备用短刃与应急药囊两件空面装备；玛铭约重排敌方阵位 |
| 庄园三模式 | 初战最终千金，未通关始终初战；首通后开放维护与回忆，两者最终均为刻仪兽 |
| 回忆与开放 | 回忆入口在玛记事顶部，勇者小队参战；刻仪兽替代原玛本尊战；完成回忆及当下收束才开放玛亲征 |
| 庄园美术／叙事 | 白布、黑木、红线；三重锁、千金救离与首通合簿；分餐侍从废弃，衣橱守门人和纯家具长桌Boss废弃 |

| 牌型 | 已用骰继续计入；力竭队友排除；沉眠面仍不成牌，需把界面提示说清楚 |
| 缺图处理 | 千金沉睡／抱起等专用姿态暂缺，保留待补，不伪称完成 |

上述是有效方向，不把具体未讨论的初章故事、敌群和奖励一并视作批准。

## 4. 当前排期

1. **O1 初章内容稿**：CG分镜／简短旁白、洋馆至回馆的完整分场、具体小钩子、第一版教学卡与素材清单。
2. **O2 教学与持久契约**：逐场敌群、提示和失败处理、奖励与时间、跳过／重看、恢复及旧档边界。可随O1交叉核对。
3. **O3 接线／O4 验收**：复用现有规则、战斗与AVG；从真实新档走完整初章，并验证旧档不被迫重来。
4. 继续处理庄园／刻仪兽配平、回忆／成长剧作与缺图，最后做包含初章的整体验收。

执行依据：[初章计划](plans/DEMO_PROLOGUE_AND_ONBOARDING_PLAN.md)。初章容易是教学目标，不撤销庄园压力不足的判断。暂定“迟到的补给车”只是钩子候选，尚未定稿。

多人事件、完整经营、其他地牢与LLM接入分别排期；不以增加系统数量替代当前内容质量。

## 5. 文档与证据的使用顺序

- 用户最新明确修订决定设计目标；原始[人设与世界资料](../st/setting)决定人物与世界基础。
- [机制总览](GAME_SYSTEMS_AND_CONTENT_SPEC.md)说明实际发布行为，并给出源码出处；两者有差异时明确登记，不悄悄把代码默认值当作定稿。
- `design/`保存仍有效的美术、文风与演出依据；`plans/`只保留有剩余工作的计划。
- `archive/`保存已结束计划、旧规格、旧剧本和验证证据。归档不删除历史，但旧“当前／下一步”不再作为执行指令。
- 本轮仅整理文档及其引用；没有调整游戏数值、剧情、UI、玩家存档或素材。文档清理结果见[整理记录](audits/2026-09-07-documentation-consolidation.md)。
