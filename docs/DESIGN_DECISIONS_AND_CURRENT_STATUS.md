# ABYSSA 定稿、完成度与当前工作

更新：2026-09-09。本页只登记有效决策、交付状态与下一步；完整当前机制见[机制与游戏闭环总览](GAME_SYSTEMS_AND_CONTENT_SPEC.md)。旧阶段日志已移至[历史档案](archive/README.md)，不再混排在当前状态前面。

## 1. 当前结论

**正式角色、庄园三种战斗、成长装备、基础商店与存档已经建立工程闭环。15张CG序幕的视觉、阅读与存档链路已阶段收口，洋馆S1及S2破窗后情报／出门剧情已接入，教学尚未实施；战斗压力和现有剧作仍不合格，不能按“工程通过”宣布Demo内容完成。**

当前新档使用 `abyssa.demo / contentVersion 6 / rulesVersion 4`，点击“新的开始”进入四幕CG，Logo后进入洋馆S1／S2，默认AVG、可切RP；出门后以黑场“第一章：雾滩·退潮岩窟”交接，教学未接入，场末仍暂回现有洋馆。旧内容包保留；内容5首晨可保留游标与选择续接，原档另留。逐镜实现与音频／分层缺口见[序幕实施记录](design/PROLOGUE_CG_IMPLEMENTATION.md)，S2范围见[首晨实施记录](design/FIRST_MORNING_IMPLEMENTATION.md)。

首晨现由JSON主控台词、分页、演出及舞台元信息，原版式与120节点契约保持一致；LLM的受限生成接口已准备，未连接真实模型服务。标题档案可归档／恢复已完整续接的旧档；见[JSON与生成契约](design/AVG_JSON_AND_GENERATION_CONTRACT.md)。

首晨动作已收减并统一复用原动作库，角色进入只用原划入；铁销改为标准小方框展示SVG，随阅读翻页关闭。正文、选项、原舞台版式与校准不变。

首晨S1早餐与S2出门统一为一幕「洋馆的第一个清晨」，从头进入只播一次背景＋左上角题签，再接人物和对白；中途不重新开幕。修复整场入场结束后角色再次划入的问题，既有120节点／五组选项仍连续兼容。

标题启动卡顿已处理：存档目录的完整校验移至可取消的 Worker，避免 StrictMode 重复扫描；两侧 CG 仅保留当前／待切帧，背景场改用独立合成层。Logo 入场分为起句弹入、魔王慢旋、连接词滑入、四字错拍展开、句尾上挑及问号／红点分拍；保持原构图与材质、约四秒总长，标题页与序幕末尾共用。

游戏已改为单入口＋十个懒加载路由：首次使用原六面骰黑幕准备资源与字体，再进入标题；内部切页不重启文档、不重复全量加载。只挂载当前页，离页释放渲染与存档会话；页面 CSS 按路由隔离。根目录只留 index.html，实验／工具 HTML 收入 entries/，旧游戏链接生成兼容跳转。重试复用成功资源，更新补取变更内容；原转场、Logo与存档规则保留。静态子目录部署与实现边界见[资源加载契约](../src/shared/loading/README.md)。

AVG／RP同拍文字与动作同步开始，不再固定等待700ms；点头改为明显下沉、短暂停顿后较快抬起，逐角色参数同步更新。最新工程基线与验证见[统一加载、懒加载路由与演出修正收口](archive/audits/2026-09-09-loading-routing-motion-closeout.md)。

## 2. 用户已确定的方向

| 范围 | 有效决策 |
| --- | --- |
| 作品 | 守望者之崖的同居与治愈群像；日常与冒险互相支撑，保留角色实力、性格与关系，不靠强制长期重伤推动循环 |
| 底座 | Abyssa独立拥有确定性规则、存档与游戏闭环；复杂LLM上下文／管线再按需调用rp-style-lab |
| 初章（最新） | 新的开始先进CG，简要世界介绍，再转洋馆介绍、基础教程与简单初始副本，包含强盗／经典小怪和简单钩子 |
| 序幕定稿 | 神话／现实／决断／日常四幕，15张本地CG；最新正文34段／696字，见[原文分屏稿](design/PROLOGUE_SCREENPLAY.md)。黑幕只显示「三年后」；拥抱与触手共用前冲回弹，触手不叠白光；保留原Logo及中心黑幕。直接修订优先于运镜附件 |
| 洋馆首场 | 按用户S1及S2稿，共120节点／四处三选一＋一处二选一；固定主角台词按稿保留，姓名仍为`{{user}}`。诺玛带回马车遇袭、货物失窃情报，五人出门。最新修稿移除动作播报，差分／动作与正文分离；红线不设重点特效。复用RP舞台，默认AVG、允许切RP；见[首晨实施记录](design/FIRST_MORNING_IMPLEMENTATION.md) |
| 首发范围修订 | 初章前置；庄园仍是首个完整主题地牢。早期“庄园唯一副本”不再排除新增教学内容 |
| 正式角色 | 玩家主角、尤斯缇丝、艾洛拉、柯萝萝、诺玛、玛丽埃塔；最多五人，玩家位必带。`kael` 仅作存档与规则兼容 ID，固定剧本使用 `{{user}}` |
| 主角行为 | 自动物理动作／群像环境锚点／关键抉择轮三层模型；固定剧情不得替玩家连续发言，每场只在推进瓶颈给出1–2次三极行动选择 |
| 成长／装备 | Lv.3封顶，只开放备用短刃与应急药囊两件空面装备；玛铭约重排敌方阵位 |
| 庄园三模式 | 初战最终千金，未通关始终初战；首通后开放维护与回忆，两者最终均为刻仪兽 |
| 回忆与开放 | 回忆入口在玛记事顶部，勇者小队参战；刻仪兽替代原玛本尊战；完成回忆及当下收束才开放玛亲征 |
| 庄园美术／叙事 | 白布、黑木、红线；三重锁、千金救离与首通合簿；分餐侍从废弃，衣橱守门人和纯家具长桌Boss废弃 |
| 界面 | 复用既有美术与组件；剧情用完整差分AVG和完整进退场；普通副本不套庄园专属红线；七槽道具坞不等于解锁七类携带 |
| 牌型 | 已用骰继续计入；力竭队友排除；沉眠面仍不成牌，需把界面提示说清楚 |
| 缺图处理 | 千金沉睡／抱起等专用姿态暂缺，保留待补，不伪称完成 |

上述是有效方向，不把具体未讨论的初章故事、敌群和奖励一并视作批准。
