UI 动效补记（2026-09-17）：当前是共享控件／窗口／内容／主板预设＋四页共享入场生命周期＋保留的逐页专用编排，不恢复已回退的 U3。合并管理范围、残留检查和实际性能限制见[动效收口计划](plans/2026-09-17-ui-motion-consolidation.md)及 [M4 验收](audits/2026-09-17-ui-motion-m4.md)；不能把维护重复减少解释为全项目卡顿已解决。

**正式角色、庄园三种战斗、成长装备、基础商店与存档已经建立工程闭环。15张CG序幕与洋馆首晨已接入，共用教程画布已实施，四场岩窟教学已接入；战斗压力和现有剧作仍不合格，不能按“工程通过”宣布Demo内容完成。**

当前新档使用 `abyssa.demo / contentVersion 12 / rulesVersion 4`，四战＋E1五房带做流程；内容9的四型AIRP制作见[AIRP-3](plans/AIRP_3_IMPLEMENTATION.md)。点击“新的开始”先弹起点选择，不立即建档或播放CG；完整开始才进入四幕CG，Logo后进入洋馆S1／S2，默认AVG、可切RP；出门后以黑场“第一章：雾滩·退潮岩窟”交接，随后进入四战＋事件教学，在S4-1毛毯归处收束，读后一次领奖，再开放自由整备。亦可跳过序章到首晨、跳过第一章到教程，或跳过教程到自由枢纽；跳过记真实选择，不补发教程金币、货物或通关事实，不推进时间。旧内容包与“继续游戏”不变；内容5／6首晨可保留游标与选择续接，原档另留。逐镜实现与音频／分层缺口见[序幕实施记录](design/PROLOGUE_CG_IMPLEMENTATION.md)，S2范围见[首晨实施记录](design/FIRST_MORNING_IMPLEMENTATION.md)。

首晨现由JSON主控台词、分页、演出及舞台元信息，原版式与120节点契约保持一致；LLM的受限生成接口已准备，未连接真实模型服务。标题档案可归档／恢复已完整续接的旧档；见[JSON与生成契约](design/AVG_JSON_AND_GENERATION_CONTRACT.md)。

内容11抵达教程后先建立固定教程远征，播放 S3-1 雾滩进场剧情，再显示五章13节规则总览，确认「开始战斗」后提交原 `tutorial-read` 进入战1。完整首晨和快捷入口一致；总览位置使用同标签页的阅读缓存，刷新／返回标题后继续可恢复，已进入战斗的档案不重复弹出。首页「界面与操作」提供六区定位、底部操作栏放大图与基本操作顺序；后续按战斗与地牢、骰子、倍率机制、其他机制、角色词条归并，保留规则表及真实局部图解。总览与战内弹层固定原冷灰／青色阅读配色，不继承战斗皮肤的暖金文字。查阅不退出带做、不改教程游标、骰子或队员选择、不写阅读事实。操作指引的 × 仅收起当前说明，保留目标和「继续教学」入口，下一步自动展开；菜单「操作指引」重开当前步骤，只有明确「退出带做」才解除步骤限制。正文源为 `src/content/presentation/tutorial/handbook.json`；`docs/TUTORIAL_COPY_EDITABLE.json` 是独立历史副本。详见[本轮审计](audits/2026-09-13-handbook-content-audit.md)。
