## 1. 结论与范围

建议采用 **固定教学局面＋有限带做＋逐步放手**：

1. 战1教操作单位：ROLL、固定、拿起角色行动、选择目标、每骰每轮一次、回合交接。
2. 战2教决策单位：公开意图、保留固定骰后重掷、格挡指向一条攻击，而非给队员挂通用盾。
3. S3-3后新增一个真实事件房，单独教“读条件→选参与者→确认尝试→独立判定→读结果→继续”。
4. 战3先带做一轮集火／牌型／铭约，之后放手；战4只保留一次同伴开场定调和淡目标，不再主动弹教学卡或锁招。
5. 返馆先兑现三件货物，再提示休整和下一委托；玩家领取后才入账、推进时段、开放自由枢纽。

**不是为每个按钮加一张介绍卡。** 每个知识点必须对应一次真实操作、一个能看见的状态变化和一句解释；已懂的操作减少说明，不靠阅读长规则表过关。

本轮不引入多人事件、事件重掷、战斗自动代理、新战斗公式、强制购物、现实时间倒计时、假胜利／假掉血或LLM判定。

### 2.1 三个特别容易误教的地方

- **槽位不等于房间，也不等于故事存档step。** S3-4的表现节点3＋4，目前最终一起提交业务接点`S3-4 / step:0 / choice`。不能将表现cursor4误写为业务step4。
- **每骰一次是每轮一次。** 使用后的骰仍参与符合资格的成牌；固定、使用、沉眠、力竭分别是不同状态。重掷不能让已使用的骰再行动。
- **事件“确认”不是确认已看见的随机结果。** 现行实现先选一名存活队员，提交`choose-event`时原子抽骰并结算；之后的滚骰只是回执演出。尚不存在“先掷完，再决定是否花钱”的窗口。

## 5. 教学交互：带做不是锁住所有页面

教学动线为：**看见敌情／机会→明确眼前目标→高亮当前操作→玩家操作→实际反馈**。各战入场、战2弩箭上膛、E1皮包、战3两对出现及其真实结算先提供一次短观察；之后每张操作卡只对应一个当前可执行的动作。讲敌情时聚焦敌方，转向操作控件后仍保留相关意图、血量或牌型的可见区域，不能一边讲弩箭，一边用暗幕盖住弩手。

观察确认只保存当前标签页的阅读进度，不新增游戏命令、不推进带做证明、不消耗资源，也不额外封锁原本合法的操作。Boss只给一次开场目标观察，之后保持自由战斗。

工程步骤数不等于确认卡数量。观察已使用骰、血量变化和另一条意图等，优先嵌入动作反馈／下一操作的焦点；不为每一句小字增加一次“明白了”。默认由真实操作推进，仅确有必要停读的节点保留单次确认。

### 5.1 两种控制状态

- `guided`：当前操作课只开放该步允许的改变状态命令；同一目标的等价原控件入口均有效。看角色、HP、意图、LOG、保存退出和无状态查看始终允许。
- `free`：用户主动选择“自由尝试”或标准课完成后放手，恢复普通合法操作。跳过带做不跳过战斗／事件房，不伪造教学完成证明。

`hintsEnabled`只决定显示说明，不能兼任上述模式。为避免“说明关了却还莫名其妙被锁”，关闭带做卡时明确提供“暂时收起说明”和“退出带做，自由尝试”；前者保留可找回的当前步骤入口。退出后重新打开帮助只给按状态提示，不强行接回已失配的指定答案。

首版不新增随时免费回滚的练习按钮。已有真实团灭后的本场／入口重试继续有效；恢复带做只能从可验证的兼容检查点开始，不能回满血又保留已赚资源。

### 5.2 硬限制的位置

前端从runtime获得本步允许操作和原因，在原控件上禁用／高亮；同一约束在游戏核心tutorial policy校验。键盘、菜单的END TURN、另一标签页和直接命令不能绕开。遮罩本身仍只是表现，不用一块透明层吞掉所有点击实现规则。

该门禁限制玩家主动指令，不能截停合法的敌方／战斗收尾`resume`队列。观察卡应等效果完成后出现；规则续算与玩家确认阅读分开，避免“等玩家确认才能结算、又等结算才显示确认”的互锁。

默认不让玩家点击错误答案再扣血；错误目标不可提交并有简短原因。局部目标草稿可以取消、重选；合法UNDO撤销操作时，也必须撤回对应步骤证明和依赖它的阅读确认。

刷新重新读取正式状态；写入失败停在原步骤、允许原请求重试。加载、滚骰、伤害队列、转场、LOG和模态窗口期间暂停高亮，不自动记为“已学会”。

### 5.3 双层文案规范（本轮确定）

**玩家在学界面，小队没有在重新学战斗。** 教学文案的定义是“老练战术小队的战场切口与肌肉记忆”，不是军校生教老兵拿武器。

| 层 | 只回答 | 写法与载体 | 禁止越位 |
| --- | --- | --- | --- |
| 系统引导层 | 现在做什么、刚才变了什么 | 原焦点高亮旁的小字／浮条；完整说明当前操作及直接结果，通常1～2句 | 居高临下、夸奖式寒暄、“根据某法则”等世界观包装；不替主角写内心 |
| 战术定调层 | 当下为什么这么做 | 偶发同伴对白，自然、具体、有角色口吻；已有态势或已发生的反应 | 教按按钮、复述规则表、报公式、固定台词认领别人的行动 |

系统例：“左侧软泥已经受伤。尤斯缇丝的剑足以收掉它：点击她的骰子，固定这枚更强的剑面。”先指出可见状态，再给出目的与当前动作。不显示“【规则说明】／【系统提示】”等作者标注；必要时直呼ROLL、REROLL等原控件名称，方便对应。

G4撤销原20字硬上限，不以省字破坏因果或把角色写成机械口令。系统正文单测按110个可见字符以内检查容量，并以真实窗口检查遮挡与换行；不是写作目标。观察卡与操作卡分开：前者说明这一小段要解决什么，后者随原操作自动推进，不为固定、选人、攻击分别增加阅读确认。人物不讲完整规则表，战术对白现版控制在64字内，AVG按自然节拍分页。

用自然、具体的现代书面中文；删除“稳住”“记住”等训导措辞，使用“两对已成型”。不把冷却、红线、优势面、战利品等未在该面板或实际结果中存在的信息写进提示。完整的倍率计算留在面板、账本与手册，实战提示讲收益变化和追击机会。

人物侧重点：尤看目标、分配攻防；诺玛看侧路、弩位和空当；艾洛拉看伤势和物件是否还能保全。称呼／语气沿用[对白口径](../design/DEMO_DIALOGUE_VOICE_GUIDE.md)，不轮流报人设。

频率：每场战斗只在开场／关键反馈插话；战2为区分准备与实际挡箭保留开场＋两次反馈，其他战斗更少；E1有两句接入和至多一句结果反应。普通拿骰、切目标、每次重掷不触发全队插话；Boss固定只有一次开场定调。系统提示与气泡不抢同一位置、不重复同一句信息，不为听完气泡新增确认锁。

时态必须分清：看见意图是“会来”，提交格挡是“我来挡”，真实攻击已被拦住才可说“挡下了”。刷新、UNDO后重演和同一回执重放不反复触发气泡；未发生的伤害、奖励或追击不提前宣布。

## 8. S3-3＋新增E1：一堂独立的事件课

### 8.1 先安顿，再切换语法

读完S3-3后若有受伤且存活的队员，打开原道具坞、高亮一份食物及合法目标，系统短句为`伤势会延续。选择补给恢复。`。标准带做选择有实际效果的一次恢复；满血则只提示可继续，不出现强制治疗步骤。不能把当前“先检查伤口”写成人人已经受伤。

恢复完成／无须恢复→推进E1。战斗骰池退出当前交互态；仍复用原页面、角色区和行动坞，不把事件做成战斗中间的第二个聊天弹窗。

### 8.2 首课题材：背风石阶·潮坑落货

采用用户示范的“石缝硬皮包／匪徒遗落备用件”作为文案方向，不是Boss后才追回的草药箱、书箱或工坊包袱；不能提前完成三件货物目标。物品归属尚未确认时，诺玛保留“好像”，不替规则新增已确认的货物事实。

S3-3同一表现节点末尾加两帧，读完后才转事件面板；不新占0～7槽位，不在事件页重复再播一遍：

- 诺玛：“等等，这石缝里卡着个硬皮包，好像是那帮匪徒掉落的备用件。”
- 艾洛拉：“上面泡了海水……得小心拆开，不能伤到里面的东西。”

角色解释谨慎处理的动机，系统负责单人参与限制；无需写“为什么其他四个人不能一起上”的设定理由。

| 属性 | 本稿建议 |
| --- | --- |
| 规则类型 | 复用已有单人`relic`事件语法；不代表沿用庄园文案／美术 |
| 参与者 | 先选择一名存活成员；标准带做选艾洛拉，种子保证本次可解释的强成功 |
| 费用／奖励 | 首课cost0、reward0；不扣钱、不赠物、不治疗、不改长期变量；成功／失败仍有真实结果 |
| 强成功 | 沿用行动种类优先：heal／expensive-heal／protect／guard-all／wild |
| 弱成功 | 未强成功时，清醒且点数≥4或万能命数 |
| 失败 | 其余面；事件结束，仍可继续，不算团灭 |
| 绕行 | 免费、0抽签、写skip并完成事件房；带做中需先明确退出带做 |
| 次数 | 一房一次尝试；无重掷、无失败重新ROLL |
| 内容边界 | 结果只叙述本次检查；不拿“看到了货物”代替实际回收，不凭空增加可售库存 |

0G是隔离第一堂课的经济风险，不意味着所有事件免费。条件说明补一句“其他事件可能花费散金，确认前查看代价”。此处不强制制作第二张收费事件卡。

用户此轮明确讨论的是文案风格，因此示范中的“获得补给”**不自动成为奖励规则变更**。当前收尾采用`事件已处理，准备前进。`。如果后续确定要实物搜刮，须先在G2明确物品ID、数量、容量／满额行为、实例及一次领取证明，并重新检查后段配给和重试；有真实奖励回执后才能显示“获得补给”。现行事件只支持散金cost／reward，不能用叙述偷偷补一份药水。

选人处使用真实查询的`可成功面4/6`，不增加“精细处理”属性或隐藏成功率加成。本轮核对Lv.1原生面表：玩家3/6、尤2/6、艾4/6、柯3/6、诺4/6；艾与诺总成功面数持平，艾有3个强成功面、诺有1个。因此可以借艾对物资的谨慎建立参与动机，不能写她比所有人成功率都高，也不能把固定教材样本的成功说成角色100%成功。

事件读取骰面作为判定条件，**不执行该面的战斗技能**：掷出治疗面不额外回复HP，掷出攻击面也不对谁造成伤害；代价只取事件定义。标准样本选普通“圣光”，避免首课还要解释越限治疗。

- 战1每骰每轮一次，固定不等于使用；新一轮可再行动；不要求使用无合法目标的面。
- 战2固定面在重掷中保留；已使用骰不参与重掷；装填不能格挡；格挡一条不会清空其他意图。
- 事件选择前／后不能偷看或刷新换骰；attempt消费1次eventRng，skip消费0次；不改变combat cursor，不重用上一战骰面。
- 战3牌型／铭约从真实本轮结果教学，沉眠不成牌、已用清醒骰仍成牌；至少一项真实铭约效果可见。
- 自由模式提前清场／不触发铭约／绕行事件均无软锁，不补刷敌人，不强行补作业。
- Boss至少验证先弩后首、先首后弩及忽略集火威胁；不是只用一套自动最优策略。
- S3-5～S4-2不提前付钱／加时，领取入账为真实终局＋8G；货物非库存，商店不强制购买。

### 稳定性与视觉

- 在每个持久节点及ROLL后、固定后、行动后、格挡后、事件确认前后、Boss死亡后、claimable逐点刷新／导出导入。
- UNDO、同请求重试、重复点击、两标签冲突、存储失败不跳步、不重复伤害／抽骰／领取。事件结果不可通过普通battle UNDO撤销。
- 新版导入严格验证五房；旧四房活动档仍可完成；伪造完成房间、检查点、guide证明或eventRng均拒绝。
- 1280×720、1600×900、1920×1080检查高亮与原控件对齐，提示不盖当前目标／HP／意图；开关教程不重排原战场。手机端不在本批。
- 看LOG、开道具坞、切AVG、后台／恢复及低动效下无残留遮罩、误点穿透、重复演出；结算卡只出现一次。

### 试教而非“测试绿色”

文案专项验收：系统单焦点、语句完整，86字以内的现版容量检查与三种窗口实屏避让同时通过；同伴不讲按键、公式或设定课，不为每句小字加确认。格挡演员／目标／量／时态与真实回执一致；事件成功面数来自查询，无奖励不写获得补给；铭约满足本人的完整条件才播效果。Boss只有一次开场气泡＋淡目标，不主动开教学卡或加教学操作门禁，原战斗合法性限制不变。

建议至少3名未看设计稿的初见玩家试玩，记录每课卡住的位置、误点击、求助、退出带做与Boss表现；样本仅用于形成修改方向，不宣称统计结论。结束后让玩家实际演示：保留一骰再重掷、指出格挡的那一条攻击、解释事件是否能重掷、指出钱在何时真正入账。

整体暂按15～22分钟预算（含新增事件约1～2分钟），这是制作目标，不是本轮实测。若提示把游戏切得过碎，优先合并重复观察卡，不删掉真实操作与结果反馈。
