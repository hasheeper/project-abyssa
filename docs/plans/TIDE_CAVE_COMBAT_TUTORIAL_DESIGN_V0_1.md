## 1. 本章要让玩家带走什么

**把失窃的东西拿回家，并学会用五枚角色骰完成一轮有取舍的战斗。**

通关后，玩家应能自行掷骰、留下有用面、重掷不合适的面、选择行动与目标，知道什么时候该挡下一击或先击倒敌人。随后理解：受伤与补给会延续，回合末还会结算牌型和伙伴铭约，带回收益后才能继续整备。

这是熟练勇者小队的一次短途追回行动。学习对象是屏幕前的玩家，角色不重新学习剑术，不互相朗读按钮名称。

推荐规模：**四场战斗、两处短暂停顿、一次回馆兑现**。初见目标约12–18分钟，已懂操作约8–10分钟，均为待试玩验证的时长预算，不强制按计时器推进。

| --- | --- | --- | --- |

这里的回合与时长是制作目标，不是引擎强制值。玩家提前清场就正常通过，不刷出备用敌人补课。

## 3. 沿用现有玩法的教学边界

以新档Lv.1、五人各3HP、无装备为工作基线。每轮两次重掷、最多两次道具使用；保留全部五人骰和实际面表。首版教学只携带原基础配给：食物4次、药水2次，不改全局容量或收费规则。

| 概念 | 玩家需要知道的准确表述 | 不应教出的误解 |
| --- | --- | --- |
| 角色骰 | 一人一骰，当前面决定这轮能做的事 | 不是点数越大，所有角色伤害都越高 |
| 固定 | 留住这个面；固定后可执行其合法行动；未使用前可以解除 | 固定不等于已经用掉，也不是敌人封锁 |
| 重掷 | 只重掷未固定、未使用、未封锁且主人未力竭的骰 | 不会把全队已执行的行动洗掉重来 |
| 行动 | 攻击选敌人，治疗选受伤且存活的队友 | 治疗不能复活力竭者；满血没有合法治疗目标 |
| 格挡 | 选中一条正在攻击的敌方意图，降低这一次伤害 | 不给角色挂一个能抵挡本轮所有攻击的通用盾；蓄力条目前不能预先格挡 |
| 击倒敌人 | 已击倒敌人的意图不再执行 | 不需要额外等到敌方演完攻击才删除威胁 |
| 行动使用后 | 本轮不能再用、不能重掷，但符合资格时仍参与成牌 | 不按“未使用骰”结算牌型 |
| 沉眠／空面 | 沉眠排除成牌；空面是没有当前主动动作，两者分别判断 | 不是整个角色所有能力都停用；其他骰成牌仍可能触发其铭约 |
| 力竭 | 本场不能行动、不能成牌、不能被普通治疗复活 | 不让教学药水凭空复活；不把当前力竭演成永久死亡 |
| 牌型／铭约 | 牌型收益增加金币；满足条件的铭约在敌方执行前触发 | 倍率不乘攻击伤害；最佳牌型与可触发铭约不是一一对应 |
| 战间延续 | 活着的队员保留伤势和道具余量 | 房间切换不全员补满；既有力竭归队规则照常处理 |

五位伙伴的职责通过行动出现：玩家位补位与保护，尤斯缇丝稳定攻击，艾洛拉恢复，柯萝萝高伤但空面多，诺玛灵活补位。不为教学把柯萝萝的4–5伤临时改小，也不关闭早触发的铭约。

### 3.1 提示的触发与退出

提示由§3.3的统一高亮画布绘制，定位到现有组件，每次只保留一个主提示。后续仅在第一次遇到新状态或连续两轮没有合法角色行动时再提示；后台、LOG和AVG阅读期间不计提示等待。普通战斗保持原版式、骰子尺寸、道具坞、倍率仪表与LOG，不往这些组件内部插入教程说明块。

| 教学点 | 触发 | 提示内容草案 | 完成／撤下条件 |
| --- | --- | --- | --- |
| 开骰 | 战1首次`roll`阶段 | “掷出全队这一轮的行动。” | 真正提交ROLL并得到骰面，不能由点击动画计完成 |
| 固定 | 首次开骰后存在未固定可行动骰 | “留下这个面，再选择它的行动。” | 任意合法固定；不强制某个角色 |
| 行动与目标 | 已固定骰有可执行动作 | “选择行动，再选择目标。” | 首个合法行动提交；目标死亡或资格变化时实时撤掉失效指引 |
| 回合交接 | 首轮已至少行动一次、仍在玩家阶段 | “安排完后结束回合，敌人将执行剩余意图。” | 手动或清场触发的正式回合收尾；不要求对已清场画面再点END TURN |
| 留骰与重掷 | 战2有已固定骰和可重掷骰 | “留下需要的面，重掷其余骰子。” | 有固定骰保留的一次真实重掷；没有合适条件则后移，不阻断通关 |
| 意图与格挡 | 战2或之后存在伤害尚未挡完的攻击条，且有格挡动作 | “格挡作用于这一次攻击。” | 完成格挡或玩家先击倒该敌人；后者视为有效应对，不弹回要求改答案 |
| 恢复 | 存在受伤存活队友且有合法恢复来源 | “伤势会带到下一场，先看看剩余补给。” | 真实治疗／用药，或玩家明确继续；满血不出现 |
| 牌型 | 首次出现非散牌，战3优先 | “用过的清醒骰仍会参与回合末结算。” | 看过一次真实结果即可；不给全牌型背诵任务 |
| 沉眠排除 | 玩家检查沉眠骰，或牌面外观容易被误认成两对 | “沉眠面不参与成牌。” | 状态注释随对象显示；不能把提示变成另一个过场 |
| 铭约 | 首次发生`covenant-triggered` | 用已触发角色与实际效果做一次短说明 | 演出与事件记录确认；没触发就不声称玩家已学会 |

必要教学证据只覆盖ROLL、固定、一次角色行动和正式回合交接。格挡、重掷、治疗、特定牌型的操作记录用于按需提示，**不作为击败Boss后仍拒绝通关的条件**。玩家可关闭辅助提示，流程仍通过真实战斗推进。

### 3.2 固定教学局面的边界

战1可使用一个离线挑选、经正式RNG运行验证的首轮种子；其余遭遇采用正常随机。种子属于内容配置，连同RNG游标持久保存，不在表现层塞入指定结果。

建议寻找的战1首掷向量，按玩家位／尤／艾／柯／诺排列为 **2／2／1／1／3**：玩家攻1与尤攻2可以合作击倒一只3HP史莱姆，艾的治疗尚可能无目标，柯与诺出现沉眠空面。它同时给出可用行动与暂时无用面，避免开场全是万能好牌。

O2-T已验证 **seed 8267**：从正式出征创建开始，敌人意图先消耗两次抽签，首轮ROLL后得到该向量，游标从2到7。固定／重掷后允许正常分歧，刷新不能重新选号。推进T2时切换到出征时保存的普通种子，之后连续使用。

不限制玩家为了避免受伤主动重掷并首轮清场。教学后续以状态决定何时再解释格挡／恢复，不人为扣血制造教学素材。

### 3.3 统一教程画布：经典高亮框

**确定的交互形态：背景适度压暗，真实目标区域保持清晰，外沿高亮框，旁侧放一张简短说明卡。** 画布独立覆盖在游戏画面上，开启与关闭教程时，下层战斗组件的坐标、尺寸和间距不变。先实现一套共用能力，再让战斗、道具和后续菜单教学注册目标；不各做一套遮罩或说明面板。

“画布”指共用覆盖层，不要求用HTML Canvas重绘游戏。建议用独立Portal中的DOM说明卡与SVG遮罩／描边；目标仍是原控件，不复制骰子、敌人、按钮或整页DOM。

#### 画布构成与版式

| 部分 | 统一规则 |
| --- | --- |
| 宿主 | 游戏壳顶层只有一个教程宿主，覆盖当前游戏可视区域；置于页面位移／缩放容器与裁剪容器之外，避免随战斗退场被裁切或偏移 |
| 遮罩 | 一张低成本半透明暗幕，在当前目标处留清晰窗口；不用整屏模糊、重复截图或持续滤镜 |
| 高亮框 | 沿真实控件外框留少量间隙，形状适配其原轮廓；复用通用主题的细描边与克制亮度，不使用庄园专属红线装饰 |
| 焦点数量 | 通常一个主目标。需要说明骰池／一组合法目标时可使用目标组；操作依然由原控件承担，不同时突出整屏 |
| 说明卡 | 短标题＋一句准确的操作提示，必要时第二句说明结果；沿用通用字体、材质和按钮。卡片浮在空位，不成为新侧栏、底栏或布局占位块 |
| 避让 | 根据目标周围可用空间选择上／下／左／右，避开目标本身、当前所需HP／意图和操作按钮；屏幕边缘保留安全间距 |
| 窄窗口 | 自动换边、折行或将说明卡放到画布内可用边缘；不移动、缩小下层战场。不够容纳时先收短说明，仍无可用位置则暂缓提示并保留关闭入口 |
| 动效 | 高亮与说明短淡入淡出，不做大幅滑入、反复弹跳；换目标时重新定位，不能让框从上一处横穿战场 |

#### 定位与操作约定

- 目标以稳定语义标识注册。O3-U已接入`battle.roll`、`battle.die:<actorId>`、`battle.intent:<enemyId>`、`battle.end-turn`等；意图锚点使用敌人实例ID。不能用按钮文案、数组第几个元素或写死屏幕坐标定位，完整表见[共用画布说明](../../src/shared/tutorial/README.md)。
- 原控件提供当前可见节点与合法操作状态。统一读取其实际外框，以同一套可视区CSS坐标定位遮罩和说明卡；页面缩放不得重复乘比例，目标隐藏／被裁剪时不画虚假的完整高亮框。
- 仅观察当前目标及必要的避让区域。窗口变化、滚动、组件尺寸变化、布局切换后统一更新；静止时不每帧测量，不为教程重复挂载角色或资源。
- 高亮窗口中的点击直接交给原控件。教程不模拟点击、不调用第二套战斗结算；默认仍允许其他合法战术选择，玩家先击倒威胁也能撤下对应格挡提示。
- 遮罩的明暗不等于强制锁定操作；纯装饰部分不吞掉正常点击。说明卡和关闭按钮消耗自己的点击，不能穿透到底下误触ROLL或END TURN。
- 原控件的键盘操作仍有效；说明卡提供可聚焦的阅读／关闭入口，出现时不抢走正在操作的控件焦点。确认“读过说明”与“完成真实行动”分开，实际步骤仍由§3.1的合法命令／事件确认。

#### 转场与其他界面的冲突处理

## 4. 四类基础敌人占位卡

### 4.1 潮滩史莱姆

自然栖居在退潮后的浅沟，因车轮和散落杂物聚集；不属于艾比希斯的小黑泥，不盗走货物、不与匪帮合作。

高约35–45cm，湿润质感有体积，保留灰蓝／贝壳色，避免黑色触手、红眼、巨大嘴部。攻击近似整体拱起撞击即可；首版复用敌人基础受击与退场，不先制作独立分裂动画。

3HP让攻1＋攻2的配合可读，柯萝萝高伤面能直接击倒，符合她已有实力。没有酸蚀、分裂、元素抗性或掉血后的新形态。

### 4.2 望风刀手

匪帮外沿哨兵，见小队闯入便上前拦截。约170cm体型，约35cm短刀，装备来自沿岸旧军需和渔民雨具，不能看成庄园执事换皮。

它应当容易被清掉：3HP可以被尤／诺的强攻面单独处理。它的价值在“这轮有一条真实攻击”，不靠高血量拖时间。没有闪避率、暴击、随机连击或隐形。

### 4.3 伏礁弩手

装备朴素十字弩，在洞口与货台使用较低射姿。弩身约70–80cm，棕灰护布和铁件有清楚层次；不做霓虹瞄准镜或现代枪械构图。

5HP是集火目标：柯萝萝攻5能一击解决；攻4需要伙伴补1，尤攻3＋诺攻2也能处理。装填轮给玩家规划空间，射击轮的2伤对3HP队友足够需要关注。

装填时仅显示已有蓄力意图，不能显示一个尚不存在的锁定目标，也不能提供格挡落点。进入射击轮后目标与2伤由正式意图公开。伤害2是最终射击值，不额外按“蓄力”再翻倍。

### 4.4 驮货打手

负责把箱子搬上不易被潮水淹到的货台，靠撬杠阻拦追兵。约180cm、厚实普通人体型；背架约60cm宽，撬杠约70cm，重心低，不做两倍人物高的“家具人”。

6HP使它略耐打，但每轮只有1伤：与弩手同场时，玩家应能看出“血多”不等于“必须先杀”。首版不附加嘲讽、护盾或保护邻居；也不挪用只属于旧回忆模板的减伤逻辑。

## 5. 关底Boss：退潮匪首「礁钩」（暂名）

**一个熟悉浅滩退路、敢以双弩掩护继续抢运货物的人类头目。** 危险来自持续逼近与两翼射击的组合；不是深渊化怪物，也不突然升级为能抗衡天王的存在。

| 项目 | 工作规格 |
| --- | --- |
| 敌人／美术ID | `enemy.intro.reef-hook-chief`／`intro.reef-hook-chief` |
| 生命与攻击 | HP12，每轮攻2，复用`attack` |
| 赏金 | 3；属于本趟散金，不自动进长期钱包 |
| 开场编成 | 左弩手5HP＋匪首12HP＋右弩手5HP，总HP22 |
| 胜利条件 | 所有敌方单位被击倒／退出战斗，且至少一名队员存活；头目先倒下不会让仍活着的弩手自动消失 |
| 形象 | 约185cm，披磨损的短海兽皮肩披，一手约80cm登船钩刃，另一手小圆盾；略宽于刀手，仍是正常人类比例 |

| 道具关联 | 身后的货台和绑箱麻绳说明他守什么，不让宝箱变成第二条Boss血条 |

### 5.1 战斗节奏

| 回合 | 匪首存活时 | 两名弩手存活时 | 玩家面对的问题 |
| --- | --- | --- | --- |
| 1 | 攻2 | 各自装填、不攻击 | 用这一轮削掉弩手，还是集中攻击头目？当前的2伤是否需要格挡？ |
| 2 | 攻2 | 各攻2 | 留下的敌人同时发难；针对真实目标分别挡伤，或抢先击倒一名射手 |
| 3 | 攻2 | 各自装填 | 再次获得恢复／集火窗口，但头目仍持续进攻 |
| 后续 | 继续攻2 | 装填／射击交替 | 剩余敌人决定压力；不靠隐藏狂暴或援军无限延长 |

表中是意图总量，不是每名队友都受到这么多伤害。现行目标随机选择存活队员，**不保证三条攻击分散**；它们可能指向同一人。玩家能在操作前看到目标，模拟必须覆盖集火，而不是验收时只挑分散目标的画面。

### 5.2 至少两条有效解法

- **先拆弩手**：用攻4＋补1处理一翼，另一组攻击压另一翼，同时用格挡处理匪首。下一轮需要处理的攻击条数实际减少；代价是匪首存活较久。
- **先压匪首**：把较多攻击投入12HP头目，赌在射击轮前后完成击倒，留下两名脆弱射手。若没压倒，下一轮必须面对三条攻击；不能同时获得快速斩首与免费无伤。
- 药水与治疗用于挽救承伤后的队员；不能代替对同轮致命集火的预先处理。铭约自然参与，可改变最优处理顺序，不按剧本禁止它清场。

本场的记忆点是**“头目一直压过来，弩手则给出装填空档”**。先用现有两种行为做出可读的组合，不为一个入门Boss新增破盾、连携槽或阵位机关。数值工作范围为头目10–14HP、攻击固定2；调整时先查目标分配和回合压力，再动生命，不直接升为无预告3伤。

## 6. 四场教学卡与工作局面

### T1：潮沟清路

- 编成：潮滩史莱姆×2，总HP6，未处理时每轮两条1伤。
- 主目标：完成一次真正的ROLL、固定、行动和回合交接；次目标是认出骰面上的伤害值。
- 推荐首轮局面见§3.2。先用玩家攻1＋尤攻2击倒同一只，玩家看到一条攻击来源消失。余下骰若暂时无合法行动，可以结束回合，也可以主动重掷。
- 失败容错：单条1伤不会从满血直接击倒；若两只攻击同一人，总2伤仍可承受。后续回合继续公开意图，不给暗中免死。
- 不要求教学先造成伤口。首轮全清即通过；恢复教学按之后实际伤势触发。
- 赏金0，避免在认识攻击按钮之前多教一遍金币和倍率；从人类遭遇开始产生真实散金。

### T2：洞口哨位

- 编成：望风刀手3HP＋伏礁弩手5HP，总HP8。
- 主目标：固定需要的面、重掷其余面，区分当前攻击和下一轮威胁。
- 一条合理路线：第一轮先解决刀手，利用弩手装填轮整理骰面；第二轮若弩手仍在，格挡2伤或集中击倒。另一条路线是先杀弩手，再处理刀手的1伤，均有效。
- 格挡示例必须在弩手已经显示攻击意图时出现，不能在装填轮要求玩家点击不存在的目标。
- 若玩家直接清掉两人，不补一只敌人强迫格挡。T3／Boss仍可承接这个知识点。

### T3：搬运队

- 编成：驮货打手6HP＋望风刀手3HP＋伏礁弩手5HP，总HP14。
- 主目标：先处理能降低当前／下轮威胁的目标；不因打手体型最大就把所有伤害投入它。
- 次目标：通过一次真实的牌型／铭约结算，看见队伍配合。只解释当下发生的一种，不暂停战斗逐个展示四位伙伴的铭约。
- 散打对照：若把伤害分给三名敌人而没有击倒任何人，更多意图会留下；集火则减少实际攻击。这是教学需要呈现的可观察差别。
- 本场仍用正常RNG。没出现某种牌型也可正常通过，不能刷骰直到系统满意。

供设计／QA复核的局面，以下均是面位而非已经落地的随机脚本：

| 玩家／尤／艾／柯／诺 | 真实结果 | 用途 |
| --- | --- | --- |
| 2／2／5／1／5 | 清醒骰为2、2、5、5；柯的1是沉眠空面。最佳牌型为两对，诺玛的“有空白”条件也成立 | 说明空面、沉眠与铭约条件不是同一件事；这些清醒骰使用后仍保留两对 |
| 2／2／3／3／4 | 柯的3沉眠，参与的是2、2、3、4，只有一对 | 专门防止把画面上的两个3误报成第二对 |
| 3／3／3／1／4 | 三个清醒3形成三条；若存在受伤存活队友，艾的初铭可回复1 | 说明回合末治疗；满血时不能演一段不存在的回血 |

以上工作局面只用于校验文案与判定一致性；正式演示必须从真实已提交状态读结果。金／锈对金币加成的细项留规则检查，不在玩家屏幕列长公式。

### T4：货台终战

- 使用§5的匪首＋双弩手，总HP22；不再弹基础操作教程，只保留鼠标查看／主动展开帮助及首次遇到的状态解释。
- 开战前允许用现有补给处理伤势；不是点击继续后全员自动满血。
- 胜利后先完成伤害、铭约和战斗收尾，再进入货物清点AVG。固定故事选择不决定命中、敌人HP或奖励倍数。
- 头目以普通敌人退场规则处理，剧情可写被制服／失去抵抗；不复制千金解线、沉睡、抱起等专属演出。

## 8. 奖励、失败和跳过的建议

### 8.1 一次成功归来

- 敌人赏金按表：T1为0，T2为2，T3为4，T4为5，基础散金合计11。使用现有单层牌型累计上限与大地共鸣；按现行倍率，未消耗散金时约12–36金币。越限治疗真实扣散金，实际收益可能更低。
- 回馆一次性追加搬运报酬8金币，作为缇比货车委托的建议报酬；最低仍有8金币可用于现有商店。它需要独立领取证据，不复用庄园20金币首通奖励。
- 不发Lv.2、不发两件空面装备、不开放玛亲征。三类货物作为任务事实与记事，先不新增可售卖的通用库存类型。
- 整章成功归来推进一个时段，建议由晨到昼。战间AVG、回看与失败重试不反复推进时间；不新增真实小时模拟。
- 基础配给依现有规则返还余量，下次普通出征仍可重新配给。不要把玩家追回的草药箱自动转换成无限药水。

上述范围保留为纸面预算，实际模拟记录见[O2-T契约](TIDE_CAVE_RULES_AND_SAVE_CONTRACT_V0_1.md)。多次治疗、队伍力竭与实际牌型均会改变结果，不对玩家承诺固定实得。

### 8.2 失败重试

推荐采用**本次遭遇开场检查点**，而不是整章重读或让新玩家付钱重试：

1. 正式规则判定团灭后，展示简短失败结果，提供“重试本场”“保存并返回标题”。不把两者写成同一种撤退结算。
2. 重试恢复开场的成员HP、配给、临时锈、散金／入袋记录及RNG；回滚本次失败尝试的产出与消耗。相同操作得到相同结果，不因重试按钮赠送免费换种子。
3. 只有全部四场真实完成并经回馆结算才写长期收益。没有“先存入失败场的战利品，再恢复满资源”的刷取口子。
4. 检查点过弱时允许明确“从岩窟入口重新尝试”：保留runId、递增attempt，以入口快照恢复满血和原基础配给重开四场；已读AVG可快进，剧情选择保留，不发失败奖金。
5. 本章没有中途正式带钱撤离点；导航离开只暂停run。不能把现有仅允许第三层的撤离接口冒充通用逃跑。

这套教学恢复政策已由O2-T实现并覆盖本场／整章重试；前端按钮与恢复画面由O3-T接入。普通庄园团灭仍按既有折损结算。具体完整快照与事件序号边界见O2-T契约。

## 11. 验证与下一步

### 11.1 工作数值如何验证

O2-T使用现有五人Lv.1、原始面表、两种基础配给执行三策略固定种子对照，命令与结果记录见[O2-T契约](TIDE_CAVE_RULES_AND_SAVE_CONTRACT_V0_1.md)。下表仍作为实际试玩要求，自动策略结果不能代替新玩家验收。

| 对照策略／场景 | 需要观察什么 |
| --- | --- |
| 基础新手：看到致命意图才格挡、伤后用药、不主动追牌型 | 可以完成多数种子；每次失败能指出被忽略的公开威胁，不因教程步骤不可达卡死 |
| 合理应对：集火、保留格挡、按需重掷和恢复 | 比分散攻击更少承伤、更少消耗；Boss的双弩窗口确实改变行动顺序 |
| 只攻击、不用格挡／治疗／道具 | 允许部分通过，但应明显增加力竭或失败；不能与合理应对在伤势／资源上几乎没有差别 |
| 熟练爆发与铭约提前清场 | 接受更短战斗；不锁血、不补刷、不追着玩家补点某个教学按钮 |
| 两／三条攻击集中同一人 | 首次看到的意图正确；防御预览与真实伤害一致，按错误次序操作有可理解后果 |
| 柯萝萝连续沉眠、治疗全队满血、没有格挡面 | 所有提示可退出／后移，有结束回合和重掷路径，不生成无合法目标的必点步骤 |

首批建议至少64个固定种子，记录各场回合数、损血、力竭、配给消耗、铭约触发和重试次数。通过率仅作平衡证据，不能代替新玩家能否复述规则。Boss目标3–4回合；大量样本拖到6回合以上先检查循环是否乏味，而非继续加血。
