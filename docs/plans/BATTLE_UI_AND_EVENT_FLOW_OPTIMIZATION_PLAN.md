## 3. 多人事件仍是后续提案

详见[多人事件规则与存档契约](MULTI_ACTOR_DICE_EVENT_RULES_AND_SAVE_CONTRACT.md)。现有遗物整理为单人提交时抽骰结算；新提案才包含开骰、选择多个参与者、持久待判定状态与放弃。规则、数值、原型及版本还未实施。

当前默认包为规则4／内容3，v4导入、有限升级和二周目已有接线；新事件应在这个实际基线上设计版本承接。旧计划中“默认v3／v4不能导入”的条件已经过时。

## 4. 不得误记为已实现

- 战中随时逃跑／撤退、扎营没有正式core规则；第三层撤离已实现，两者区分。
- 七个展示槽不代表七类可同时携带，设施升级增加容量未开放。
- 当前本地角色反应不代表已经接入正式LLM日常管线。
- 重要剧情用AVG，操作与判定留在已有战斗区域；不因清理旧弹窗另造一套对话样式。
