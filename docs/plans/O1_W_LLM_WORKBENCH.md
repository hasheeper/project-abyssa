## 文案交接

1. `llm/context/tasks/` 为 S3-1 至 S4-2 七个场景分别建立大纲、人物、已知/未知事实、槽位和不可变分支。
2. `llm/context/o1-w.json` 按需读取实时 `st/setting`，同一份人设只装入一次；当前任务的玩家身份和玩法边界覆盖旧档案的固定凯尔名及旧规则示例。
3. `llm/prompts/editorial.md` 保存法文原则、逐角色坏句/本音修订/定稿对照和日文原文＋中文翻译协议；编辑记录是可审阅摘要。
4. 生成结果是可审阅的候选 JSON，明确绑定原槽位、角色和情绪。完整且结构合法时生成可选续修历史；不自动写回现行剧情、规则或存档。
5. 人工核对人物本音、自然对白、双语、AVG阅读节奏、连续性及玩家主控权，审稿记录绑定该版正文摘要。程序不代替文风合格判定。

当前先完成七个已有剧情槽的工作流。新增分支专属反应、艾比希斯回馆演出、增加分页以及教程提示文案精修，仍按 O1-W 设计逐项制作与审定；不为了通过模型结构检查擅自增添节点。
