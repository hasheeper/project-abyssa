## 实际页面变化

- 战斗 → 玩法手册：关闭的 160ms（减弱 80ms）期间，战斗、导航和教程暂停继续生效，真正移除才恢复。重复查阅保留章节，关闭后回到常驻菜单的既有焦点落点。
- 角色档案 → 骰装 → 管理通用装备：背景角色选择、页签和导航持续锁到退场完成；回焦到管理按钮。打开请求绑定角色，外部切换角色／页签不会把窗口带给下一角色；失去适用性安全卸载，配置冻结则保留只读窗口。
- 回忆 → 回忆战规则／章节选项：正文和底栏一直锁到退场完成，关闭中不会误跳句、跳段或再开另一窗口；场景就绪不抢模态焦点，回顾操作不改存档。

仍沿用现有 RpgModal 的 220／160ms、8px surface，不新增第二层动画。不改窗口美术、战斗规则、装备命令、剧情回执，也不改标题／Logo。
