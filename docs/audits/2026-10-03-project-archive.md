1. 提交并推送最终源码和封存说明，推送 `archive-2026-10-03`，核对远端主分支及标签指向。
2. 上传上述五个 Release 附件，回读远端文件大小与 SHA-256，并确认可下载内容与本机一致。
3. 通过 GitHub 设置归档仓库，回读确认 `archived: true`；不删除仓库，不改写既有历史或版本标签，不删除 Pages 站点。
