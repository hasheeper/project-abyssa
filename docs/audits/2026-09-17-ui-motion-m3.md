# M3：页面 UI 入场生命周期收拢

日期：2026-09-17。对应[动效合并计划](../plans/2026-09-17-ui-motion-consolidation.md)的 M3。仅合并角色、商店、出征、洋馆的重复生命周期；不改动作、速度或布局，不实施 M4。

## 实际变更与保留边界

新增产品内部 `shared/transition/usePageUiIntro.ts`，四页保留原调用 API 的薄适配。共享 waiting／playing／ready、每挂载一次、后台与减弱收束、提前输入及计时／监听清理；不新增依赖、DOM wrapper、全局状态、轮询或 RAF。

| 页面适配 | 保留的起播条件 | 完整收尾时点 | 保留的输入差异 |
| --- | --- | --- | --- |
| 角色 | 已挂载且路由 idle | 920ms | 焦点进入；Tab／Enter／空格／方向／Home／End，不含 Escape |
| 商店 | 已挂载且路由 idle | 920ms | 角色按键＋Escape／PageUp／PageDown；焦点进入 |
| 出征 | 真正 sceneReady 且路由 idle | 1520ms，仍引用地图原常量 | Tab／Enter／空格／Escape／方向；焦点进入 |
| 洋馆 | 图景 presentation ready、未 suspended 且路由 idle | 1000ms | 地图按键；不监听 focusin；输入范围仍包含 viewport 的 `.mansion-app` 祖先及兄弟 UI |

角色原来的 920ms 字面值命名为 `CHARACTER_INTRO_END_MS`，数值不变；M2 收尾时钟测试改为检查该常量，未删掉收尾保护。地图纸片时钟保持原来源，洋馆最后一组 960ms 之后仍在 1000ms 收束。

提前输入继续使用捕获阶段的同步收束，业务 handler 随后正常执行，不调用 preventDefault／stopPropagation；资源未就绪、剧情占用或黑幕未揭开时不能快进。一次起播后 readiness 抖动、数据更新、偏好恢复、洋馆剧情恢复均不重播；重新挂载才允许再入场。

与本轮开始前保存的源码逐字对照：四页动效 CSS、共享 `tokens.json`、`useMenuIntro`、`TransitionProvider`、`ExpeditionBattleFrame` 均相同。运行修改只有共享 hook 与四个适配，没有改页面 JSX、CSS、路由或美术。Logo、标题菱形、menu 视差与专用时序、角色切换、地图弹簧、战斗／骰子、AVG、洋馆时间幕和天气未迁移。

四个生产 hook 原共 221 行，现在薄适配 55 行＋共享机制 77 行，共 132 行，净减少 89 行（含注释和空行，不含测试）。这只衡量维护重复，不代表包体或帧率收益；原先也不是四个页面监听同时常驻。ready 后清理本 hook 的入场输入／visibility 监听和计时器，减弱偏好的原有订阅仍随挂载保留。

- 16 个相关 app 测试文件共 156 项通过：角色／商店实际页面 30 项，其余 14 文件 126 项，含四页适配、共享机制、地图、洋馆、图景准备、时间幕、GameShell、黑幕和样式边界。
- 新共享机制 21 项测试：启动门槛、同步业务事件与默认行为、修饰键／输入法／根外事件／右键过滤、焦点策略、祖先输入根及回退、无 Provider、StrictMode、内容与 readiness 更新、后台／减弱／剧情／离场收束。
- 监听测试按 target、type、callback、capture 逐项配对，覆盖 waiting／playing／ready 卸载，确认计时器归零、普通重渲染不重订阅、不请求 RAF。四页另增 4 项策略测试；洋馆测试改用真实的 viewport／兄弟 chrome 结构，防止误把监听只挂在世界区域。
- `typecheck:app`、`boundaries:check`、`motion:check` 通过；共享 hook 不进入 `@abyssa/ui` 公开入口。
- M1／M2 的 8 项 Node 样式与参数检查及 1 项路由 CSS 检查通过；`build:game`、`check:output -- game`、`git diff --check` 通过。公开 UI 包、参数和组件预览实现本批未改，不重复构建 UI／Storybook 来冒充新的视觉验收。

## 真实入口验收

本机 5190、1280×720、沿用独立 QA 档 `bb198529-610c-460b-a559-593dc0665da5`。只查看页面、开关功能窗，不购买、不改编队／物资、不推进剧情、时间或远征。

1. 出征兼容入口冷启动、出征→角色档案→返回出征、洋馆内部导航及冷启动、商店兼容入口均检查。出征返回时实测 `playing → Tab → ready`，随后编队按钮正常打开／关闭名单。
2. 角色／商店／出征分别采得 14／11／18 个不同位移值，实际动画仍为 `abyssa-page-board-settle, abyssa-ui-appear`，`0.82s, 0.24s`，曲线 `(.32,0,.18,1)`／`(.3,0,.5,1)`。不是仅检查 class 或静态终态。
3. 三页最终 `animation:none / opacity:1 / translate:none`。角色盒 `(202.4970703125, 29.2076416015625, 874.9996337890625, 684.6246948242188)`，宿主 transform 仍为 `matrix(.950538,0,0,.950538,0,14.4)`；商店盒 `(0,0,1280,837.1500244140625)`，地图盒 `(0,0,1280,720)`，均与 M2 记录一致。商店读数是宿主盒，不是可见画框高度。
4. 洋馆完整采样观察到 `work:waiting → paint:waiting → reveal:waiting → ready:playing → ready:ready`。相位 UI 原 680ms／延迟 60ms，从 -30px 收束至原位；playing 期间采得 46 个不同位置，之后动画移除。第一次短时选择器等待未等到洋馆资源流程完成，随后以完整只读阶段采样核实，不将该等待超时判断为动画失效。
5. 洋馆仓库、日志、整备开关均不重播页面入场。功能窗保留 manor 预设；关闭后焦点分别回到原按钮，三个窗口关闭后 `data-world-paused` 解除，世界继续保留原实现。
6. 商店截图核对木质面板、TAB、商品与商人布局；本轮 QA 页浏览器无 error 记录。系统／手动减弱、后台、剧情暂停、卸载由组件测试验证，没有改用户系统或持久化设置。

这些采样证明实际中间状态、就绪门槛和终态未退化，不是 FPS／长帧基准，不宣称解决全部卡顿。下一批是 M4 的整体维护与性能对照收口，本轮未开始。
