# 洋馆时间切换：与普通加载页统一

## 本次范围

只调整洋馆时间/天气切换幕；不改地图昼夜色调、场景缩放、美术、房间界面、独立 Logo 动画或其他页面入场。不引入动画依赖，也不恢复已撤销的全局动效迁移。

## 外观与层次

- 提取 `LoadingPlaque` 与 `loading-surface.css`，普通加载与洋馆实际消费同一份牌面、暗纹、水印、角饰、文字和恢复按钮样式。保留普通加载原配色、布局及六平面旋转体。
- 牌面 `#101718`，幕底 `#030607`，使用原加载页低饱和灰绿边线。四时段只改变仪表符号的轻微冷暖，不再整幕换色。
- 洋馆小牌宽 320px，时钟缩至 96px，四时段刻度缩至 28px；复用实体菱形，作为只读刻度而非按钮。底部提示保留一行，不另做厚底栏。
- 小牌 portal 到 `body`，不受 Stage 缩放裁切，覆盖画布外边缘和安全区；层级低于路由黑幕。
- 剧情暂停时显式隐藏、禁止指针命中并暂停动画，不卸载仪表；保留 React 上下文中的减少动态偏好。

## 播放顺序

| 阶段 | 节奏 | 行为 |
| --- | --- | --- |
| 遮住旧景 | 420ms | 全屏遮幕；小牌延迟160ms后轻移6px显现 |
| 提交 / 准备 | 按真实任务耗时 | 延续原时间提交、资源准备和错误恢复；只有提示字轻微呼吸，不循环转钟 |
| 目标景致确认 | 至少620ms | 指针向前走一格，末端越过2°归位；日月在局部SVG窗口中上移更替，当前刻度同步亮起 |
| 揭幕 | 660ms | 小牌先180ms退场，幕底稍后淡出；仍须真实图片decode与绘制就绪 |

时钟通过单次启动标记贯穿准备完成与揭幕，提示更新不重播。夜→晨向前跨越360°，不反转；同相位初次进入不伪造时间推进。减少动态模式直接呈现最终符号、指针与刻度。

业务控制器仅变更共享节奏参数。原有防重复提交、过期任务丢弃、只读取的错误重试、真实图片等待及路由幕优先级保持不变。

## 浏览器验收

- 1280×720：幕层边界恰为整个视口，父节点为 `body`。洋馆小牌约320×262；普通加载实测外框320×206（原204px内容最小高度加边框），六平面与 `preserve-3d` 保留。
- 360×640：幕层仍覆盖整个视口，牌宽自动缩至316px，两侧22px留白；错误状态的重试和返回菜单同排，均在牌内。
- 独立预览用正式组件验证跨日、错误恢复、减少动态、剧情让位。更新提示、揭幕及暂停恢复后，指针/日月/刻度的 `animationstart` 均未从1增加到2。
- 单独播放的620ms转钟在本机rAF取样中出现39个不同transform，非首尾两帧切换；该结果不代表实际世界页的GPU帧率或全设备性能保证。跨标签页取样受后台调度影响，不作为性能结论。
- 真实独立QA档进入洋馆、晴天→雨天→晴天均通过原资源管线；回到 `data-presentation=ready`，切换幕卸载，场景图片无未加载项，未捕获控制台警告/错误。
- QA档有正在进行的旧庄园远征，未强行解除规则或推进存档。实际推进提交/失败重试由控制器回归覆盖，跨日视觉由无存档预览覆盖。
- 临时预览HTML、诊断TSX和窗口尺寸覆盖已清理，不进入正式功能。
