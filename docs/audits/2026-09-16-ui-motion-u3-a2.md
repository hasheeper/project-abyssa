## 标题差异的原因与修复

U1 真实删掉了标题的选中横向微展、扫光、左右菱形错拍／浮动和鼠标视差。A1 只与 U1 后快照比较，保留的是静态配色与图案，不是用户认可的原效果；此前“原效果保留”的结论不准确。U1／A1 审计已加后续更正，保留历史记录而非抹掉清理事实。

恢复依据是本任务 09-15 清理前读取的 `title-interaction.css`（包括 keyframes 尾段），以及 `/tmp/abyssa-motion-u1.x1E8z6/` 中保存的原 `useTitleParallax.ts` 与测试。没有回滚当前的起点选择、存档、固定猩红主题或退出生命周期。

- 恢复原选中牌面 `scaleX(1.018)`、640ms 一次扫光、原漆面／金属描边与按压。
- 恢复双菱形 240／270ms 跟随、右侧 28ms 错拍、4600ms 轻浮动和按压时向内靠拢。首次直接定位，连续选择接续当前过渡；选择事实与键盘焦点不等待动画。
- 恢复 CG 左右层 −15／−12px、背景 −4px、Logo 外层 −7px、菜单 −2px 的水平视差，纵向及轻透视沿用旧参数。宿主固定，按 Stage 实际边界归一化；右侧图像镜像仍在内层。使用原 125ms 跟随／170ms 回中指数平滑，稳态停止 RAF，不逐帧 setState。
- 接 `useUiMotion`：手动／系统减弱停止视差、扫光、浮动与按压位移；触摸／粗指针不跟随。弹窗／转场／存档 busy 回中并忽略输入，页面隐藏立即归零，失焦／离开平滑回中，卸载取消监听与 RAF。
- 标题退出普通 control，避免共享提亮／下压和原设计叠加；后续 C 不再覆盖双菱形专属效果。**Logo 原动画实现和分段时序完全未改**，菜单不等待 Logo；不恢复菜单长入场或外部法阵自动慢转。

## A2 实际覆盖

| 调用点 | 处理 |
| --- | --- |
| Shape 四种几何、Circle、SquarePanel | 共享 control；只有内部 SVG 和内容层 80ms／1px 下压，原生 button 热区固定，120ms 材质反馈。保留 ref、type、selected、disabled 与原几何。 |
| DiceActionButton、教程／手册 Shape 消费者 | 自动继承，不重复包装。双语文字静态偏移、primary、placeholder、busy 不改；空占位保持禁用／不进 Tab。 |
| MenuCommandDial | 四个局部 SVG 牌面与各自 HTML 图文按组内槽位联动，共享提亮／轻压暗；不移动完整 SVG 或透明按钮，选中配色和轮廓焦点保留。 |
| RpgDirectionPad | 同一分离美术配方；原 translate／rotate 不改，去掉命中区 active scale 和无效兄弟选择器，disabled 不再亮起。 |
| MansionUtilityRail | 仓库／日志／整备的印章、图标、角标同步下压；外部标签静止，保留引用、计数、inert 和模态语义。 |
| ArrowButton | 保持继承 IconButton；验证静态箭头旋转与内层下压，不加第二层动画。 |

共享层新增 `abyssa-control-group`／`abyssa-control-feedback` 的 1～4 槽映射，无动画状态机或额外引擎。透明热区与 SVG 坐标不同，因此采用 120ms 提亮（1.07）、80ms 轻压暗（0.96）而非强做位移；参数进入现有 tokens。材质类兼容直接 art，不能覆盖 translate 的过渡。已移除本批对应的私有 hover／active／transition。

命令盘旧 `onClick`＋`onDoubleClick` 会叠加提交，已去掉双击回调并按原生 click detail 去重；未选中双击仍是选择→进入，已选中双击只进入一次，Enter／Space 仍正常。

A2 定向测试 22 文件／177 用例通过；游戏浏览器 6 组通过，覆盖正常／减弱、1600／1280、偏好持久化和触摸。App／tooling 类型、边界、UI release、游戏构建与产物检查通过。浏览器输出在 `dist/reports/ui-motion-u3-a2/verified/`，开工快照在 `/tmp/abyssa-u3-a2.Nrx6X2/`。
