## 已移除

| 范围 | 本批结果 |
| --- | --- |
| 标题普通 UI | 移除菜单错拍入场、扫光、双菱形漂浮与左右回弹、选中横向拉伸、鼠标驱动的整体视差，以及外部背景法阵的慢转／呼吸。保留纹理、构图、双菱形、焦点与按下反馈。 |

| 日志／仓库 | 移除日志窗口、阅读区和物品详情各自的挂载 keyframe，避免同一次打开重复入场。 |

## 明确保留

**Logo 动画是独立品牌演出，保留原实现、分段时序与曲线。** 清理过程中曾误关标题页调用，已恢复为 `AbyssaLogo intro`。品牌目录没有代码差异；新增测试保护入场调用，并在普通 UI 的 keyframe 验收中明确排除 Logo。

Logo 与菜单不再共用等待表；菜单不会等 Logo 播完才可见，也不会因选择菜单而中断 Logo。浏览器已确认 Logo 的缩放、文字展开、问号摆动、宝石和字标动画实际运行。

另保留：

- CG 轮播与解码后淡变。
- 路由／洋馆换景遮挡、数据和图像就绪门禁、真实加载提示。
- AVG 人物动作、战斗回执、骰子结果、天气和场景渲染。
- 静态美术、布局、字体、配色，以及基础 hover／focus／press 状态。

本批没有安装 Motion，没有修改 `package.json`／锁文件，没有新建动画引擎。
