## 清理与统一

- 参数仍由 `tokens.json` 唯一提供：控件 120／80ms，窗口 220／160ms、最多 8px，正文 120ms；减弱无空间运动，窗口／遮幕 80ms。
- CSS flat 配方覆盖不能拆出独立美术的按钮／开关；禁用和只读不新增反馈。可拆美术的控件只压内部层，点击区不移动。
- 删除信息页私有缩放／位移、档案骰子 16 秒装饰自转、地图 650／780ms 时间表、道具栏 22px 切换、战斗账本 620ms 下拉、皮肤边角入场与普通阅读提示呼吸。手动骰子检视保留。
- 从 RpgModal 原实现抽出内部 UiModal，序幕回看复用它，未更换原侧栏美术或增加第二套退出引擎。
- 游戏壳／独立 Provider／洋馆使用同一 `useUiCurtain`。只有 Motion 完成遮挡后换页，真实资源就绪后揭示；不再使用 560／620／1850ms 的视觉等待，也不再播放区域名＋面板下落。
- 6 秒视觉保险、15 秒 handoff TTL、读档持有协议、250ms 加载防闪、请求超时与专用演出时间保留。新导航／卸载取消旧动画、RAF 和监听。
- 地图减弱切换会终止当前相机 tween 并到正确终位；退出侧板仍拦截拾取。非模态账本不新增全局模态锁，教程暂停延续到真实移除。
- 模态在挂载同帧接焦，修复“打开后立即 Escape 被当成背景输入吞掉”。关闭期间仍隔离输入、退出后归还来源，快速重开保留内容。
- 视觉检查发现并修复骰面详情包装破坏左右网格的问题；已补浏览器几何断言。其他原有窗口、文字、按钮材质与布局保持。

## 防回退及限制

`control-motion-boundary.test.ts` 检查源码的直接引擎导入，只有 shared/ui/motion 与精确的地图 GSAP 相机例外；对已迁移样式逐文件检查私有 timeline，并保护标题专属 keyframes。加载体真实等待旋转与战斗人物反应有具体例外，不豁免整个战斗／剧情目录。

当前游戏构建为 807 文件／135.34 MiB；59 个 JS 文件合计 3,128,309 字节，各文件 gzip 之和 983,106 字节。相对 U2 记录分别增加 14,761／4,915 字节；这是当前工作树的累计构建差值，不是单独动效代码的因果分析，也不是首屏传输量。

UI 包约 6.34 MiB 压缩／6.94 MiB 展开，224 文件。Storybook 仍有已有的大 chunk 告警，没有提高阈值。独立 React 18／19 消费以 U2 的实测为基础，本次公开 API 未变；本次额外跑发布产物检查，不冒称重新跑了两套独立消费工程。

真实页面性能采样结果待浏览器报告补齐。这里只验收基础统一和交互连续性，不保证所有设备稳定 60fps，不把 headless 截图当作低端设备性能认证。
