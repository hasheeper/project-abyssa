# 出征 GM 特殊鉴定物接入

日期：2026-09-25。对应 [实施计划](../plans/2026-09-25-gm-special-appraisal.md)。下方浏览器与截图结果为奇物实施阶段的已有证据；最后一轮文档与发布收口不做视觉验收，最新非视觉验证汇总在[发布审计](2026-09-25-release-security.md)。

## 已实现

- 新出征准备显式启用 `appraisalPlanVersion: 1`。程序复用实际 loot seed 和掉落算法预演奇物位，固定实例、铜／银品质与已有报价；不改战斗随机流、掉落数量或经济模板。
- 仅本次出征规划附带缇比完整角色卡及哈希，不将她加入同行队伍，也不修改每日 GM 的人物材料。旧冻结输入仍按原版读取。
- 同一次规划响应增加 `appraisalItems`，与委托实物字段分开。严格校验槽位覆盖、唯一性、字段、中文和可用表情；缺稿不能采纳后出发。复制字段与原始响应一同保存在原计划中。
- 普通战斗完成才真实取得物品，按原逐层保管／撤离／团灭规则带回；文案不产生物品或金钱。
- 商店、收获面板和掉落通知按实例解析原文案。未鉴定投影只给外观及未知选中句，不给真名、品质或鉴定稿；鉴定成功回执才开放全文。
- SVG 图标已复用 `assets/icons/items/catalog.ts` 的现有关键词权重匹配器。未鉴定仅以公开名称匹配，已鉴定以真名及程序品质匹配；无命中使用匹配器的杂物袋兜底，不再固定为宝箱。商店列表／详情／已售记录、战斗掉落通知及收获／结算使用相应实例的图标。
- 日志的待鉴定收获同步使用生成物公开名称与匹配图标，并按实例分行；最近归来的物品名也读取原生成文案，避免显示经济模板名称。
- 台词进入 `ShopCounter → ShopSurface → MerchantWindow` 的现有小对话框。保留逐句继续、收好和鉴定记录回看，不使用 AVG、场景脚本或额外模型调用。
- 已鉴定选中使用独立句；未鉴定出售使用通用废料成交句。生成物不走固定物品的重复鉴定稿，不与共享经济模板的其他物品合并出售。
- 查询原始 runId 和实例，保留已售历史与旧远征文案；开始新的出征准备不覆盖前一趟。教程／首访台词和立绘焦点逻辑保持原样。

## 验证

- 已通过：两条普通路线、24 组种子、每个房间前缀的预演与引擎掉落一致性；无 RNG 状态变化。
- 已通过：中文与结构校验、缺少角色卡／缺稿／越权数值／外来槽位拒绝，旧协议仍可读取。
- 已通过：真实应用命令完成远征取得奇物 → 鉴定扣费 → 阻止重复鉴定和批量混售 → 出售入账 → 导出恢复 → 下一趟仍保留历史；仅 GM 响应使用明确模拟数据。
- 已通过：小对话框选中、逐句鉴定、成交、未知废料出售、交易失败和历史恢复的组件用例；验证没有 AVG DOM。
- 已通过：现有委托往返、旧计划、出征门禁、读取／结算和失败恢复回归。校正了一条旧测试的默认 Catalog 版本断言：生产代码此前已由 23 升至 25，本次未改默认版本。
- 已通过：core、application、app、tooling 类型检查，模块依赖边界，游戏构建及构建产物检查。
- 已通过：构建页面的浏览器验收 1/1。通过界面导入真实流程生成的存档，验证未知选中 → 小对话框逐句鉴定 → 刷新恢复 → 已知选中 → 精确出售 → 已售鉴定记录回看，全程没有 AVG DOM 或额外模型请求。1280 × 720 截图已人工检查，小对话框、物品说明和继续按钮显示正常；截图位于 `dist/reports/browser/shop-generated-appraisal-g-58de1-ad-and-sells-the-exact-item-game/generated-small-dialogue-1280.png`。

首轮新增集成用例在与另一整批回归并行时触发过 Vitest worker RPC 超时；为长战斗夹具添加事件循环让出后，新增集成与恢复用例单进程重跑 9/9 通过。

- 57/57 用例通过：现有图标库 39 项、商店组件 8 项、远征收获 5 项、日志投影 3 项、日志界面 2 项。覆盖鉴定失败仍保留未知图标、鉴定提交成功才更新图标、实例图标进入掉落通知及结算、未知物品不按描述中的猜测选图、原作者物品展示兼容。
- app／tooling 类型检查、游戏构建、产物检查和本次文件差分空白检查通过。
- 构建页面浏览器验收 1/1 通过：验证兜底图标的实际 SVG URL 返回成功、鉴定逐句播放、刷新、出售及记录回看。1280 × 720 截图已人工检查；此浏览器夹具名称刻意没有匹配词，因此显示杂物袋。锁盒／木箱／钥匙等具体命中与鉴定切换由上述组件和投影用例验证。
- 浏览器前两轮分别在商店转场及存档导入阶段触发默认 5 秒等待超时；补上项目已有的转场完成等待，并对齐导入的 30 秒超时后重跑通过，未改产品加载或动画逻辑。
- 图标接入当时，全库依赖边界剩设施模块的既有类型循环；后续已解除。09-25最终文档收口复验1,553个源文件通过，此项不再列为当前阻断。
