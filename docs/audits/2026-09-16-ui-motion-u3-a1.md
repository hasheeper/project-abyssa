> 09-16 后续更正：A1 对照基线取自 U1 之后，只保留了清理后的配色、纹理与静态菱形，不是用户认可的清理前完整效果。标题现已在 [A2](2026-09-16-ui-motion-u3-a2.md) 恢复横向微展、扫光、左右菱形错拍／浮动与鼠标视差，并作为专属例外退出普通 control；本文的 A1 验证数字与当时实现保留为历史，不代表当前标题仍为静态定位。

日期：2026-09-16。状态：**A1 实现与定向验收完成**。依据：[U3 分批计划](../plans/UI_MOTION_U3_ROLLOUT_PLAN.md)。本批没有新增依赖或公开组件 API，没有推进 A2～F。

用户明确要求复用标题原有选中样式与小菱形效果。本批保留标题选中配色、漆面纹理、描边／焦点高亮、双侧菱形的尺寸／旋转／光泽与直接定位；**Logo 独立动画没有修改**。

## 已迁移与已移除

| 调用点 | 本批实现 |
| --- | --- |
| `TitleCommandMenu` | 原生按钮消费 control；内部表面与文字同步下压，现有材质渐变调用共享配方，原选中事实及键盘导航不变；菱形不属于按压层。 |
| `JournalButton`／`JournalActionLink` | 共用 control 与有效偏好；美术和 HTML 文字作为两个同步层，不缩放文字；链接继续是原生 a，保留 href／target／Enter 等行为。 |
| `MansionTimeLoading` 返回链接 | SVG 美术接同一 control 与减弱偏好；与原有重试按钮一致，不改变加载牌、时钟或资源时序。 |
| `RpgHexButton` | SVG 边框、HTML 文字和图标同步下压；保留 selected、loading、disabled、ref、原生 type 与事件。选中阴影和悬停提亮可以同时成立。 |
| `RpgNotchButton` | 默认 SVG 图标及自定义子图标都随对应边框下压，按钮命中区不缩放。 |
| `RpgBackButton` | 三角美术及内嵌文字下压；删除整个按钮的斜移与缩放，不改变三角图形、原生热区和标签。 |

节奏沿用 U2：120ms 提亮、80ms／1 个设计像素下压，减弱时 0ms／0px。没有加入新空间运动、延迟命令或循环装饰。`motion-controls.css` 的可选 `__material` 类提供 SVG 填色／描边／透明度的统一渐变，内部美术层统一文字颜色与阴影反馈；页面只拥有原有美术终态。

删除了上述范围的私有 hover／active 位移、缩放与时长。核实源码内手工使用 Ribbon／NotchedPill 的入口都已接入后，移除 U2 为它们保留的临时兼容规则。Shape／SquarePanel／页签／状态节点的旧规则仍按后续批次处理，未一并清空；静态参考 HTML 自带的样式也未重写。

## 验证

- 开工基线：7 文件／55 用例通过；修改前生产构建的 5 组 UI motion 浏览器流程通过。
- 最终定向回归：**19 文件／141 用例通过**。包含六类控件相关结构／原生事件、标题导航与选中美术、链接语义、偏好继承与实时变化、设置、整备、日志／仓库、窗口退出与焦点，以及 18 项 Logo 测试。
- 浏览器最终 **6 组流程通过**：普通／减弱 × 1600×900／1280×900 的标题→菜单→洋馆窗口→地图→设置，持久化与系统偏好切换，另加触摸打开／关闭标题起点窗口。实际验证标题、整备按钮／链接、设置 Hex／Notch 的内部下压、热区不动，模态退出和焦点归还保持；Mansion 返回链接另由组件测试覆盖，未制造资源失败来重验整套换景协议。
- Storybook `Foundation/UI Motion`：三类 A1 控件 × 普通／减弱的内部按压与不动热区、原生 Space、窗口焦点归还、loading 禁用、按住时切换系统减弱均通过；截图已检查，预览使用固定列宽避免展示容器挤压美术。
- `typecheck:app`、`typecheck:tooling`、`boundaries:check`、`motion:check`、游戏 build／output、UI release check 和 Storybook build 通过。公开 runtime exports 数量不变；未新增公开 API，本批未重复 U2 的 React 18／19 独立安装验收。
- 新增 `control-motion-boundary.test.ts`，定向阻止 A1 控件／标题表面恢复本地时长、位移或引擎导入，同时保留标题菱形样式断言。不会把整页专用演出或业务计时一并豁免／禁止。

新增浏览器断言调试时，修正了同名“出征编队”链接的查询范围（应测整备窗口中的 JournalActionLink，不是尚未迁移的 GameMenu）、读取选中几何前的实际就位等待，以及装饰 SVG 覆盖的原生 checkbox 操作方式。现有全局减弱兜底仍给静态节点设置 0.01ms transition，断言等到正确几何再验证按压不移动菱形，不用固定 sleep。没有修改这些 B／C 批产品组件来让 A1 测试通过。

本批没有重跑全量 `test:app`；U2 记录的 4 文件／6 项非动效断言失败仍作为历史限制保留，不能把本批定向通过写成全项目全绿。Storybook 仍报告大分块告警，未提高阈值掩盖。

## 性能与证据范围

同机、同 headless Chromium、1600×900，生产构建标题页等待 Logo 有限动画结束后，每三帧切换一次键盘选中，共采样 120 个帧间隔。前后无其他测试任务同时运行：

| 指标 | A1 前 | A1 后 |
| --- | ---: | ---: |
| 帧间隔 P95 | 66.6ms | 66.6ms |
| 最大帧间隔 | 83.4ms | 100ms |
| LayoutCount | 158 | 152 |
| 累计布局时间 | 8.79ms | 8.33ms |
| 累计样式计算时间 | 57.19ms | 122.88ms |
| 累计 TaskDuration | 208.31ms | 277.79ms |

这是高频选中压力样本，不是实际设备帧率保证。样式计算开销有增加，布局没有随接入增加；前后较长帧均明显存在，不能据此宣称稳定 60fps 或零回归。没有为了改善数字加入全局 will-change、合成层或更改 Logo；后续仍需按真实设备录制定位绘制／栅格化开销。
