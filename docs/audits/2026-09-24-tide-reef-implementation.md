## 玩家路径

新建普通档 → 完成／跳过教程 → 地图「潮声溶洞」 → 第一层雾滩两战 → 第二层洞内两战 → 撤离，或继续第三层栈道组合战 → 通透结算 → 返回洋馆 → SHOP 出售壳类／鉴定铜环。

正常刷本没有教程暂停，不反复发教程物件、三件货、礁钩奖励或庄园首通奖励。不会因此取得庄园成长或回忆凭证。失败、撤离和通关共用已有结算组件，没有新增实验页或界面皮肤。

庄园的自动结算用于进入落幕 ADV，保留原流程。新增普通路线的通关结果等待“返回洋馆”确认，与其失败／撤离保持一致；重新打开已结算结果不重复发奖。

## 规则与交易结果

| 实际命令情境 | 带回道具 |
| --- | --- |
| 第一层第二战失败 | 无；第一战螺壳仍未入袋 |
| 第二层第二战失败 | 螺壳 ×1；本层新螺壳丢失 |
| 第二层撤离 | 螺壳 ×2、礁蟹硬壳 ×2 |
| 第三层末战失败 | 螺壳 ×1、礁蟹硬壳 ×1 |
| 第三层通关 | 螺壳 ×2、礁蟹硬壳 ×2、未知铜环 ×1 |

第一层与第二层均清完两场才入袋，第二层出口不重复结算。失败保留一半已入袋 G 与道具，当前层未入袋收益丢失。测试通过实际战斗推进／停止攻击制造失败，没有修改 HP、骰面或直接构造奖励快照。

铜环鉴定扣 300 G，出售获得 600 G；壳类合计出售 680 G。全套实际交易净增 980 G，结算资金不预支道具估值。未鉴定铜环按废料出售仅得 2 G。固定台词使用银币／铜板，规则与界面按 G 记账。
