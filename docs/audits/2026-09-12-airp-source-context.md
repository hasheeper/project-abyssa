## 1. 结论与边界

**源码资料接线与隔离工程验收完成；第二批的真实文学质量退出条件尚未满足。** 这次推进的是 Abyssa 药箱样本，不是 rp 通用工作台。现有宿主能力够用，没有新增 Agent 循环、模型调度器、Memory 数据库或专用 HTTP 路由。

- 原27份分类草稿保持不变，从其中4份来源选择11个逐字摘录，作为3份Package默认Resource进入实际编译输入。
- 应用版本0.3.0→0.3.1，艾洛拉资料版本1→2；Abyssa显式接受0.3.1，旧版本精确映射继续保留，未放宽未知版本或Result来源。
- 三模型职责不变：纯文字大纲→纯正文→小模型格式化；阅读确认后另做小模型记忆更新，修复仍回传上轮原文与程序错误。
- 不改Program／State／Action合同、默认内容9、内容10两场范围或记忆容量，不改序幕／首晨定稿。
- 本轮真实Provider调用0次；未安装真实应用包、新建真实Release／Session、迁移旧档、覆盖资料草稿、改密钥或重启用户服务。

rp通用宿主源码未因本批改变；同步了新增应用／测试文件造成的架构统计报告，不修改架构政策。两仓已有大量用户未提交内容继续保留。

## 2. 来源、冲突与可移植性

| 来源 | 选取内容 | 摘录数 |
| --- | --- | ---: |
| [世界现状](../../st/setting/current_situation.txt) | 海崖、古典洋馆、共同生活的公共基线 | 3 |
| [艾洛拉原始档案](../../st/setting/char/2-elora.txt) | 人物动机、物资态度、医疗底线、同伴边界 | 4 |
| [对白指南](../design/DEMO_DIALOGUE_VOICE_GUIDE.md) | 艾洛拉表现尺度、对白节拍、口癖与动作承接 | 3 |
| [玩家行为契约](../design/NON_LLM_PLAYER_AGENCY_CONTRACT.md) | 兼容ID不是固定玩家姓名 | 1 |

清单：[medicine-case-sources.ts](../../../rp-style-lab/applications/airp/resources/medicine-case-sources.ts)。每份来源有相对路径和SHA-256，每个摘录有稳定ID、原文定位、逐字引用及适用解释。跨仓脚本逐项验证SHA和原文子串；源文件变化必须重新审定，不能只换hash跳过取舍。

本批明确选择**包内版本化默认资料**，不绑定本机Resource UUID，也不在运行时读另一仓库文件。原27份导入草稿是可编辑资料档案，不因存在分类标签就获得上下文访问权。来源文件、导入快照、应用默认切片、已读记忆是四种不同对象，不能互相冒充。

取舍规则：

- 已提交玩法事实是权威，原设定只辅助表达，不覆盖当前地点、在场者、结果、资产或知情范围。
- 世界概述的泛化出身与艾洛拉个人档案冲突，本场不发送或讲述身世；人物基线取个人档案，表现尺度用后续对白指南收束。
- 不选取私密关系、世界内幕、其他人物情节、原文固定玩家姓名及强关系长对白。不是整份资料送模后仅靠负面提示保密。
- 共同生活不等于已发生某次共同经历，更不等于亲密等级。已有精简人设中的两句示例只是口吻参考，不能进入历史记忆。
- “选择如何取回”不等于执行成功；撤离不证明全清，也不证明正道没清。未知天气、伤势、治疗、设施状态不补成事实。

## 3. 实际组装与编辑权限

| 阶段 | 已有受控输入 | 本批直接加载的Resource |
| --- | --- | --- |
| Outline／大推理 | 当前玩法投影、作者选项语义、任务、时地、已确认记忆 | 人物、公共场景 |
| Writing／文本 | 同一受控情境、纯文字大纲 | 人物、公共场景、专门对白规范 |
| Format／小推理 | 冻结正文、大纲、上轮格式原文与错误反馈 | 无 |
| Reformat／小推理 | 显式保存的精确正文修订、错误反馈 | 无；玩家端未开放该动作 |
| Updater／小推理 | 可信已读Result、授权State View、policy及错误反馈 | 无 |

资源作为 `airp-reference / participant` turn，不替换system规则。绑定固定，slot分别只接受entity／lore／instruction；测试核对声明和实际编译后的消息角色。Format可能通过上游正文间接看见选用的背景，这是正常的，不能误称完全不知道世界信息。

人物／场景沿用宿主授权派生机制：显式保存→新Release→新Session生效，旧Session继续读旧冻结版本。写作规范是instruction，保持包内只读，未开放`allowContentOverride`，没有为应用削弱宿主政策。本次没有创建用户派生资料；所有测试使用临时库。

## 4. 预算

| 包内默认资源 | 当前UTF-8字节 | 本批构建上限 |
| --- | ---: | ---: |
| 人物（精简档案＋证据） | 2953 | 8192 |
| 公共场景 | 1288 | 4096 |
| 写作规范 | 2295 | 6144 |

资料合计6536字节，不冒充模型精确token数。超过单资源构建上限直接拒绝，不静默截断原文。该上限针对包内默认内容；用户派生资料另受宿主资源校验和实际编译预算约束。

Pipeline总预算仍16000 tokens；Writing保留4096输出，输入上限11904。首次接线使最大事实用例触发`CONTEXT_BUDGET_EXCEEDED`；最终通过每资源去重来源元数据、去除人物JSON排版缩进解决，没有加大预算或丢弃必需事实。24条、每条320字的必需玩法事实用例已通过原生编译与完整三段调用。

这不是任意数量资料／长记忆都能装入上下文的承诺。当前模型额度和记忆容量不扩展，后续四型／多人需要独立容量测试。

## 5. 验收结果

本轮最终源码的定向检查：

- 来源／语义：4份SHA、11个逐字摘录、3个作者选择、256个游戏时钟组合全部通过，无模型调用。
- rp原生应用测试最终38项整体通过，无跳过；新增资料测试共4项，覆盖撤离／完成、两种选择、读前无摘要、读后召回、participant角色、Writing专用规范隔离及超预算拒绝。
- Abyssa接入／契约／客户端／旧reader轻量专项203项通过，包含0.3.1精确hash、错误最终生产者和未审定版本拒绝。
- 当前0.3.1包→独立Session→三段生成→确认→召回、过期head／重复确认／格式失败／required Updater拒绝通过，15次模拟调用。
- 合法玩家记录→原生Session→冻结AVG→实际阅读→记忆→后续通过，8次模拟调用；原身份响应丢失重放不增调用、不覆盖新存档。
- writer／Updater中断、宿主重启、精确重放及明确手写降级／依赖阻断通过，分别2／4次模拟调用。
- 本轮隔离game构建790文件／120.48 MiB，产物引用与hash核对通过；构建基础设施69项通过。
- 构建后的浏览器4项全部通过：双窗口丢失响应恢复与召回、格式失败手写降级、required Updater失败拦截、Session创建丢失响应唯一恢复。截图核对保留原AVG、人物和创作记录展示，没有重做前端。
- 两仓相关TypeScript、改动TS的ESLint／Prettier、Abyssa模块边界通过。rp架构边界无错误；新增源文件使统计快照过期，按原工具刷新报告后完整检查通过，未修改policy。
- 两仓`git diff --check`通过；13份更新文档的242个本地链接、7个锚点核对通过。

模拟正文是测试夹具，不是实际文学成品；以上测试不等于全仓CI、真实供应商文风／延迟／费用验收。第一批的旧内容长流程验收保留原报告，本轮不把它重复计入203项。
