# DEMO 内容体验审计：战斗压力与剧作

日期：2026-09-07。触发：用户实际游玩反馈“副本毫无压力、文案严重不合格”。本次核对当前默认 `abyssa.demo / contentVersion 3 / rulesVersion 4`、原始人设、实际运行脚本及既有配平记录。仅审计与制定返工边界，没有修改游戏数值、剧情、界面或存档。

## 1. 结论

**当前 Demo 已有工程闭环，内容体验仍未达到交付标准。两个首要缺口是关卡没有充分考验决策、剧本没有建立值得经历的戏。**

两者互相削弱：低威胁战斗支撑不起庄园的压迫感；对白又不断安慰、解释和收束，提前消解危险。玩家很难经历“冒险承受压力 → 克服困境 → 回到洋馆放松”的落差。美术上的恐怖与日常上的治愈，缺少中间的游玩经历。

既有人设、三重锁、白布／黑木／红线、千金受难与首通合簿，已经提供了足够明确的内容方向。不能把缺口归因于用户没有继续补设定。前面的交付过分集中在规则正确、页面接通、保存恢复及节点数量；内容是否好玩、人物是否成立，没有获得同等强度的审查。

## 2. 战斗：压力从哪里漏掉了

### 2.1 已经存在的警报没有推动返工

[D4 实施记录](/Users/liuhang/Documents/project-abyssa/docs/archive/audits/2026-09-06-demo-d4-implementation.md)早已记录：旧版默认四类配给下，HP18 千金的两种策略均为 **100/100 首通**；进入第五层时总 HP 均为 **15/15**，配给还剩 **6–10 次**。这说明前三层到后半程的消耗预算没有形成预期压力。

该记录有明确“工作值、未完成人工验收”的限定，不能冒充当前版本的统计。但警报当时已经足够明确。把它继续挂作尾项、随后不断接入成长与回忆，是交付优先级的失衡。

### 2.2 当前结构性问题

| 位置 | 当前事实 | 对体验的影响 |
| --- | --- | --- |
| 第三层管家 | 单体 HP16；封锁与3伤攻击交替 | 玩家至多五次角色行动，对方每轮只有一种意图；封锁轮缺少叠加的攻击压力，考核容易变成轮流处理一个问题 |
| 刻仪兽 | 维护 HP16、回忆 HP14；单体，直接使用普通 `charge` 行为 | 独特外形尚未对应独特战斗结构，仍是蓄力／3伤的循环；终战的变化和考核不足 |
| 回忆队伍 | 四名伙伴采用 Lv.2，药水和护符各两次；敌方仅刻仪兽 | 更强、更稳定的固定队伍面对更薄的单体终战；原护卫和重排带来的复合压力被移除后，没有补上刻仪兽自己的考验 |
| 我方行动 | 五人分摊攻防；每回合两次重掷；治疗面可反复出现；回合结尾还有铭约 | 敌人不能只按一次普通攻击的强度配平，必须计入重掷、格挡、治疗和回合尾额外效果 |
| 拖回合 | 当前正式庄园规则没有随回合升级的通用压力；牌型收益在层内累加并封顶 | 部分局面中，拖延可以同时恢复和积累收益。需要验证时长收益与风险，不能只看“最终是否通关” |
| 第三层出口／补给 | 有撤离和道具功能，但前段消耗不足 | 撤离缺少现实理由；商城、整备和成长的必要性被基础低难度稀释 |

例如柯萝萝一半骰面为4–5伤，保留两次重掷连续追这些面，理论命中率为87.5%。这不是要求削掉她的定位，而是说明敌人预算必须面对玩家可获得的稳定爆发。只拿单次随机骰的平均值判断难度，会低估实际队伍强度。

### 2.3 当前版本对照模拟

本次另以当前生产 Catalog 做固定种子的纯规则模拟，覆盖初战、维护、回忆。原始数据与脚本放在 `dist/reports/demo-quality/`。结果仅说明指定策略的表现，不等于玩家通关率，也不能代替实际试玩。

两种策略均不重掷、不主动追牌型、不购物、不装新增装备、不偷看未来随机数：

- **基础应对**：使用现有集成策略，按当前公开意图识别致命威胁、选择攻防和治疗，并使用携带的恢复品。
- **仅攻击**：依次固定骰子，只用第一个合法攻击，不使用防御、治疗和道具；铭约按正式规则自然触发。它用于检验无视防守的代价，不代表正常新手。

维护采用已有合法通关记录的战役状态，出征仍选默认勇者五人；回忆采用正式固定历史队伍。各模式独立启动，不将上一组结果伪造为下一组通关。

每组种子1–16，总计96条完整模拟；全部到达合法终局，没有达到步数上限的未完成样本。

| 模式 | 基础应对通过 | 仅主动攻击通过 | 基础应对平均总战斗回合 |
| --- | ---: | ---: | ---: |
| 五层初战 | 15/16 | 4/16 | 18.50 |
| 五层维护 | 16/16 | 15/16 | 14.00 |
| 回忆刻仪兽 | 16/16 | 16/16 | 2.88 |

进一步检查初战的基础应对组：**16/16满血进入管家，14/16满血进入千金**；另外两次进入千金时分别为14/15和13/15 HP。减少为两类免费配给以后，前半程的压力问题仍然存在。

同时必须如实保留反证：初战完全放弃主动防御和恢复时只有4/16通过。基础防守确实有作用，不能把模拟说成“任何乱点都必胜”。当前更准确的问题是：常规应对就能抹平大部分前程压力，额外的重掷优化、成长、装备及购物尚未发挥必要价值；维护和回忆的考验进一步下降。仅攻击通过维护／回忆也可能有队友力竭，通过率本身不能代表全程毫无损失。

当前 Catalog 摘要：`8b0267560ab2037ce862de5d3f2bbe30e2b252b5bbdffddb19a5d505ad0f9080`。默认勇者五人；初战／维护基础组携带食物四次、药水两次。总回合为各场进入的回合数之和，不是单场最长回合；纯规则步骤不表示屏幕游玩时长。本次没有新增实屏人工试玩，也没有验证全部等级／阵容。

### 2.4 返工重点

先设计每层究竟让玩家舍弃什么、保护什么、承担什么后果，再确定敌方组合、意图节奏、恢复预算与数值。第三层应检验之前学会的东西；第五层应把宾客与千金的关系变成有代价的选择；刻仪兽需要自己的战斗识别点。

单纯把3伤改成更高伤害，容易让3HP角色从无压力直接变为随机暴毙；单纯加血，会拉长已有的简单循环。免费基础配给、失败可恢复等既有定稿，不应被随手取消来制造难度。商业补给的价值应来自合理挑战中的取舍。

## 3. 文案：问题已经超过字句润色

### 3.1 人物被同一种照料语气覆盖

[原始玛丽埃塔档案](/Users/liuhang/Documents/project-abyssa/st/setting/char/1-marietta.txt)包含古典教养、边界感、居高临下、严苛与无声妥协；[柯萝萝档案](/Users/liuhang/Documents/project-abyssa/st/setting/char/2-kororo.txt)包含狡黠依赖、歪理、天才直觉与危机时的冷硬；[艾洛拉档案](/Users/liuhang/Documents/project-abyssa/st/setting/char/2-elora.txt)的核心矛盾是珍惜物资与不计代价救人。

实际文本取到了“休息、照顾、困、温柔”等表面元素，却很少让这些矛盾推动事情发展。凯尔频繁负责叫人坐下、吃东西、休息和兜底；伙伴频繁负责接受照料。人物各自的主动性、棱角与相处摩擦被削弱。

### 3.2 四类脚本各自的问题

| 范围 | 实际例子 | 需要返工的层面 |
| --- | --- | --- |
| 成长 | 艾洛拉“留给自己的那一份”、柯萝萝“留着的那一份”、诺玛“桌上留了位置”、玛丽埃塔坐下喝茶 | 多个关系节点重复分食物／留座／休息的解决方式；没有充分呈现不同角色在此刻做出了什么不同于从前的选择 |
| 庄园事件 | 登记簿一读，角色立即解释“没有停止权”；席位表直接说明清客减伤，凯尔再说“别把她当成操纵这一切的人” | 关键真相与解题结论被连续说明，玩家观察、怀疑和发现的空间不足；设计提纲直接变成对白 |
| 遗物事件 | “里面的东西”“一件件取出”，失败则安慰“人没受伤就好” | 没有具体到足以让人在意的物件、旧主人痕迹或角色反应。保全的情感价值没有建立，成败主要落在金币和泛化安慰上 |
| 玛丽埃塔回忆 | 历史段落是勇者队打钟、互相叮嘱、休息；回来后邀她同行便接受 | 战斗替换已经完成，但人物章节的因果未补齐：玩家新理解了她什么，她现在为什么愿意以不同方式参与，仍缺少戏剧支点 |
| 战斗短句 | 多人不断说“跟紧”“别勉强”“先休息”“别受伤” | 高频重复会把一次性的温柔磨成机械应答；有称呼和口癖，也不等于存在鲜明人物声音 |

“勇者小队对刻仪兽”、首通后开放回忆／维护、完成回忆后玛亲征，均继续遵守用户定稿。需要补的是这条结构内的人物因果，而非擅自恢复已经被替换的本尊战。

### 3.3 戏剧结构先于口癖

每场先写清楚：谁此刻想做什么，谁或什么阻止她，人物怎样应对，场景结束后究竟改变了什么。再决定出场人物、动作、停顿、信息量和对白。

ACGN 的人物感来自欲望、脾气、反差、熟人之间不必解释的关系，以及说话时机。给现有台词补“哼”“嘛”“BOSS”和省略号，解决不了大家都在执行同一套体贴流程的问题。

用户定稿的“家宴结束了，小姐。您可以离席了。”和“今天没有客人。”应保留。它们的力量需要前面的困境和人物选择来支撑，不能仅靠结尾引用名句完成情绪交付。

## 4. 前面的工作方法为何没有拦住问题

1. **把工程验收当成了主要推进依据。** 正确扣血、公式一致、事件能保存，都无法证明这场战斗需要思考或这段剧情值得读。D6 配平和试玩一直保留尾项，内容弱点却随功能扩张继续放大。
2. **脚本先被节点装满，再被当成内容完成。** 当前回忆固定8／9／6／9／8行；成长基本每段6句；事件基本3句。现有测试验证长度、ID、人物是否在队、与计划稿逐字一致，这些是兼容及完整性检查。它们没有判断人物是否有戏、信息是否冗余、情绪是否成立。
3. **修稿范围不完整。** 上一次声音指南及修订集中在庄园、结局、回忆，成长和高频战斗短句仍延续旧表达，玩家实际接触的是多套标准混合的文本。
4. **验证者代替作者的问题未被解决。** 用户不断指出布局、交互、语义和文案，实际上承担了主要的体验筛查。后续交付必须先形成可评审的内容质量，再让用户裁决方向与品味。

保存稳定行 ID 有工程意义，创作仍可通过显式新脚本版本调整篇幅和结构。不能以兼容为由，让新稿永久受旧行数约束；也不能为了重写直接破坏正在阅读的旧档。

## 5. 建议的返工顺序与验收口径

同日用户后续调整优先级：先补“CG世界介绍→洋馆介绍→基础教程／简单副本→初始钩子”的初章，详见[初章计划](../plans/DEMO_PROLOGUE_AND_ONBOARDING_PLAN.md)。下表保留为庄园内容返工的内部顺序，不再表示下一步立即改第二层／管家。初章采用弱敌教学不撤销本审计结论；庄园压力、回忆与成长剧作仍需独立验收。

| 优先级 | 交付内容 | 通过标准 |
| --- | --- | --- |
| P0：体验目标与主线重构 | 五层压力曲线、每场战斗的决策职责；庄园／回忆完整分场大纲，明确玛的变化与解锁因果 | 能解释各层的取舍及递进；主线有发现、阻力、行动和收束，避免逐段解说设计答案 |
| P1：一个代表段落做到可玩 | 第二层→管家→撤离选择，连同对应的剧情与队伍互动；已有界面承载 | 轻率决策有明确后果，合理策略有可解释优势；出口选择有意义；角色在同一麻烦中作出有差异的反应 |
| P2：推广到完整 Demo | 千金、刻仪兽、成长事件和战斗短句；核对商店、成长对难度的影响 | 普通打法、忽略机制、利用机制的表现有合理差异；主线读完能说清玛的变化；高频文本不反复消耗同一个情绪 |

先用固定种子比较策略与资源曲线，再以完整试玩检验理解、疲劳、节奏与人物感。全员满血稳定抵达后半段、关键机制忽略也毫无代价、对白换人仍基本成立，均应触发返工，而不是再加一句“待后续优化”。具体胜率与难度目标留待体验目标定稿，不能在审计中凭空指定。

本轮结论是**内容层需要正式返工**。现有前端和工程承担验证这些内容的底座；新系统、更多事件数量和 LLM 接口都不能代替这一步。
